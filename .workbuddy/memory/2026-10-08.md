## 三个坑（重要，下次直接复用）

1. **Maven 在本机跑不起来**：全局 `MAVEN_HOME=D:\\soft-install\apache-maven-3.9.14` 带反斜杠，导致 `org.codehaus.plexus.classworlds.launcher.Launcher` 加载失败；且全局 `JAVA_HOME` 指向 temurin-18（缺 lib，报 "Failed setting boot class path"）。
   解决：新增 `tools/mvn-run.sh`，unset MAVEN_HOME/M2_HOME，固定 `JAVA_HOME=C:/Program Files/Microsoft/jdk-17.0.13.11-hotspot`，用 java 直接调 `-classpath D:/soft-install/apache-maven-3.9.14/boot/plexus-classworlds-2.9.0.jar -Dclassworlds.conf=.../m2.conf` 启动 Launcher。注意 MVN_HOME 必须用盘符写法 `D:/...`，`/d/...` 形式同样失败。
2. **环境变量 `SERVER__PORT=59390`（WorkBuddy 注入）会被 Spring 宽松绑定成 server.port**，优先级高于 application-local.yml，导致 Tomcat 占用 WorkBuddy 自身端口并报 "Port 59390 was already in use"。必须在命令行显式 `--server.port=8080`。
3. **安全基线要求必需密钥**：`STUDENT_LOGIN_CODE_SECRET_V1`（Base64 ≥32 字节）、`STUDENT_IMPORT_CREDENTIAL_KEY`（Base64 恰好 32 字节）、`EXPORT_SOURCE_HMAC_SECRET`（≥32 字符）。已随机生成并写入 `application-local.yml`（gitignore），用户确认走本地配置。注意更换 v1 学生登录码密钥会使远端库里存量学生登录码摘要失配。
