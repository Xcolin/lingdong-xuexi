# 工作台待审、入驻角色与用户范围验证

## 行为

- 工作台待审核页同时支持系统待审任务和原有学习审核。系统任务使用现有服务端权限过滤后的 PENDING_REVIEW 查询，显示总数和最多 5 条，点击直接定位系统任务详情；自己的申请显示“查看”，不能自审。
- 系统任务响应分别保留申请人/审核人的姓名与标识，界面使用标识判断是否为本人，避免把姓名与用户 ID 比较。
- 入驻家庭默认授予 PARENT_ADMIN，学校/培训机构通过审核后授予 ORG_ADMIN。既有事务同步保存组织成员、该组织范围角色、管理员和负责人；本次保留已配置角色权限，没有重新初始化。
- 组织用户标记当前负责人，“取消关联”“取消管理员”禁用并提示先转交。后台批量取消及直接组织解绑路径均拦截当前负责人；转交后原负责人可以取消，最后有效管理员保护继续保留。
- 用户管理列表、总数、详情和机构查询选项使用服务端推导范围：当前账号直接归属组织及其下级组织，多组织取并集。只有启用的 SYS_ADMIN 可以查询所有用户，包括未归属组织的账号。
- ALL 数据范围角色和系统审核员不能绕过这项目录限制。无组织归属返回空列表，越界详情返回 404。
- 用户同时属于可见/不可见组织时，机构筛选必须匹配同一条可见成员关系；返回的机构名称仅来自可见范围。
