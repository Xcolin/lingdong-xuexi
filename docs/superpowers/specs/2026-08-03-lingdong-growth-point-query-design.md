# 灵动学习 V25 积分账户与台账查询设计

## 1. 目标与范围

V25 在 V24 学生唯一积分账户和不可变任务奖励台账之上补齐安全查询闭环。学生通过 uni-app 查看本人累计积分、可用积分和台账；主家长通过 Web 选择活动主关系学生后查看同一账户与台账。

本里程碑只提供只读查询和双端展示，不实现积分纠错、兑换、休眠清零、衰减、统计报表、排行榜或消息通知。所有展示值均来自服务端，不在客户端重算余额或奖励积分。

## 2. 隐私与角色边界

1. 学生只能通过 `MINIAPP` 会话查询当前身份对应的学生档案，不接受客户端学生标识。
2. 主家长只能通过 `WEB` 会话查询活动主家长关系下的学生，越权对象统一返回资源不存在。
3. 教师、机构管理员、系统管理员和系统审核员不获得统一积分账户查询权限。
4. 统一账户混合家庭、机构和教师来源。教师或机构管理员若读取总余额，会间接获知家庭私有任务积分，因此 V25 不向其开放；后续机构统计必须按授权来源单独聚合。
5. 台账原记录继续不可修改，查询不暴露账户版本号、内部权限范围或其他学生数据。

## 3. 功能开关与 RBAC

Flyway V25 新增全局功能开关 `GROWTH_POINT_QUERY`，默认启用；新增 `GROWTH_POINT_READ_SELF` 和 `GROWTH_POINT_READ_CHILD` 两项操作权限，分别授权内置学生角色和家长角色。

公开能力摘要增加 `growthPointQueryEnabled`。开关关闭后，Web 菜单与直达路由、小程序首页入口与直达页面全部隐藏或退出，后端积分查询接口统一返回功能停用错误。权限拒绝与功能停用均由后端再次强制执行。

## 4. 查询模型与接口

积分账户响应包含学生标识、学生姓名、累计积分、可用积分和账户更新时间，不返回 `version_no`。台账响应包含台账标识、变更类型、数量、可用积分变化、来源任务实例、任务标题、来源类型、来源组织名称、审核人名称、发生时间和备注；所有 19 位标识按字符串返回。

新增接口：

| 方法与路径 | 权限 | 用途 |
|---|---|---|
| `GET /api/v1/growth-points/me/account` | `GROWTH_POINT_READ_SELF` | 学生查询本人账户。 |
| `GET /api/v1/growth-points/me/ledgers` | `GROWTH_POINT_READ_SELF` | 学生分页查询本人台账。 |
| `GET /api/v1/growth-points/students` | `GROWTH_POINT_READ_CHILD` | 主家长查询活动主关系学生候选。 |
| `GET /api/v1/growth-points/students/{studentId}/account` | `GROWTH_POINT_READ_CHILD` | 主家长查询指定孩子账户。 |
| `GET /api/v1/growth-points/students/{studentId}/ledgers` | `GROWTH_POINT_READ_CHILD` | 主家长分页查询指定孩子台账。 |

分页参数为 `page` 和 `pageSize`，页码范围 1 至 1000000，每页范围 1 至 100，固定按发生时间和台账标识倒序。账户或学生不存在、停用或超出对象范围统一返回 `404`；客户端类型或角色错误返回 `403`；分页错误返回 `400`；功能关闭返回 `409`。

## 5. 后端设计

`growthpoint` 模块新增只读查询 Mapper、查询行模型、应用服务和 Controller。查询 SQL 以学生标识为唯一数据边界，台账只做左连接补充任务、来源组织和审核人展示名，不读取任务目标或其他学生。

学生身份由当前认证用户反查启用学生档案。主家长对象范围使用活动主家长关系校验，不复用机构学生目录。应用服务先执行功能开关、角色与客户端校验，再解析学生范围并查询账户或台账。

## 6. Web 交互

Web 新增独立“积分台账”路由，仅主家长且积分查询开关启用时显示。页面顶部提供孩子选择；选中后展示累计积分和可用积分摘要，下方以紧凑表格展示变更类型、任务、来源、积分变化、审核人和时间。无孩子、无账户、无台账、加载失败和重试均有明确状态。

页面不提供编辑、纠错、导出或统计入口。开关关闭时不渲染菜单，直达路由回到工作台且不请求积分接口。

## 7. uni-app 交互

学生首页在积分查询开关启用时显示“我的积分”入口。积分页顶部展示累计与可用积分，下面按时间倒序展示台账；支持下拉刷新和分页加载。任务奖励显示任务标题、来源标签、发生时间和正向积分变化。

直达积分页先验证本地学生会话和公开能力，再请求业务数据。会话缺失回到入口页，功能关闭回到学生首页，不发送积分查询请求。小程序不提供任何积分修改或审核操作。

## 8. 测试与验收

迁移测试验证 V25、功能开关、两项权限、两条角色授权和 44 张表非自增雪花主键基线不变。后端端到端测试验证学生本人查询、主家长孩子查询、越权隐藏、教师和机构管理员拒绝、台账分页顺序、19 位标识字符串以及功能关闭拦截。

Web 测试验证入口判定、孩子选择、账户和台账展示、分页与接口失败反馈。uni-app 通过类型检查、H5 和微信小程序构建，并使用本地虚拟接口进行学生首页入口、积分页、空态和功能关闭直达阻断的视觉验收。
