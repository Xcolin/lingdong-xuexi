# V63 PDF 导出选取与准备

范围：既定 PDF 作业接入前的数据准备，不新增 HTTP 接口、下载入口、其他报表或数据库表。

单份通过学生标识和复盘标识选取；区间通过学生、周期、开始/结束日期选取，两种方式互斥。区间包含完整落入边界的报告，不截断周/月快照；按周期开始日期和标识稳定排序。单次最大报告数默认为 100，作为可配置资源保护上限，超过时拒绝而非截断。

服务只接受 Web 活动关系家长，实时检查 GROWTH_REVIEW_READ_CHILD、账号有效性与亲子关系；系统审核员不得进入。查询与数量限制在 SQL 内执行，不读取全部报告后内存过滤。主副家长的读取边界沿用现有复盘查询。

在可重复读事务中选定当前快照、分类、趋势及当时补录，形成不可变准备结果。结果是内存值对象，并非已持久化导出作业；后续作业必须原样固化而非执行时重新查询当前快照。若查询间版本不一致，明确冲突，不返回混合版本。

该服务只核验数据读取资格，不授予 PDF 生成或下载权；后续创建/执行必须另查 PDF 开关、导出权限、模板与附件规则，下载时再次查关系。历史文件读取不以“新导出已关闭”为唯一拒绝理由。

测试覆盖真实 MyBatis 区间、单份互斥、边界、空选集、上限、主副亲子关系、撤权及准备结果不随后续补录改变。
