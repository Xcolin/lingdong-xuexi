# 灵动伴随 V57 通用异步导出作业设计

## 1. 目标

V57 在 V54 统一附件、V55 导入导出模板和 V56 异步校验作业基础上，建设可复用的 Web 端异步 Excel 导出能力，并以两条真实链路验证不同安全等级：

1. 家长导出本人当前活动主监护关系学生的积分明细，属于当前业务范围内的普通脱敏导出，不进入系统审核队列。
2. 系统管理员导出权限变更日志，属于敏感系统导出，必须创建 `SENSITIVE_DATA_EXPORT` 系统任务，由系统审核员批准后才能进入生成队列。

V57 只生成 `.xlsx` 文件。成长复盘 PDF、十四类完整报表、真实消息推送、云对象存储和其他业务导出适配器不在本专项范围。

## 2. 依据与不可突破边界

1. 导出继承功能权限、动态 RBAC、组织或学生对象范围，审批不能扩大数据访问范围。
2. 系统审核员只审批系统管理员提交的高风险系统任务，不进入家长积分、任务、兑换、考勤等普通业务审核。
3. 普通导出和敏感导出共用作业引擎，但入口、权限、审批状态和下载对象边界不同。
4. Web 承担复杂筛选、进度、审批和下载；uni-app 不增加复杂导出页面、路由、API 或权限码。
5. `DATA_EXPORT`、`IMPORT_EXPORT_TEMPLATE_MANAGEMENT`、`ATTACHMENT_SERVICE` 任一关闭时，导出入口、台账、审核和下载全部隐藏，后端拒绝创建、领取、查询、审批和下载；历史文件事实保留，重新启用并通过当前权限校验后才可读取。
6. 所有新增表主键使用应用层生成的 19 位雪花 `BIGINT`，禁止自增。V1 至 V56 不修改，下一迁移为 V57。
7. 导出文件不自动删除；功能停用期间只保留历史文件事实，不提供读取入口。文件关系、下载和退役继续由统一附件边界控制。

## 3. 方案选择

采用“通用导出作业 + 适配器注册表 + 系统任务审批桥接”。不为每个业务模块复制一套作业表，也不允许客户端提交 SQL、实体字段名或表达式。

每个 `ExportDatasetAdapter` 负责一个稳定导出类型：声明可选列、默认列、数据敏感等级、请求范围校验、不可变数据上界、总数和分页读取。通用引擎只负责状态机、模板、分页调度、Excel 生成、附件、审计和下载。

本专项注册两个生产适配器：

| 导出类型 | 申请角色 | 安全等级 | 数据范围 |
|---|---|---|---|
| `GROWTH_POINT_LEDGER` | Web 家长 | 普通脱敏 | 本人当前活动主监护关系学生。 |
| `IAM_CHANGE_AUDIT` | Web 系统管理员 | 敏感 | 当前系统管理员已有 `IAM_AUDIT_READ` 权限可读取的权限变更日志。 |

## 4. 模板约定

V57 使用管理员通过 V55 模板管理上传、启用并设为默认的 `EXPORT/REPORT` 模板。V55 没有预置物理模板文件，部署或验收前必须先完成该配置；不存在可用默认模板时，选项接口返回“导出模板未配置”，不允许创建作业。模板第一张工作表的首行使用 `${字段编码}` 占位符，例如 `${OCCURRED_AT}`、`${STUDENT_NAME}`。占位符必须唯一，且全部来自目标适配器列白名单。

创建作业时校验模板状态、默认项和占位符，并固化模板标识、名称、版本及选定列快照。生成时读取已固化模板版本的文件，不改用后续新默认模板。未选择的允许列从结果工作簿移除；请求包含未知、重复或适配器禁止列时拒绝创建。模板不执行公式、宏、外链或脚本，只复制允许的单元格样式和静态文本。

## 5. 导出字段

### 5.1 家长积分明细

允许列：

| 字段编码 | 表头 | 默认 | 处理规则 |
|---|---|---:|---|
| `OCCURRED_AT` | 发生时间 | 是 | 上海时区格式化到秒。 |
| `STUDENT_NAME` | 学生姓名 | 是 | 姓氏加星号脱敏。 |
| `CHANGE_TYPE` | 变动类型 | 是 | 输出中文业务名称。 |
| `AMOUNT` | 积分变动 | 是 | 输出整数。 |
| `AVAILABLE_DELTA` | 可用积分变动 | 是 | 输出整数。 |
| `SOURCE_TYPE` | 来源类型 | 是 | 家庭、机构或教师。 |
| `SOURCE_ORGANIZATION` | 来源机构 | 否 | 无机构时为空。 |
| `TASK_TITLE` | 任务标题 | 否 | 保留当前任务标题快照。 |
| `REVIEWER_NAME` | 审核人 | 否 | 姓氏加星号脱敏。 |
| `REMARK` | 备注 | 否 | 最长按现有台账事实输出，不拼接隐藏字段。 |

不导出手机号、亲子关系、账号、设备、登录码、令牌、位置、情绪数据或其他学生信息。

### 5.2 权限变更日志

允许列为发生时间、事件类型、目标类型、目标标识、目标名称、操作人、变更前摘要、变更后摘要和操作结果。操作人姓名脱敏；前后摘要只允许既有审计模型中的非敏感枚举与标识，不输出密码、令牌、手机号、设备信息、存储键或请求正文。

## 6. 数据模型

### 6.1 `sys_export_job`

保存一项导出请求及其当前状态：

- `id`：19 位雪花主键。
- `job_code`：不可变唯一作业编码。
- `export_type`：适配器类型。
- `template_id`、`template_name`、`template_version`：模板快照。
- `requester_id`：申请人。
- `student_id`：积分导出的目标学生，其他类型为空。
- `system_task_id`：敏感导出的系统任务，普通导出为空且唯一约束忽略空值。
- `filter_snapshot`：规范化筛选条件 JSON。
- `column_snapshot`：有序列定义与表头 JSON。
- `scope_snapshot`：申请时对象范围和不可变数据上界 JSON。
- `mask_policy_snapshot`：实际脱敏规则 JSON。
- `request_reason`：申请原因。
- `sensitive_flag`：是否需要系统审核。
- `status`、`version_no`：状态和乐观版本。
- `result_file_id`：成功结果文件，可空且一个结果文件只能属于一个导出作业。
- `total_rows`、`processed_rows`：总量和进度。
- `failure_code`、`failure_message`：受限失败信息。
- `request_source_hash`：通过服务端密钥生成的来源地址摘要，不保存原始地址，密钥不进入代码库或数据库。
- `requested_at`、`reviewed_at`、`queued_at`、`started_at`、`completed_at`、`created_at`、`updated_at`。

索引覆盖作业编码、系统任务、状态领取、申请人时间和导出类型时间。模板、申请人、学生、系统任务和结果文件均使用受限外键，不级联删除导出事实。

### 6.2 `sys_export_job_event`

保存不可变状态事件：19 位雪花主键、作业标识、事件类型、操作者、受限中文摘要和发生时间。事件类型包括申请、提交审核、批准、驳回、领取、成功和失败；批次进度只更新作业主表，不按批次追加事件。事件不保存原始筛选报文、单元格内容、IP、堆栈或文件路径。

V57 后共有 82 张显式非自增主键表。

## 7. 状态机

```text
普通导出：QUEUED -> EXPORTING -> SUCCEEDED
                            \-> FAILED

敏感导出：PENDING_REVIEW -> QUEUED -> EXPORTING -> SUCCEEDED
                       \-> REJECTED             \-> FAILED
```

1. 普通导出创建后直接为 `QUEUED`。
2. 敏感导出在同一事务创建系统任务和导出作业，并立即提交系统任务，作业为 `PENDING_REVIEW`。
3. 系统审核员批准后，系统任务为 `APPROVED`，作业条件更新为 `QUEUED`；驳回后系统任务和作业均为 `REJECTED`。
4. 调度器以 `QUEUED + versionNo` 条件领取为 `EXPORTING`，多实例只有一个领取成功。
5. 文件生成、附件保存和关系建立成功后，作业进入 `SUCCEEDED`；敏感导出的系统任务随后标记 `EFFECTIVE`。
6. 生成失败进入 `FAILED`，敏感系统任务保留 `APPROVED` 而不伪造 `EFFECTIVE`。
7. 所有终态重复处理保持原事实，不重复生成文件或事件。

## 8. 创建、执行与下载流程

### 8.1 普通积分导出

家长在 Web 积分页选择当前活动主监护学生、时间筛选、字段和原因。服务端重新验证 Web 家长、`GROWTH_POINT_READ_CHILD`、`EXPORT_JOB_CREATE`、主监护关系及三个功能开关，取得当前积分台账最大标识作为数据上界，固化快照后创建排队作业。

### 8.2 敏感权限日志导出

系统管理员在导出中心选择时间、事件类型、字段和原因并二次确认。服务端验证活动系统管理员、`IAM_AUDIT_READ`、`EXPORT_SENSITIVE_SUBMIT` 和三个功能开关，在同一事务创建系统任务和待审导出作业。系统审核员具有 `EXPORT_SENSITIVE_REVIEW` 时可查看脱敏申请元数据并批准或驳回，不能读取导出数据或结果文件。

### 8.3 异步生成

工作线程领取前和领取后均再次验证申请账号、角色、权限、对象关系和开关；生成期间每批检查全局开关，关闭后立即停止并进入 `FAILED`。适配器只查询不大于创建时上界的不可变数据，使用稳定的 `id` 游标分页；每批只更新作业主表处理数量。Apache POI 使用流式工作簿写入，单工作表达到配置行数后创建下一工作表，不一次性加载全部数据。生成完成后通过统一附件服务保存 `.xlsx`，建立 `EXPORT_JOB_RESULT/REPORT_EXPORT` 关系并原子写入结果文件标识；失败时补偿未关联内容，数据库只保存中性错误，应用日志按既有脱敏规则记录追踪标识和异常原因。

### 8.4 查询与下载

三个全局功能开关均启用后，普通用户只能查询本人作业。积分导出下载时必须仍是活动 Web 家长、仍持有读取和导出权限、仍与目标学生保持活动主监护关系。敏感导出只允许原系统管理员申请人在当前仍具备系统管理员角色、`IAM_AUDIT_READ` 和导出权限时下载。系统审核员只能查看审批元数据，不能下载。系统管理员不因平台角色读取其他家长的积分导出文件。统一附件通用端点不得凭文件标识直接读取 `EXPORT_JOB_RESULT`，只能由导出应用服务完成对象级复核后返回内容。

## 9. 权限与功能开关

新增 Web 权限：

| 权限 | 默认授权 | 用途 |
|---|---|---|
| `EXPORT_JOB_READ` | 系统管理员、家长 | 查询本人导出作业和受控下载。 |
| `EXPORT_JOB_CREATE` | 家长 | 在适配器业务权限范围内创建普通导出。 |
| `EXPORT_SENSITIVE_SUBMIT` | 系统管理员 | 提交敏感导出系统任务。 |
| `EXPORT_SENSITIVE_REVIEW` | 系统审核员 | 查看并审批系统管理员提交的敏感导出元数据。 |

新增全局开关 `DATA_EXPORT`，默认启用。普通积分导出同时要求 `GROWTH_POINT_QUERY`；敏感权限日志导出同时要求身份权限审计已有功能边界。动态角色或用户 `DENY` 优先，固定系统管理员与系统审核员职责不能由自定义角色绕过。

## 10. API

| 方法与路径 | 说明 |
|---|---|
| `GET /api/v1/export-jobs/options?exportType=...` | 返回当前用户可用导出类型、模板、对象、筛选和列选项。 |
| `POST /api/v1/export-jobs` | 创建普通或敏感导出；敏感类型必须满足系统管理员边界。 |
| `GET /api/v1/export-jobs` | 分页查询本人作业。 |
| `GET /api/v1/export-jobs/{id}` | 查询本人作业详情、进度、快照摘要和事件。 |
| `GET /api/v1/export-jobs/{id}/download` | 成功后受控下载结果文件。 |
| `GET /api/v1/export-job-reviews` | 系统审核员分页查询待审敏感导出。 |
| `POST /api/v1/export-job-reviews/{taskId}/approve` | 批准并将作业加入队列。 |
| `POST /api/v1/export-job-reviews/{taskId}/reject` | 填写意见并驳回。 |

列表默认每页 20、最大 100。所有雪花标识按字符串返回。响应不返回存储键、摘要、原始来源地址、永久 URL、模板物理路径或未脱敏样例数据。

## 11. Web 交互

1. `/export-jobs` 为独立导出中心，展示类型、状态、进度、申请时间、完成时间、失败摘要和下载命令。
2. 家长积分页面增加导出图标按钮，弹窗选择当前学生、时间范围、列和原因；当前筛选已确认无数据时不显示导出命令。
3. 系统管理员可在导出中心提交权限变更日志敏感导出并查看本人申请。
4. 系统审核员只显示“敏感导出审核”视图，展示申请人、类型、范围摘要、原因和时间，不展示数据明细、样例或下载按钮。
5. 功能关闭或无读取权限时菜单和直达路由同时隐藏并拒绝；创建、敏感提交和审核按钮分别按权限裁剪。
6. 1280px 保持紧凑台账；390px 筛选和弹窗单列，宽表在自身区域滚动，进度和图标按钮尺寸稳定。

## 12. 异常与补偿

| 场景 | 处理 |
|---|---|
| 模板缺失、停用或占位符不兼容 | 创建失败，不生成作业。 |
| 权限、角色、关系或开关在排队后失效 | 执行时进入 `FAILED`，记录中性错误，不查询或生成数据。 |
| 同一作业被多实例领取 | 仅条件更新成功实例执行，其他实例跳过。 |
| 查询批次失败 | 作业失败，已生成临时内容清理，不建立结果关系。 |
| 附件保存成功但数据库终态失败 | 补偿新文件和关系，原始异常为主，补偿异常作为附加异常。 |
| 结果文件不存在或已退役 | 下载返回 404，不暴露存储状态。 |
| 审批重复、越权或状态已变化 | 返回冲突或拒绝，不重复排队。 |

## 13. 配置

在 `application.yml` 增加导出调度启停、扫描周期、每轮作业数、查询批量行数、单工作表最大行数和临时目录配置。来源摘要密钥只从环境变量或密钥管理服务读取，缺失时生产配置拒绝启动。生产默认值不写入任何远程地址、账号或密钥；测试使用本地 H2、测试密钥和临时目录。发布检查必须确认管理员已配置启用且默认的 `EXPORT/REPORT` 模板；V57 不通过迁移伪造物理附件或默认模板记录。

## 15. 完成口径与后续边界

V57 完成后可以声明：通用异步 Excel 导出框架、家长积分明细普通导出和权限变更日志敏感导出已本地闭环。不能声明：十四类报表、成长复盘 PDF、消息真实投递、超大文件跨文件分包、云对象存储、文件自动归档或其他业务导出已完成。

真实 MySQL、Redis、微信、对象存储、共享测试、预生产、生产和业务 UAT 不在本地验收中执行。下一迁移从 V58 开始。
