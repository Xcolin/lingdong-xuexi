# 学校、年级、班级统一管理

用户已批准学校→年级→班级，以及选节点→看列表→点按钮的简洁操作，并要求开始实施。
同一组织树作为上下文：学校默认年级列表，年级默认班级列表，班级默认学生；组织用户、教师、信息放对应页签。新增自动固定父级，提交后树和列表刷新且保留选中节点。用户后续要求将更多及更多业务内操作直接显示：组织操作、机构业务操作使用独立按钮区，空间不足自动换行，列表内部滚动。
新年级必须直接属于学校，新班级必须直接属于年级；后端创建及移动统一校验。学校归属查询从组织路径/祖先类型解析，不能把班级parentId当学校。学校停用禁止新增。保留权限编码、功能开关、真实数据范围、学生教师业务关系和审计。
存量直属学校班级不删除、不猜年级；提供待归属提示及选择年级归并入口，同校归并不改变班级ID或业务关系。跨校移动沿用专门变更流程。
验证层级拒绝、上下文自动带入、树列表刷新、学校范围及跨校拒绝、教师学生查询、存量归并；构建与真实数据库健康检查。
