# V63 复盘导出内容持久化

## 范围与复用

继续既定 PDF 作业接入，不新增其他报表。新增 `sys_export_job_payload` 作为现有 `sys_export_job` 的一对一内容扩展，避免批量报告全文超过旧 `TEXT` 筛选字段容量。原作业状态、事件、模板引用和附件关系仍由原模块管理，不建立第二套作业状态机。

## 写入与读取

- `GrowthReviewExportPayloadStore.freeze` 必须加入调用方已有事务；创建作业与固化内容需要同一事务提交或回滚。仅允许申请人和学生一致、`QUEUED` 且版本号为 0 的作业写入，唯一键拒绝重复，不提供覆盖方法。
- 内容包含格式版本 1、作业标识、统一模板标识和版本、简洁/详细模式，以及创建时准备好的报告快照、分类、趋势、补录。使用结构化 JSON 序列化，不拼接 JSON、不执行用户文本。
- 单份和批量共用内容结构。报告数量最多 1000，仍受上游默认 100 的可配置选取上限约束；UTF-8 内容最大 8MB，超限明确拒绝，不截断。拒绝空列表、跨学生和重复报告标识。
- 读取验证格式版本、作业/模板引用、申请人和学生归属及 SHA-256 完整性。摘要只发现内容损坏，不是权限凭证，也不声称能够防止数据库管理员同时改写正文和摘要。
- 异步执行必须使用固化内容，不通过当前快照指针重查报告；重试只能复用旧内容。迁移不改动历史 XLSX 作业。

## 安全和实施状态

该服务是内部持久化组件，不是 PDF 创建或下载接口，不负责授予功能权限。外层创建和执行仍须核验功能开关、动态权限、账号和亲子关系；历史下载还须实时验证原有对象和附件访问资格。原始正文只存于数据库，不添加到作业列表、事件摘要或日志。

本次未接通 PDF 作业类型、创建端点、调度格式分支及下载入口。存储测试使用既有作业类型作为关联夹具，只验证内容存储契约，不能当作完整 PDF 业务链路验收。

## 数据迁移

新增 `V63__add_export_job_payload.sql`，不修改 V1-V62。新表主键由现有雪花生成器分配 19 位 `BIGINT`；`job_id` 唯一并外键关联原作业。正文为 `LONGTEXT`，内容类型固定 `GROWTH_REVIEW_PDF_V1`，包含 64 字符摘要与创建时间。今后数据库结构变更从 V64 连续新增；业务工作包仍为 V63，不与迁移号混淆。

验证使用本地 H2 MySQL 兼容模式。远程 MySQL 的迁移及业务联调未执行，不作为已通过证据。
