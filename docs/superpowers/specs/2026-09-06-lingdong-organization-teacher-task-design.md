# 灵动伴随 V60 机构与教师任务补齐设计

## 1. 目标与需求追溯

V60 对应 `BRD-3.4-02`、`BRD-3.4-03`、`BRD-3.4-07`、`BRD-3.4-12`、`BRD-3.6-05`、`BRD-3.6-06` 和 WBS-03、WBS-07，补齐机构管理员与教师在 Web、uni-app 两个独立前端中的任务操作职责。

本专项复用 V22-V34 已有任务定义、目标展开、发布、执行、审核、免执行、顺延、批量发布和附件能力，不新增原始需求之外的任务类型。复杂机构报表、班级趋势、异常报备和考勤分别留在 V61-V64。

## 2. 现状与缺口

现有后端已允许机构管理员创建机构任务、教师创建本班教师任务，并支持一个任务选择多个组织或学生目标；发布时目标展开为学生任务实例。Web 已有任务管理、批量发布、审核待办和待优化任务页面。

剩余缺口如下：

1. 任务管理权限当前仅有 Web 客户端权限，机构管理员和教师在小程序无法调用同一后端业务契约。
2. 小程序仅有学生任务执行页，缺少机构管理员和教师的任务列表、新建、编辑、发布、审核入口。
3. 管理者只能看到任务定义和审核待办，缺少按任务查看学生级状态进度。
4. 教师停用或解除班级关系时仍采用“存在待审核任务即阻止”的临时保护，尚未落实自动转交规则。

## 3. 方案

### 3.1 双端职责

Web 保留完整任务筛选、多草稿批量发布和后续复杂统计。uni-app 增加独立的机构/教师任务页，提供任务列表、单项创建、编辑、发布、学生进度和审核处理，不实现批量发布与复杂图表。

小程序机构管理员继续使用既有机构密码会话；教师使用相同的组织用户密码入口建立独立 MINIAPP 会话，但进入教师工作台。登录后由后端角色决定工作台，前端不接受外部角色参数。

### 3.2 权限与开关

V60 为 MINIAPP 客户端增加任务创建、管理查询、发布、审核、免执行和进度查看权限，分别授予机构管理员和教师内置角色。所有接口继续由 `LEARNING_TASK_MANAGEMENT` 后端开关失败关闭；小程序入口同时受公开能力和实时权限码控制。

Web 和小程序共用后端 DTO 与状态机，不共享页面代码、令牌存储或前端路由。

### 3.3 任务下发

机构任务可选择授权组织子树内的学校、班级或指定学生；教师任务只能选择本人活动班级或班内学生。一个任务选择多个目标即为批量下发，发布时去重展开学生并在单事务中生成实例。

Web 的多草稿批量发布继续使用每条任务独立事务并汇总失败结果；小程序只提供单任务发布。教师“接收机构统一任务”表现为查看授权班级内已经下发的机构任务及学生进度，不复制成新的教师任务，避免同一学生收到重复任务。

### 3.4 学生进度

新增管理任务进度分页接口。调用者必须先通过任务可读范围校验：创建者可查看自己管理的任务；授权班级教师还可查看本班已发布机构任务；家长只保留自家学生结果，不获得班级进度入口。

接口返回学生标识、脱敏账号、姓名、班级、任务实例状态、计划日期、认领时间、完成时间和最近状态时间。SQL 在分页前应用任务、班级和组织范围，范围外对象统一按不存在处理。

### 3.5 审核人失效自动转交

教师停用、锁定或解除班级关系前，系统锁定该教师负责的待审核任务并逐条选择接替人：优先同班其他启用教师，无可用教师时选择覆盖该班级的启用组织管理员。每次转交更新当前审核人并追加既有审核转交历史和任务事件。

若不存在合格接替人，原操作仍被阻止，避免产生无责任人的待审核任务。转交和教师状态或班级关系变更在同一外层事务内完成，任一环节失败全部回滚。

机构管理员失效和审核超时的跨模块自动转交留在后续账号生命周期与调度补齐，不在本专项扩大变更范围。

## 4. API

1. `GET /api/v1/learning-tasks/{taskId}/progress`：分页查询可见学生任务进度。
2. 既有 `POST/PATCH/GET /api/v1/learning-tasks`、`POST /{id}/publish`、审核和免执行接口开放对应 MINIAPP 权限，不新增重复移动端路径。
3. 既有 `POST /api/v1/auth/organization-sessions/password` 接受启用的机构管理员或教师组织账号，返回角色受服务端会话约束。
4. 新增 `GET /api/v1/teacher-workbench/context` 返回教师本人、实时权限码和活动班级摘要。

## 5. 数据与迁移

V60 不新增业务表，复用 `learn_task_assignment`、`learn_task_reviewer_transfer` 和 `learn_task_assignment_event`。迁移只新增功能权限种子、角色授权及必要索引；全部种子主键为 19 位雪花数字，不使用自增。

## 6. 验收边界

1. 机构管理员和教师可在小程序完成高频单任务操作，Web 批量发布保持可用。
2. 教师不能创建或操作其他班级任务，也不能查看家庭任务和家庭私有数据。
3. 机构管理员不能越过组织范围查看学生进度。
4. 教师失效时待审核任务有接替人则自动转交，无接替人则拒绝失效操作。
5. 后端测试、Web 测试与构建、uni-app 类型检查及 H5/微信小程序构建全部通过；不连接远程 MySQL、Redis、微信、共享测试、预生产或生产环境。

## 7. 实施与验证结果

V60 已完成教师小程序认证与工作台、机构和教师任务的独立小程序操作、学生级任务进度、机构任务共享可见，以及教师停用、锁定或解绑班级时的待审核任务自动转交。任务进度继续使用现有任务定义和学生实例，不复制机构任务数据；无合格接替人时，状态或关系变更事务整体回滚。

本地验证通过后端 152 个测试套件 561 项、Web 31 个测试文件 122 项、Web 生产构建、uni-app 类型检查、H5 构建和微信小程序构建。新增 Flyway 权限及授权种子均为 19 位雪花数字，未使用 `AUTO_INCREMENT` 或 `IDENTITY`。真实 MySQL、Redis、微信、共享测试、预生产、生产和业务 UAT 未执行，下一迁移从 V61 开始。
