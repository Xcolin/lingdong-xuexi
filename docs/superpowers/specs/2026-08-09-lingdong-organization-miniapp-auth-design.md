# 灵动伴随 V40 机构管理员小程序认证与工作台基础设计

## 1. 设计目标

为机构（学校）管理员建立独立的 uni-app 账号密码认证、会话存储和工作台基础，使后续转班、转学、机构关系维护等操作能够在小程序端安全落地。

V40 只解决机构管理员小程序身份基础，不实现转班转学、机构任务、考勤、复杂统计或机构微信快捷登录。Web 现有登录行为保持不变。

## 2. 需求与现状依据

1. 系统角色包含机构管理员，操作功能最终需要同时支持 Web 与小程序，复杂统计以 Web 为主。
2. Web 与小程序是两个独立前端应用，不共享页面代码和本地会话。
3. 当前 uni-app 只有家长和学生入口，分别使用独立会话存储；机构账号密码登录仅能签发 Web 会话。
4. V39 已完成统一设备会话、首次设备站内提醒、设备下线和安全事件，可直接复用于机构小程序会话。
5. 未成年人定位功能继续保持停用；V40 不新增定位、地图、轨迹或考勤代码。

## 3. 方案选择

### 3.1 采用方案

新增机构管理员专用密码登录端点，由服务端固定签发 `MINIAPP` 会话。请求不接收 `clientType`，避免调用方自行选择或扩大账号可登录终端。

### 3.2 不采用方案

1. 不扩展现有通用密码登录请求让前端提交 `clientType`，避免平台、家长或普通机构账号伪装为机构小程序身份。
2. 不在小程序复用 Web 会话或 Web 本地存储。
3. 不为 V40 新建另一套令牌模型，继续使用 `auth_device_session` 和统一令牌轮换逻辑。

## 4. 功能范围

### 4.1 本次实现

1. 机构管理员小程序账号密码登录。
2. 当前机构管理员身份和管理组织摘要查询。
3. 机构管理员小程序工作台。
4. 当前会话退出。
5. 复用 V39 设备列表、安全事件、指定设备下线和全部设备下线。
6. `ORGANIZATION_MINIAPP_AUTH` 功能开关及公开能力字段。
7. 家长、学生、机构三类小程序会话和设备标识完全隔离。

### 4.2 明确不实现

1. 机构微信快捷登录、微信账号绑定或外部消息通知。
2. 转班、转学、退学、机构关系停用和学生注销。
3. 机构任务、班级、教师、考勤或报表页面。
4. 平台管理员、系统审核员或教师的小程序登录。
5. 定位、地图、围栏、轨迹及对应权限声明。

## 5. 后端设计

### 5.1 Flyway V40

V40 只插入全局内置功能开关 `ORGANIZATION_MINIAPP_AUTH`，状态默认启用，标识使用19位雪花数字。V40 不新增业务表，V1-V40 仍为67张显式非自增 `BIGINT id` 主键表。

后续迁移从 V41 开始，不修改 V1-V40。

### 5.2 登录接口

新增公开接口：

`POST /api/v1/auth/organization-sessions/password`

请求字段：

| 字段 | 必填 | 约束 |
|---|---|---|
| `username` | 是 | 去除首尾空格后1至64字符 |
| `password` | 是 | 最大64字符，不写入日志 |
| `deviceId` | 是 | 最大128字符，仅用于服务端设备判定 |
| `deviceName` | 是 | 最大100字符 |

响应继续使用统一 `SessionResponse`，所有雪花标识按字符串传输。

登录必须同时满足：

1. `ORGANIZATION_MINIAPP_AUTH` 全局开关启用。
2. 用户存在且状态为启用。
3. 用户类型为 `ORGANIZATION`。
4. 用户具有启用的 `ORG_ADMIN` 角色。
5. 用户至少配置一个状态为启用的管理组织。
6. 密码匹配。

任一条件不满足均返回统一认证失败，不区分账号不存在、密码错误、角色缺失、组织关系缺失或组织停用。

### 5.3 会话与持续校验

1. 登录成功通过统一 `createSession` 创建 `MINIAPP` 会话，不复制令牌生成逻辑。
2. 首次机构小程序设备自动记录 V39 `NEW_DEVICE_LOGIN` 安全事件；同用户、同客户端、同设备不重复。
3. 刷新令牌和访问令牌认证都重新校验用户状态、用户类型、`ORG_ADMIN` 角色、至少一个启用管理组织及功能开关。
4. 用户停用、角色移除、全部管理组织移除、所有管理组织停用或功能关闭后，旧机构小程序会话立即不可继续使用。
5. 上述失效不改变机构账号的 Web 登录规则；Web 与小程序会话可独立撤销。

### 5.4 工作台上下文

新增认证接口：

`GET /api/v1/organization-workbench/context`

仅允许有效的机构管理员 `MINIAPP` 会话调用。响应包含当前用户标识、账号、显示名称和其直接管理的启用组织摘要。组织摘要只包含字符串标识、名称和类型，不返回完整组织树、其他管理员、用户列表或数据范围配置。

组织按组织路径、排序号和标识稳定排序；没有启用管理组织时，会话在认证层即失效，不返回空工作台。

## 6. 功能开关

公开能力响应增加 `organizationMiniappAuthEnabled`：

1. `client=MINIAPP` 时按 `ORGANIZATION_MINIAPP_AUTH` 返回真实值。
2. `client=WEB` 时固定返回 `false`，防止 Web 误用小程序入口能力。
3. 开关关闭后，小程序首页隐藏机构入口，登录接口与工作台上下文后端拒绝访问。
4. 认证过滤器在处理机构 `MINIAPP` 令牌时检查开关，使关闭前签发的旧令牌也立即失效。
5. 家长、学生和 Web 登录能力不受该开关影响。

## 7. uni-app 设计

### 7.1 独立会话

新增机构会话模块，固定使用：

- 会话键：`lingdong.organization.session`
- 设备键：`lingdong.organization.device-id`

机构登录、退出、设备全部下线只能读写机构键，不读取、覆盖或删除家长和学生会话。

### 7.2 首页入口

小程序首页在公开能力启用时展示“机构登录”入口：

1. 已有机构会话时进入机构工作台。
2. 无机构会话时进入机构登录页。
3. 能力停用时入口完全隐藏。
4. 家长和学生入口及既有会话判断保持不变。

### 7.3 登录页

机构登录页只包含账号、密码和登录命令。提交期间禁止重复操作；失败保留账号、清空密码并显示中文中性错误。登录成功后保存机构会话并重定向到机构工作台。

页面不提供家长验证码、学生登录码、微信授权、角色选择或客户端选择。

### 7.4 工作台

机构工作台展示：

1. 当前机构管理员显示名称和账号。
2. 当前直接管理的启用组织列表。
3. 账号安全入口。
4. 退出当前会话命令。

不展示尚未实现的转班、任务、考勤或统计入口。上下文请求认证失败时只清除机构会话并返回小程序首页。

### 7.5 账号安全页扩展

账号安全页身份参数由 `parent|student` 扩展为 `parent|student|organization`。机构身份只读取机构会话令牌；全部设备下线成功后只清除机构会话。

## 8. Web 影响

Web 仅同步公开能力 TypeScript 契约，不增加机构小程序入口，不改变登录页、路由或 Web 会话。现有 Web 构建和测试必须全部通过。

## 9. 安全设计

1. 登录接口和异常日志不得记录密码、访问令牌、刷新令牌或原始设备标识。
2. 登录失败使用统一状态和消息，避免账号、角色、组织关系枚举。
3. 机构工作台只查询当前用户直接管理的启用组织，不接受用户标识或组织范围参数。
4. 机构会话失效条件在每次令牌认证和刷新时重新检查，不能仅依赖前端入口隐藏。
5. 系统管理员、系统审核员、教师、家长、学生及无 `ORG_ADMIN` 角色的机构用户均不能使用专用端点。
6. V40 不扩大任何现有业务权限；后续小程序业务接口仍须分别校验动态权限、组织数据范围、业务对象和功能开关。
7. 动态权限决策必须把当前令牌客户端与权限目录的 `WEB/MINIAPP/BOTH` 一并校验，机构 `MINIAPP` 令牌不得复用机构账号已有的 `WEB` 操作权限。
8. 未知账号、错误类型、无角色或无组织关系仍执行一次同算法密码哈希比较，再返回统一认证失败，降低账号枚举时序差异。
9. 会话因持续校验失败而撤销时使用独立事务提交，外层刷新认证异常不得回滚撤销；审批停用机构小程序开关时批量撤销全部机构 `MINIAPP` 活动会话，机构 `WEB` 会话不受影响。

## 10. 异常处理

| 场景 | 处理 |
|---|---|
| 功能关闭 | 登录返回 `FEATURE_DISABLED`；旧机构小程序令牌认证失败；入口隐藏。 |
| 凭据或身份条件不满足 | 返回统一 `AUTH_REQUIRED`，不暴露具体原因。 |
| 工作台无有效组织 | 会话认证失败，小程序仅清机构会话并返回首页。 |
| 网络失败 | 保留当前页面和其他身份会话，显示中文网络错误。 |
| 退出接口失败 | 仍清除本地机构会话；服务端会话由过期和后续鉴权兜底。 |
| 全部设备下线失败 | 保留机构本地会话并提示重试。 |

## 11. 测试与验收

### 11.1 后端

1. Flyway 从空库连续执行 V1-V40，功能开关和19位标识正确，67张主键表无自增语法。
2. 正常机构管理员登录、刷新、认证、退出和 V39 首次设备事件通过。
3. 错误密码、平台账号、家长、学生、教师、无角色机构用户、无管理组织用户和仅管理停用组织用户统一失败。
4. 登录后移除角色、移除全部组织管理关系、停用全部管理组织或关闭开关，旧访问令牌和刷新令牌均不可用。
5. 工作台只返回当前用户直接管理的启用组织，跨用户、停用组织和完整组织树不进入响应。
6. WEB/MINIAPP 公开能力值正确，现有 Web、家长和学生认证行为不回归。
7. 机构小程序令牌调用 `WEB` 权限接口返回 `403 ACCESS_DENIED`，不得创建或修改业务数据。
8. 未知机构账号仍调用密码哈希校验；刷新认证失败后会话撤销状态独立提交，恢复资格或重新启用功能后旧令牌仍不可复活。
9. 审批关闭机构小程序开关会批量撤销机构 `MINIAPP` 活动会话，同时保留机构 `WEB` 会话。

### 11.2 前端

1. uni-app 类型检查、H5 和微信小程序构建通过。
2. 构建产物包含机构登录页、机构工作台、能力判断和机构独立会话键。
3. 构建产物不包含定位、地图、轨迹代码，不混用三类身份会话键。
4. Web 全量测试和生产构建通过。

### 11.3 环境边界

全部自动化验证继续使用本地 H2 和本地前端工具链，不对远程 MySQL、Redis、共享测试、预生产或生产环境执行迁移或写操作。真实微信、短信和业务 UAT 不计入 V40 完成。
