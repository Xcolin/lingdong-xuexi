# 菜单与按钮配置

用户已确认：独立菜单配置、复用现有权限，初始化全部管理端菜单和按钮，支持层级、启停与顺序。

- 新增 sys_menu 独立目录，节点类型 DIRECTORY/PAGE/BUTTON。字段包含 id/code/name/type/parentId/route/icon/permissionCode/sortOrder/status/version。页面绑定已有前端路由，按钮 code 绑定现有动作；配置不能生成不存在的业务功能。
- 管理 API `/api/v1/iam/menus`：读取、新增、更新；`PUT /order` 原子调整同父级顺序。版本号防并发覆盖。校验唯一编码、父级类型、循环引用、页面路由与按钮绑定；工作台和菜单管理入口保留避免配置锁死。
- `/api/v1/menus/current` 返回当前用户可展示节点：过滤停用节点与祖先、绑定权限；业务页面仍执行既有角色/功能开关检查，接口权限仍独立校验。
- 菜单管理树表采用统一紧凑布局、查询与重置同行、独立操作区、抽屉编辑，支持排序号与上移/下移。权限 MENU_READ/MENU_MANAGE 分别给平台管理员读写、审核员只读。
- 前端保留已实现路由注册表，将配置映射为侧栏和页签名称、层级及顺序。公共按钮适配器读取对应配置，控制名称、启停和顺序；配置失败显示可重试错误，不用旧默认菜单绕过配置。
- Flyway V87 创建结构与权限，V88 初始化现有页面与动作目录。真实数据库迁移后重启后端，实测菜单读取、排序、启停与按钮显示。
- 验证包含层级循环、权限、顺序并发、祖先停用、当前用户过滤，Web 树表编辑与按钮显示，以及原有布局与认证回归。
