# V63 复盘 PDF 统一执行与附件结果

## 本次范围

在原 `ExportJobExecutionService` 中增加 `GROWTH_REVIEW_PDF` 分支，复用已有队列扫描、状态版本领取、附件登记、业务关联、终态服务和失败清理。XLSX 分支仍使用原适配器、模板解析器和流式工作簿，不把 JSON 模板交给 XLSX 解析器。

## 执行顺序

1. 统一队列领取后，验证作业为生成中的复盘 PDF 类型、学生非空、非敏感导出且无系统审批任务，再复核固化范围和当前生成权限。
2. 文件生成组件读取固化内容，产生单份 PDF 或批量 ZIP，保持逐份和结束时权限检查。
3. 调用统一附件内容服务保存到 `EXPORT_JOB/REPORT_EXPORT`，创建 `EXPORT_JOB_RESULT/BUSINESS_AUTHORIZED` 业务关联。
4. 文件保存后再次校验当前生成权限。通过后调用原成功终态服务，结果数量以报告份数记入 `total_rows/processed_rows`；完成事件和成功状态沿用原事务。
5. 生成、保存、关联、复核或终态失败时，沿用原补偿流程解除已建立关系、退役已登记结果、删除已保存物理内容，并记录中性失败信息；不把报告正文写入日志。清理异常继续按原机制保留，不伪造成功。

## 数据与配置

新增 `V65__add_growth_review_pdf_job_type.sql`，扩展原作业类型检查，增加 PDF 学生对象及非敏感约束；不新增表。只为统一导出结果附件类别增加 PDF、ZIP 扩展名，不覆盖大小、启停、下载范围或其他类别的规则。两个新增种子使用 19 位标识，已存在对应扩展名时不重复插入。

内容存储和生成组件现在只接受正式 PDF 作业类型，不再使用积分台账类型承载测试 PDF 内容。新生成开关仍默认关闭；本次不开放创建入口。后续迁移从 V66 连续新增，业务工作包仍为 V63。

## 剩余边界

执行分支已进入原队列执行器，但正式 PDF 创建服务、HTTP 请求、模板选择页面、历史查询与受控下载仍未接通，不能把可执行的内部作业描述为用户已经能完整导出。附件保存仍服从配置的大小上限，生成器上限不覆盖附件规则。远程 MySQL、Redis、微信和生产联调未执行。
