# 全部按钮统一授权设计

用户已确认所有按钮包括查看详情、批准、驳回、查询、重置、取消均支持授权；历史数据不要求兼容，可删除重建，但本次采用新增迁移补齐，不删除业务数据。

所有BUTTON节点强制grantable=true且permissionCode=code。编码保留现有actionKey大小写和点横线，以免破坏组件绑定。新按钮同样规则，不允许创建无权限按钮。角色和用户树复用权限目录，无独立权限而置灰问题消除；继承、停用、DENY仍只读。后端current菜单仅返回有权限按钮，ConfiguredButton继续按current配置隐藏，原业务接口权限校验保持。

V98补齐全部按钮权限和节点标志，SYS_ADMIN具备配置操作权限；不为其他角色自动授予新按钮权限，按授权树配置。验证迁移全按钮映射、角色勾选、权限过滤、新增/编辑/批量、前端构建及真实服务健康和页面。
