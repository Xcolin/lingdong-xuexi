# 成长复盘页面迟到响应隔离

## 问题与范围

对应 V63-F 已有的旧请求回填检查项。主页面读取列表及详情时原来直接写入状态，切换周期后，上一请求仍可能清空当前报告或恢复旧报告。不调整业务统计、权限及导出规则。

## 实现

页面使用递增请求序号。重新加载、选择详情时建立新序号；范围切换及卸载时作废旧序号。异步列表、详情、错误提示与加载结束只允许当前序号写入。重新加载立即清除旧列表和详情，避免等待期间继续操作上一范围的报告。

补录提交保留原目标，不取消或重试已经发出的写请求；返回后的读取与页面反馈检查当前序号，避免把旧目标的结果回填到新范围。范围切换关闭补录窗口并重置表单。孩子选项加载也在卸载时忽略迟到响应。

## 验证

新增两个延迟 Promise 用例，分别验证旧列表和旧详情迟到，修复前均失败，修复后页面 7 项测试通过。类型检查、构建以及 1280px/390px 合成接口浏览器既有模板检查通过。浏览器检查不是远程后端或微信验收；本轮未执行前端全量测试。
