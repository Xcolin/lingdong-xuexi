# 学生首页今日任务（R04）

复用已有 `/task-assignments?scheduledDate=YYYY-MM-DD&page=1&pageSize=3`，按业务时区 UTC+8 取今日日期。首页显示服务端今日任务总数和前三项的任务名称、来源、当前状态，点击进入原任务详情继续认领、打卡等操作。这里的总数包含查询返回的全部状态，不称为待执行数；全部任务仍使用原学习任务入口。

进入和恢复页面时核对真实 MINIAPP 学生身份、当前读取权限和任务开关；没有机构的家庭学生同样使用本人查询。隐藏时清空并废弃旧响应，刷新和请求失败清空历史明细，失败不显示空任务结论。无需新迁移、统计公式或新业务接口。

验证脚本 `miniapp/scripts/verify-student-today.cjs` 使用合成会话和接口，检查日期参数、学生令牌、服务端总数、家庭来源、失败清空和动态权限撤回。构建和浏览器结果记录在当前执行计划；此脚本不代表微信真机验收。
