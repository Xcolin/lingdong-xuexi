# 菜单拖动与树形权限授权设计

## 菜单管理

树形拖动支持同级排序及调整父级，移除上移/下移按钮。目录可包含目录和页面，按钮只能属于页面；不能拖到自身子孙下，关键入口继续保护。保存采用后端事务和版本校验，冲突反馈后刷新，成功刷新当前菜单配置，左侧导航同步顺序和层级。

页面提供批量新增按钮抽屉，可逐行填写名称、编码、排序并一次提交；编码就是权限编码，自动生成/同步权限，取消手工选择另一权限编码。新增页面采用相同规则；目录作为导航分组。已有编码与权限映射按当前数据库规则兼容，不擅自删除既有角色授权。新配置动作需要绑定实际业务动作才能执行；配置本身不生成新的业务功能。

## 角色授权

角色授权改为菜单/按钮树复选框，勾选上级级联勾选所有可授权下级，取消同样级联；上级部分选中显示半选状态。选择角色后回显当前显式允许授权，保存统一批量提交，移除单条授予和单条撤销操作。

未归属菜单的现有业务权限归入其他权限分组，避免功能权限遗漏。树未勾选表示移除该范围内的显式允许，不自动新增拒绝；已有显式拒绝授权保留并展示，用户独立授权不随角色授权修改。

## 验收

拖动同级/跨目录与非法层级测试；批量新增原子失败与编码同步测试；父级级联、半选、角色切换不串数据、批量保存与保留范围外权限测试；构建与后端相关测试；真实页面验证导航随配置变化。
