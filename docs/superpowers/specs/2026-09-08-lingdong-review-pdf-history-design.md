# 复盘 PDF 历史查询与下载设计

## 范围

仅补既定 V63 的导出历史，不新增报表、角色、状态机或数据库表。沿用统一导出作业公开响应和附件读取服务，既有 XLSX 查询规则不变。

## 接口与流程

- 列表：GET `/api/v1/growth-review-export-jobs`，必填 studentId，可选 status，page 默认 1、pageSize 默认 20（最多 100）。先检查当前读取资格，再以申请人、学生和正式 PDF 类型共同限定 SQL，最后排序分页；总数使用相同条件。
- 详情：GET `/{id}`，加载正式 PDF 作业，检查原申请人及当前亲子关系，只返回公开作业字段，不返回内容快照、存储键或内部文件标识。
- 下载：GET `/{id}/download`，详情授权通过后，检查 SUCCEEDED、结果文件存在、有效 EXPORT_JOB_RESULT 关联、BUSINESS_AUTHORIZED 可见范围、文件所属模块/分类、上传人及 AVAILABLE 状态，再调用统一附件内容服务。
- 文件以 attachment 返回，中文文件名采用 UTF-8，明确 PDF/ZIP 类型，其他类型回退二进制；设置 no-store 与 nosniff。

## 权限和开关

每次请求复核 Web 身份、启用账号、当前家长角色、非系统审核员、动态 GROWTH_REVIEW_READ_CHILD 和 EXPORT_JOB_READ，以及有效主/副亲子关系。不能借另一个家长对同一学生的关系读取其导出历史。

新导出、数据导出及模板管理开关停用，不撤销合法历史读取资格；统一附件服务停用仍拦截。历史不重新读取当前报告、模板或全文载荷，不因这些生成依赖失效而失去已有文件。

分页参数错误返回 400；越权按既有权限异常处理；作业不存在、未成功或附件失效返回 404。无新增迁移，无远程数据库操作。

## 验证边界

本地 H2/MyBatis 与真实渲染、作业执行、附件服务覆盖开关停用后下载、关系撤销、跨申请人、SQL 分页隔离、状态筛选、关联释放/可见范围变化、文件退役及未完成作业。独立 MVC 测试仅验证 HTTP 绑定与下载响应头，不替代认证实网联调。前端操作仍在后续同一工作包接入。
