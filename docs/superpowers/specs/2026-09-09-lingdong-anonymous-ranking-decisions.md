# 班级匿名排行确认口径

## 已确认范围

原始素材 4.2.5.5 和 BRD 3.5.8：班级内排行，仅显示名次和积分，不显示学生真实姓名；家长只能查看自己孩子当前所在班级，默认关闭，主动开启后查看。不扩展学校、区域排行，不输出其他学生标识、头像、稳定匿名键或可识别明细。

## 已批准口径

原始要求未给出积分来源、周期、并列规则及“主动开启”是否影响参榜名单。用户已回复“按推荐推进”，确认以下规则：

1. 仅当前班级来源任务的累计净积分，奖励减纠错，不含家庭积分，兑换不减少排名积分。
2. 同分并列，名次按 1、1、3。
3. 主动开启只控制该家长查看，不改变参榜名单；当前在班学生参榜。

当前班级来源采用积分台账 source_organization_id 与该班级精确匹配，不取学校其他班级任务，不取学生全局积分账户替代。当前在班关系决定参榜名单；不迁移旧班级积分，重新加入同一班级仍按该班级累计口径，不另造“本次入班”周期。

## 当前实现边界

已开始实现内部 MyBatis 汇总：先限定启用班级与当前活动成员，排除停用学生，再按来源组织及 TEACHER/ORGANIZATION 的奖励、纠错台账汇总，用 RANK 实现 1、1、3，零积分成员保留。内部结果仅 rank、points，不返回学生标识或姓名。

现有 V26 约束只允许 FAMILY 纠错，当前没有机构任务纠错入口；本项不新增纠错业务，也不修改历史约束。家庭奖励及家庭纠错均排除。兑换和沉睡清零不进入汇总类型集合。

内部访问校验组件已实现：仅 WEB、有效账号、数据库当前家长且非审核员、动态 ANONYMOUS_CLASS_RANK_READ 权限、活动亲子关系及当前启用班级关系。19 位学生/班级标识校验在查询前完成；独立 ANONYMOUS_CLASS_RANK 功能未注册时按既有开关服务拒绝，不默认放行。该组件尚未与汇总和主动开启偏好组成公开查询流程。

后续增量已通过 V68 保存本人主动查看偏好，并将访问校验、偏好和汇总接到 HTTP 查询；具体设计见 `2026-09-09-lingdong-rank-query-design.md`。功能默认关闭，页面和班级选项仍待接入，不能将后端计作完整排行功能。前序访问组件 4 项和真实 H2/MyBatis 汇总 3 项联合通过，日志 `server/target/rank-access-tests.log`。微信模板参数仅阻塞微信对应子项，不阻塞排行。
