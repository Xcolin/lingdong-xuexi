# V63 复盘导出文件生成编排

## 范围

继续原始需求中单份和区间批量 PDF 导出。`GrowthReviewPdfArtifactService` 只接收生成中作业，从 `GrowthReviewExportPayloadStore` 读取并校验固化内容，调用已有中文 PDF 渲染器；不重新查询当前复盘，也不引入其他报表。

## 文件与权限

单份结果为 `application/pdf`，使用已有标准报告文件名。多份逐份生成 PDF，以 UTF-8 文件名打包 ZIP，包名为“灵动伴随-复盘批量-作业标识.zip”；包内各份仍使用标准报告文件名，保持固化选取顺序，不合并或丢弃报告。ZIP 只是多文件传输容器，不增加业务报告格式。

每份生成前及全部生成结束后重新检查当前生成权限和开关。任一报告渲染失败、关系失效或撤权均使整次生成失败，不返回部分文件。包内名称禁止路径分隔符、冒号和控制字符，重复文件名拒绝，不静默覆盖。

## 资源保护

`lingdong.growth-review-export.max-output-bytes` 默认 64MB，可配置为 1 至 128MB 的字节数。单份大小、批量 PDF 未压缩累计大小和实际 ZIP 写入大小分别校验；压缩输出在写入时限制缓冲区增长，不等完整包生成后再截断。沿用已有报告数、单报告文字和页数上限，不新增分页查询或改变统计口径。

## 实施边界

结果是内部文件名、内容类型、字节和报告数量，由后续统一导出执行流程接收。本次没有创建附件、结果关系或成功终态，也未注册调度分支和 HTTP 创建/下载入口。下一步必须复用原有附件保存、失败补偿和终态事务，不直接把字节公开为下载地址。

测试区分模拟渲染器的边界编排和真实 PDFBox 中文报告打包/解包读取；合成报告不含真实学生资料。不新增迁移，不连接远程 MySQL、Redis 或微信，业务工作包仍为 V63。
