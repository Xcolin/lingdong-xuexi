# 复盘 PDF 创建 Web 操作

## 既定范围

仅落实 V63 已有单份及区间 PDF 导出，不新增报告数据、自动评价或模板管理权限。创建调用已有异步作业接口，文件仍由后台生成并通过统一附件服务下载。

## 页面流程

1. 入口使用 Web 专用 growthReviewPdfExportEnabled 能力字段，同时要求家长、非审核员、复盘读取和导出创建权限。能力字段组合 PDF、数据导出、模板管理、附件服务四个生成依赖；小程序返回 false。原历史入口不依赖新导出开关。
2. 打开弹窗固定当前孩子和当前报告标识；有当前报告默认单份，否则默认区间。按孩子查询专用模板选项，展示名称和版本，只允许该模板的支持模式。无模板禁用提交，加载失败支持重试。
3. 区间选择日/周/月和起止日期，开始不得晚于结束；实际后端仍按完整周期范围选取。单份请求不携带区间字段，区间请求不携带报告标识。标识始终使用字符串。
4. 导出原因去首尾空白，必填且最多 500 字；提交中禁用编辑、关闭及重复提交。失败保留表单并显示服务端错误，不自动重试写请求。
5. 成功关闭弹窗并提示入队；有历史读取资格时自动打开所选孩子的历史抽屉，重新加载作业。切换孩子卸载旧创建状态，旧异步响应不能触发当前孩子的成功提示或历史刷新。

## 验证边界

专项覆盖单份载荷、空模板、倒置日期与区间互斥字段。浏览器脚本 `web/scripts/verify-review-export-create.cjs` 使用合成接口验证 1280px/390px 表单、单份/区间提交、历史自动打开和停用新导出后的入口隔离；不等同远程数据库、真实微信或业务 UAT 验收。截图保存于 `.local-verification/review-create-*`。

后端继续逐次执行完整对象鉴权、模板复核和生成依赖检查。公开能力字段只供前端呈现，不代替服务端授权。无新增 Flyway 迁移，未改动微信、账号初始化或远程配置。
