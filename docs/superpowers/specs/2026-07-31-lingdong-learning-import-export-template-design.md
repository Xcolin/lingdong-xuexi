# 灵动学习导入导出模板管理设计

## 1. 范围与边界

本模块实现 FSD-SYS-03 的模板类型、适用模块、版本、默认项和启停规则。模板文件复用附件管理核心的已完成文件元数据；本模块不定义具体业务导入字段、Excel/PDF 生成、导入任务逐行校验或导出数据口径。

当前未建设认证上下文和业务 REST Controller，因此仅提供后端应用服务与持久化。后续导入、导出任务必须引用本模块中启用模板的确定版本，历史任务和已生成文件不得因默认模板调整而被改写。

## 2. 数据模型与唯一默认项

Flyway `V14__create_import_export_template_table.sql` 新建 `sys_import_export_template`，使用应用层生成的 19 位雪花 `BIGINT id` 主键，主要字段为模板名称、模板类型、模块编码、版本、附件文件、默认标记、状态和审计时间。

模板类型固定为 `IMPORT`、`EXPORT`；状态固定为 `ENABLED`、`DISABLED`。`file_id` 必须关联 `AVAILABLE` 状态的 `sys_file`，但不要求或创建业务可见关系。

`default_scope_key` 与 `(module_code, template_type, default_scope_key)` 组成唯一约束：默认模板使用固定值 `DEFAULT`，非默认模板使用 `ID:<模板主键>`。因此同模块同类型在数据库层最多只有一个默认模板，不能只依赖并发不安全的查询判断。

## 3. 规则与流程

1. 系统管理员创建模板，必须填写名称、模块、类型、版本并关联已完成附件文件。
2. 创建默认模板或切换默认模板时，先撤销原默认模板，再将目标模板设为默认；历史模板记录和版本不更新。
3. 停用模板时清除其默认标记，停用模板不能被设为默认，也不能作为后续导入/导出任务模板。
4. 当前默认模板查询只返回启用且默认的模板；不存在时返回空，由后续业务任务提示管理员配置。

## 4. 验证边界

测试覆盖雪花主键、同模块同类型默认项切换、关联未完成文件拒绝、非系统管理员拒绝维护、停用后不能继续作为默认模板。真实导入、导出、脱敏、审批和历史任务模板快照由后续模块实现。
