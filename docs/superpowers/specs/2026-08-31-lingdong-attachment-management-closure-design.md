# 灵动学习附件统一管理闭环设计

## 1. 目标与范围

V54 在 V13 附件核心和 V31 任务打卡图片能力上，补齐附件规则管理、文件元数据台账、统一功能开关、动态权限、REST/OpenAPI 和 React Web 管理入口。现有任务打卡图片继续使用统一附件上传、预览、下载和软删除接口；小程序不增加平台配置页面。

本专项只声明本地实际具备的能力。继续复用 `AttachmentContentStorage` 存储端口和安全本地实现，不把真实云对象存储、CDN、病毒扫描、音视频转码或文档在线转换标记为完成。业务附件关系只能由具备业务上下文的应用服务建立，不提供可将任意文件绑定到任意业务对象的公共 HTTP 接口。

## 2. 既有能力与本次缺口

### 2.1 既有能力

- V13 已有附件规则、扩展名白名单、文件元数据和业务关系四张雪花主键表。
- V31 已为任务打卡图片提供 JPG/JPEG/PNG 内容特征校验、10 MB 单文件限制、最多 9 张、统一上传、受控预览、上传人临时文件软删除和业务关联。
- Web 任务审核和 uni-app 任务详情已经通过认证附件接口读取图片，不使用永久公开地址。
- `AttachmentContentStorage` 已隔离存储实现，本地存储键和实际文件路径不通过 API 返回。

### 2.2 本次补齐

- 附件服务总开关及前后端停用闭环。
- 附件规则查询、新增、修改、启用和停用。
- 文件元数据及业务关系只读台账。
- 明确的受控下载接口。
- 动态 RBAC、React Web 管理页面、OpenAPI 和完整本地验收。

## 3. 功能开关

新增全局功能开关 `ATTACHMENT_SERVICE`，默认启用。该开关控制统一附件服务，不只控制后台管理页面。

开关停用后：

1. Web 隐藏附件管理菜单，直达 `/attachment-management` 返回工作台。
2. uni-app 隐藏任务图片上传、预览和下载入口，不发起附件内容请求。
3. 后端拒绝附件规则查询和维护、文件台账查询、上传、元数据读取、预览、下载和临时文件删除。
4. 学习任务等父业务详情继续正常返回，但附件集合投影为空，既不破坏文字任务也不暴露附件元数据。
5. 已有关联关系、文件元数据和存储内容全部保留，不物理删除。
6. 学习任务文字打卡继续可用；只有依赖附件的操作停用。

公共能力接口新增 `attachmentServiceEnabled`，Web 和 miniapp 均按当前客户端获得结果。公共能力只用于入口裁剪，不能替代后端开关校验。

## 4. 角色与动态权限

V54 新增三个 Web 操作权限：

| 权限编码 | 用途 | 默认授权 |
|---|---|---|
| `ATTACHMENT_RULE_READ` | 查询附件规则 | 系统管理员 |
| `ATTACHMENT_RULE_MANAGE` | 新增、编辑、启停附件规则 | 系统管理员 |
| `ATTACHMENT_FILE_LEDGER_READ` | 查询文件及业务关系元数据台账 | 系统管理员 |

权限遵循现有 RBAC、客户端范围和 `DENY` 优先规则。系统管理员可将三项权限动态授予自定义运维角色；规则维护不固定校验内置角色。既有 `ATTACHMENT_UPLOAD` 和 `ATTACHMENT_READ` 继续控制业务附件上传与读取，不与后台配置权限混用。

具备文件台账权限只允许读取安全元数据，不自动获得附件内容查看权限。预览和下载继续执行所属业务对象的数据权限，平台配置权限不能绕过学生、家长、教师或审核人边界。

## 5. 附件规则流程

### 5.1 查询

按模块编码、文件分类、状态和规则名称查询，最多返回最近 200 条。每条规则返回字符串形式标识、模块、分类、名称、扩展名白名单、单文件字节上限、单批数量上限、是否允许预览、下载范围、状态、版本和更新时间。

### 5.2 新增

管理者填写模块编码、文件分类、规则名称、扩展名、大小、数量和预览配置。模块与分类统一转为大写，扩展名去除前导点并转为小写。同一模块和分类只能有一条规则；扩展名只能包含字母和数字，大小及数量必须大于零。

### 5.3 编辑

允许修改规则名称、扩展名、大小、数量和预览配置，不允许修改模块编码和文件分类。请求必须携带当前版本号；数据库按标识、版本和当前状态条件更新，版本冲突时返回明确错误。新配置只影响后续上传，不追溯删除历史文件。

### 5.4 启停

停用规则后禁止该模块和分类新增上传，但历史文件仍可按业务权限预览和下载。重新启用恢复后续上传。启停请求携带 `versionNo`；目标状态已经满足时返回当前规则作为幂等成功，否则按标识、当前版本和原状态更新，版本不一致时返回冲突错误。

## 6. 文件台账与内容访问

文件台账支持按原始名称、模块、分类、状态、上传人和时间范围查询，最多返回最近 200 条。返回文件标识、原始名称、扩展名、规范化内容类型、大小、上传人、模块、分类、状态、内容摘要是否存在、上传时间和创建时间，不返回存储键、实际路径或摘要原文。

文件详情可查询活动及已解除业务关系，返回关系标识、模块、业务对象标识、关系类型、可见范围、状态、创建及解除时间。台账只承担审计和排障，不允许从页面直接修改关系。

既有 `GET /api/v1/attachments/{id}/content` 保持受控内联预览。新增 `GET /api/v1/attachments/{id}/download`，复用完全相同的业务权限和内容读取流程，只将 `Content-Disposition` 设置为附件下载。两者都不返回永久地址，不接受客户端提供存储路径。

物理删除不在本专项开放。上传人仍只能软删除尚未建立业务关系的临时文件；已关联文件通过业务关系生命周期管理，保留元数据和审计记录。

## 7. 数据库与 Flyway

新增 `V54__add_attachment_management.sql`：

1. 为 `sys_attachment_rule` 增加 `version_no BIGINT NOT NULL DEFAULT 0`，用于并发控制。
2. 新增 `ATTACHMENT_SERVICE` 功能开关。
3. 新增三项 Web 动态权限及系统管理员默认授权。
4. 所有新增基础数据标识均为 19 位雪花数字。

V54 不新增业务表，不修改 V1-V53 历史迁移。下一迁移从 V55 连续新增。远程 MySQL、共享测试、预生产和生产库不执行。

## 8. 后端接口

新增后台接口：

| 方法与路径 | 权限 | 说明 |
|---|---|---|
| `GET /api/v1/attachment-management/rules` | `ATTACHMENT_RULE_READ` | 条件查询附件规则。 |
| `POST /api/v1/attachment-management/rules` | `ATTACHMENT_RULE_MANAGE` | 新增附件规则。 |
| `PUT /api/v1/attachment-management/rules/{id}` | `ATTACHMENT_RULE_MANAGE` | 按版本修改附件规则。 |
| `POST /api/v1/attachment-management/rules/{id}/enable` | `ATTACHMENT_RULE_MANAGE` | 携带版本号启用附件规则。 |
| `POST /api/v1/attachment-management/rules/{id}/disable` | `ATTACHMENT_RULE_MANAGE` | 携带版本号停用附件规则。 |
| `GET /api/v1/attachment-management/files` | `ATTACHMENT_FILE_LEDGER_READ` | 查询文件安全元数据台账。 |
| `GET /api/v1/attachment-management/files/{id}/relations` | `ATTACHMENT_FILE_LEDGER_READ` | 查询文件业务关系台账。 |

现有业务附件接口继续保留，并新增 `GET /api/v1/attachments/{id}/download`。所有标识按字符串序列化。后台接口和业务附件接口都必须独立校验 `ATTACHMENT_SERVICE`，OpenAPI JSON 继续位于受认证保护的 `/api/v1/openapi`。

## 9. React Web 与 uni-app

React Web 新增 `/attachment-management` 页面，使用“附件规则”和“文件台账”两个页签。规则页支持查询、新增、编辑和启停；文件页支持筛选、查看安全元数据和业务关系抽屉。无管理权限时隐藏写操作；无文件台账权限时不显示文件页签。页面提供加载、空态、错误重试、提交中、冲突反馈和宽表内部横向滚动。

uni-app 不增加平台配置页面。公共能力关闭时，任务详情隐藏图片选择、历史图片预览和下载入口；文字任务及文字打卡保持可用。构建产物继续不包含定位或地图能力。

## 10. 异常与安全处理

- 功能关闭统一返回功能停用错误，前端不保留可操作入口。
- 规则重复、版本冲突、扩展名非法、大小或数量非法均在写库前拒绝。
- 内容读取对不存在、已退役或无业务权限文件统一返回不可访问结果，避免泄露文件存在性。
- 下载文件名使用标准内容处置编码，不拼接本地路径。
- 接口响应、日志和页面不得出现存储键、真实文件路径、微信密钥、数据库密码、Redis 密码或第三方凭据。
- 文件台账权限不等于内容权限，不能通过管理页面绕过业务数据范围。

后端测试覆盖 V54 连续迁移、19 位种子、规则查询和完整生命周期、版本冲突、动态权限、功能停用、文件台账、关系台账、受控下载、无权访问及 OpenAPI。既有任务附件测试增加附件总开关关闭场景。

Web 测试覆盖规则查询、新增、编辑、启停、只读权限、文件台账、关系详情、菜单、直达路由和错误反馈。uni-app 覆盖能力关闭后不显示附件入口且不调用附件 API。

最终执行后端全量测试、Web 全量测试和生产构建、uni-app 类型检查及 H5/微信小程序双目标构建；完成桌面与 390px 窄屏视觉检查，以及雪花标识、敏感信息、定位能力、临时文件和补丁格式扫描。

## 12. 明确不纳入 V54

- 真实云对象存储供应商、CDN 域名和生产凭据。
- 病毒扫描、图片压缩、音视频转码和 Office/PDF 在线转换。
- 永久公开链接或绕过业务权限的管理员内容查看。
- 任意业务对象关系绑定 HTTP 接口。
- 已关联文件物理删除和存储生命周期清理任务。

以上能力需要供应商、保留周期、安全策略或具体业务模块确认后，以后续专项实施，不能通过空实现计为完成。
