# V63 复盘 PDF 导出授权边界

## 既定范围

只补充原始需求 4.2.5.3 的复盘导出授权及关闭新导出后的历史访问，不改变其他报表和既有 XLSX 作业的权限规则，不开放新接口。

## 新导出与执行

`GrowthReviewExportAccessService` 创建入口接受经认证的 Web 用户，使用数据库当前角色、账号状态和动态权限决策，不信任请求内角色列表。必须是有效家长，系统审核员即使兼有家长角色也拒绝。主副家长沿用既有复盘读取范围，均须存在活动亲子关系。

创建和后台执行要求 `GROWTH_REVIEW_READ_CHILD`、`EXPORT_JOB_CREATE`，并同时检查 `GROWTH_REVIEW_PDF_EXPORT`、`DATA_EXPORT`、`IMPORT_EXPORT_TEMPLATE_MANAGEMENT`、`ATTACHMENT_SERVICE`。后台从持久化范围取得申请人与学生，不依赖过期登录会话。内容固化服务已接入同一生成校验，内部调用不能绕过新导出开关和当前权限。

新增 V64 迁移只注册 `GROWTH_REVIEW_PDF_EXPORT` 全局功能开关，19 位雪花种子，默认停用；完整业务入口未验收前不默认开放。权限复用已有编码，不创建额外角色或扩大家长范围。

## 历史读取

历史读取必须是原申请人本人，使用当前有效账号、家长身份、`GROWTH_REVIEW_READ_CHILD`、`EXPORT_JOB_READ`、活动亲子关系，并要求统一附件服务启用。关闭新生成开关、通用新导出开关或模板管理，以及撤销创建权限，不单独撤销历史文件读取资格。

该规则只完成对象授权，不等于直接返回文件。后续统一下载流程仍须验证作业成功状态、结果附件存在、业务附件关系和文件状态；不得把持久化正文直接作为下载接口返回。该授权方法尚未接入历史查询页面与下载端点，不能声称前端已支持关闭新导出后的下载。

## 验证边界

授权测试覆盖新生成开关、动态撤权、主副关系、审核员排除、端隔离、他人文件和历史访问规则；真实 MyBatis 存储测试验证停用新导出后固化无写入。所有验证在本地完成，不操作远程 MySQL、Redis 或微信。数据库迁移已到 V64，后续迁移从 V65 开始；当前业务工作包仍为 V63。
