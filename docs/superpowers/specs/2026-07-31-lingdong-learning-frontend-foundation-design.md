# 灵动学习前端工程基础设计

**版本**：V1.0  
**日期**：2026-07-31  
**状态**：已实施并完成本地验证

## 1. 建设目标

在不混合 Web 与小程序前端代码的前提下，创建两个独立工程：

- `web/`：面向平台管理员的 React 管理端，第一轮接入已经实现并可闭环的登录、设备会话、角色权限和组织管理接口。
- `miniapp/`：面向家长、学生和教师的 uni-app 小程序工程基础。当前不创建微信登录、学生关系、学习任务或统计页面，因为这些后端能力尚未实现。

本轮不新增后端接口、不修改权限模型，也不把尚未存在的学习业务流程显示成可用功能。

## 2. 工程边界

### 2.1 Web 管理端

Web 使用 Vite、React、TypeScript、Ant Design、Ant Design Pro Components、Lucide React 和 React Router。工程只调用 `/api/v1` 内部接口；开发服务器通过 `/api` 代理转发到本地 Spring Boot，浏览器不直接跨域访问后端。

首批路由如下：

| 路由 | 功能 | 后端接口 | 可用条件 |
|---|---|---|---|
| `/login` | 平台账号密码登录 | `POST /api/v1/auth/sessions/password`、`GET /api/v1/auth/me` | 公开 |
| `/dashboard` | 当前身份与设备会话 | `GET /api/v1/auth/me`、`GET /api/v1/auth/devices`、会话下线接口 | 已登录 |
| `/iam` | 角色、权限目录的查询和新增，角色授权 | `/api/v1/roles`、`/api/v1/permissions`、角色创建和授权接口 | 后端动态 RBAC 放行且服务端为系统管理员 |
| `/organizations` | 组织类型、组织树查询与新增 | 4 个 V17 组织管理接口 | 后端动态 RBAC 放行且服务端为系统管理员 |

用户列表、编辑启停、角色权限详情、数据范围维护、组织编辑/启停/移动等接口尚不存在，因此不在首批菜单中展示为可完成操作。服务端返回 401 时清空本地会话并回到登录页；403、404、409 和参数校验错误在当前页面显示统一错误消息。

### 2.2 小程序端

小程序使用 uni-app、Vue 3 和 TypeScript，工程目录与构建配置独立于 `web/`。首轮只提供应用壳、页面注册、主题变量和 API 基础封装，不保存 Web 的 Bearer 凭证，也不调用未实现的微信登录接口。小程序的真实业务入口待微信登录、学生/亲子家校关系和学习任务接口完成后单独实施。

## 3. Web 数据流与安全

1. 登录成功后，Web 仅在 `sessionStorage` 保存访问凭证、刷新凭证和过期时间，随后请求 `/auth/me` 获取当前身份。
2. API 客户端为需要认证的请求加入 `Authorization: Bearer <accessToken>`；响应为 401 时清除本地会话并通知路由层回到登录页。
3. 访问凭证过期且刷新凭证仍有效时，客户端串行调用刷新接口后重放一次原请求；刷新失败时回到登录页。原始令牌不写入日志、页面 URL 或持久化数据库。
4. 前端菜单只作为体验层过滤，不能替代后端 `@RequirePermission` 与系统管理员校验。后端拒绝时，页面必须保持拒绝结果，不得在前端绕过。

## 4. 交互与视觉约束

管理端首先呈现可操作的登录或已登录工作台，而不是营销页。工作台使用紧凑的侧边导航、页头操作区、表格、抽屉和表单；新增操作采用明确的命令按钮，表单状态、加载状态、空状态和错误状态均可辨识。复杂统计在任务、积分、复盘等数据源完成后只进入 Web，不提前制造空报表。

## 5. 测试与验证

- Web 使用 Vitest 和 Testing Library。先验证认证存储、401 清理、刷新重试与页面级接口状态，再实现对应代码。
- 使用 Vite 生产构建验证 TypeScript、路由和资源打包。
- 通过浏览器在本地开发服务器检查登录页的桌面与移动端布局，不以本地前端测试替代后端 H2 回归。已登录页面需要本地后端服务和具备权限的测试账号后再完成端到端联调。
- 小程序首轮执行类型检查和构建；不访问共享测试、预生产或生产服务。

## 6. 后续衔接

下一后端阶段优先补齐组织数据范围 SQL 过滤和可管理用户列表等 API，再扩展机构管理员的 Web 操作范围。微信登录、学生与家长主体、学习任务、积分奖励和复盘接口稳定后，开始小程序的真实身份与学习闭环页面。
