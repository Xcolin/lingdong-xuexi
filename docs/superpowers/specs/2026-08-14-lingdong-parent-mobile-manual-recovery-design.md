# 灵动学习 V44 家长原手机号不可用人工核验换绑设计

## 1. 目标与边界

V44 为无法接收原手机号验证码的家长提供机构人工核验后的手机号换绑闭环。该能力不是普通自助换绑旁路，只允许活动学生所属机构的直接机构管理员在组织数据范围内操作，并由新手机号短信验证码证明新号码当前可用。

现有原始材料未规定身份证件种类、证明附件、双人复核或资料留存期限，因此 V44 不采集证件照片、不新增证明材料类型、不自行设定物理删除期限。系统审核员只审批系统管理员提交的系统任务，不审核机构业务换绑。没有活动机构关系的独立家庭不具备机构核验主体，本版本不开放人工恢复；其处理方式须在平台支持角色和核验规则另行确认后设计。

## 2. 启用与角色

1. 新增全局功能开关 `PARENT_MOBILE_MANUAL_RECOVERY`，默认停用；停用时 Web、小程序入口隐藏，后端候选、验证码和提交接口全部拒绝。
2. 新增 `BOTH` 权限 `PARENT_MOBILE_MANUAL_RECOVERY_MANAGE`，只授予 `ORG_ADMIN`。Web 与机构小程序使用独立页面和会话，业务结果一致。
3. 系统管理员、系统审核员、教师、家长、学生和无组织范围的机构管理员不能执行。RBAC 只控制入口，服务端还必须重新校验活动入学关系、管理员组织范围和活动亲子关系。

## 3. 业务流程

1. 机构管理员从本人管理的启用组织子树中选择活动学生，再选择该学生的活动主家长或副家长。候选只返回家长内部标识、匿名显示名、关系角色和脱敏手机号。
2. 管理员录入新手机号。系统校验目标家长为启用的 `FAMILY` 用户、具有 `PARENT` 角色、仍与该学生存在活动关系、新手机号与原号码不同且未被其他用户占用。
3. 系统使用独立短信用途 `MANUAL_MOBILE_RECOVERY_NEW` 向新手机号发送验证码；公共家长验证码接口不得接受该用途。
4. 管理员填写 1 至 200 字核验原因，并输入确认语句“已完成线下身份核验”。提交时再次消费新号验证码并重新执行全部范围、关系、用户状态、手机号唯一性和功能开关校验。
5. 服务端锁定目标用户。若目标账号存在活动注销申请，无论是否到期均拒绝人工换绑，避免与不可逆终结并发；须先通过已确认的账号生命周期流程处理该申请。
6. 成功后更新手机号；仅当用户名等于旧手机号时同步用户名。微信绑定、亲子关系和历史业务事实不变，目标家长全部活动会话撤销。
7. 同一事务写入不可变审计，保存 19 位雪花标识、家长、学生、核验组织、操作者、新旧手机号 HMAC 摘要、原因、客户端和发生时间，不保存手机号明文、验证码或证件材料。

## 4. 状态、并发与异常

V44 不建立长时间待审状态，机构管理员提交成功即完成换绑；线下核验责任由提交确认和不可变审计承载。短信验证码过期或错误、手机号占用、活动关系变化、组织范围变化、账号停用、活动注销申请和并发换绑均失败且不写部分数据。用户行锁、期望旧手机号条件更新和手机号唯一约束共同控制并发。

错误响应保持中性：对象或范围不符返回资源不可访问；验证码错误不区分目标账号事实；手机号状态冲突返回统一业务冲突。日志只允许记录审计标识、操作者标识和异常类型，不记录号码、验证码、原因全文或身份材料。

## 5. API 与端侧

| 方法与路径 | 用途 |
|---|---|
| `GET /api/v1/organization-parent-mobile-recoveries/candidates` | 返回当前机构管理员范围内可核验的学生和活动家长候选。 |
| `POST /api/v1/organization-parent-mobile-recoveries/codes` | 校验候选范围后向新手机号发送专用验证码。 |
| `POST /api/v1/organization-parent-mobile-recoveries` | 消费验证码并原子换绑、审计和撤销会话。 |

Web 在组织管理的学员关系工具中增加独立“家长换号核验”模式；uni-app 在机构工作台增加独立页面。两端均显示核验责任提示、脱敏旧号、新号验证码、原因和确认语句，不显示原手机号明文、验证码内容、微信标识或历史安全数据。

## 6. 验收重点

1. V1-V44 空库迁移成功，新增表主键为应用层 19 位雪花 `BIGINT` 且无自增。
2. 功能默认关闭；启用后仅机构管理员可见，Web 与 `MINIAPP` 权限均有效。
3. 跨机构、已转出学生、无活动亲子关系、停用或已注销家长、活动注销申请、占用新号、错误验证码和错误确认语句全部拒绝。
4. 成功换绑保留微信与业务关系，撤销目标家长全部会话，只保存号码摘要和不可变审计。
5. 独立家庭没有候选且不能调用提交接口；系统审核员不进入该业务流程。
