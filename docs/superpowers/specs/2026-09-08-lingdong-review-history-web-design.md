# 复盘导出历史 Web 操作

仅落实既定 V63 历史读取，不增加业务报表或家长管理权限。

成长复盘页面新增导出历史命令，打开抽屉后查询所选孩子的本人作业；支持状态过滤、每页 20 条分页、手动刷新，排队或生成中的列表每 5 秒刷新一次。仅成功作业可下载；详情展示公开字段和失败原因，不展示报告全文与文件存储标识。

入口要求家长角色、非审核员、GROWTH_REVIEW_READ_CHILD、EXPORT_JOB_READ 及附件服务启用，不要求新导出开关。后端仍逐次复核实际关系及动态授权；前端入口不能替代后端鉴权。

切换孩子以学生标识重新挂载组件，关闭抽屉使未完成动作失效；旧查询返回后不回填当前页面。查询失败清空列表并显示错误。下载复用统一登录刷新流程，保留 Content-Disposition 的 UTF-8 文件名，过滤路径及控制字符，释放临时对象 URL。旧 getBlob 使用方式不变。

桌面与窄屏沿用 Ant Design 抽屉和横向滚动表格，操作列固定；未新增菜单或小程序页面。浏览器脚本 `web/scripts/verify-review-export-history.cjs` 使用合成接口，验证 1280px/390px 详情、中文下载、新导出关闭后仍可读取与附件停用隐藏。

创建入口仍需专用模板选项接口。不得借用管理员模板管理列表、允许手输内部模板标识，或为家长扩大配置管理权限。此缺项属于原 PDF 创建链路，不扩展需求范围。
