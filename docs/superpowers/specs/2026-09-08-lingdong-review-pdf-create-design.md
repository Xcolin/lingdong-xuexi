# V63 复盘 PDF 创建入口

## 入口与范围

新增 `POST /api/v1/growth-review-export-jobs`，仅接受经认证且有 `EXPORT_JOB_CREATE` 权限的 Web 家长。申请人与请求来源从服务器认证上下文和请求地址取得，不接受客户端指定申请人。复用当前主副亲子关系、功能开关、动态权限、模板及内容固化检查，不新增角色、报表或迁移。

请求字段：`studentId`、`templateId` 为必填 19 位标识字符串；`mode` 必填 `SIMPLE` 或 `DETAILED`；`reason` 必填且最多 500 字。单份传 `reviewId`，区间传 `periodType`、`dateFrom`、`dateTo`，两种方式互斥，区间按完整报告周期选取。

## 事务与响应

应用服务以可重复读事务执行：参数校验、创建授权、请求来源 HMAC、报告选取、模板引用、创建 `QUEUED` 作业、固化全文及写入申请事件。固化服务再次验证模板模式与当前权限；任一步抛出异常时回滚同一事务，避免队列看见没有内容的作业。

接口返回 HTTP 201 和统一作业公开字段，包括字符串作业标识、类型、模板名称/版本、状态、数量、原因及时间；不返回内部选择快照、报告全文、来源摘要或存储键。PDF 内容仍在后台由原统一队列执行器生成，接口不直接返回 PDF 字节。

## 当前边界

创建服务和 HTTP 入口已落地，管理端/家长端模板选择、历史查询及受控下载尚未接通。不能让前端把通用 XLSX 详情接口当成已支持 PDF 的接口使用。新生成开关仍默认关闭，示例 JSON 模板也不等于已在业务库完成注册。

验证分为本地真实服务链路与 HTTP 绑定契约两类；后者使用测试身份解析，不代替认证安全联调。没有新迁移，下一迁移仍为 V66；未连接远程 MySQL、Redis、微信。
