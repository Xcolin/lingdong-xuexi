# 灵动学习 V33 按学生复制昨日任务设计

## 1. 目标与范围

V33 实现原始需求中的“复制昨日任务”功能：活动主家长在 Web 选择一个已绑定学生，将该学生昨日可管理的家庭任务逐条复制到今天；每日每名学生只能成功发起一个复制批次。任务模板、机构/教师批量下发、完整清单/增量模式切换和小程序家长端不在本版本范围。

本版本受 `LEARNING_TASK_MANAGEMENT` 总开关和新增 `COPY_PREVIOUS_DAY_TASK` 独立开关共同控制。独立开关默认启用；任一开关关闭时 Web 隐藏入口，后端拒绝预览、复制和重试。

## 2. 角色与数据范围

1. 复制入口只向 Web 端 `PARENT` 角色开放，并要求 `LEARNING_TASK_COPY_PREVIOUS_DAY` 权限。
2. 学生必须与当前用户存在活动主家长关系；副家长、教师、机构管理员、学生及系统角色不能使用本接口。
3. 候选任务必须为选定学生昨日的家庭任务实例，且任务创建人为当前主家长。机构任务、教师任务和其他家庭创建人的任务不进入候选集。
4. 每次预览、执行和失败重试都重新校验功能开关、客户端、RBAC、活动主关系和任务来源，不能只依赖前端状态或首次校验。

## 3. 日期、候选与同名规则

1. “昨日”和“今天”固定按 `Asia/Shanghai` 服务端自然日计算，客户端不得提交源日期或目标日期。
2. 候选集按昨日学生实例反查已发布任务定义；一个源任务最多进入批次一次，按任务标识升序稳定处理。
3. 复制不按昨日实例状态筛选。已完成、待审核、免执行等仍属于昨日清单；经 V32 自动顺延后计划日期已经迁到今天的实例不再属于昨日候选。
4. 若今天该学生已存在同名家庭任务，预览返回去重后的冲突标题。未确认同名时执行接口返回状态冲突且不创建批次；确认后允许复制重复标题。
5. 昨日无候选任务时返回空预览，执行接口不消耗每日一次额度。

## 4. 复制字段与新任务语义

每个成功条目创建新的 19 位雪花任务标识、目标标识和学生实例标识，并复制标题、难度、基础积分、执行时长、分类、标签、备注、审核超时及家庭来源。新任务：

- `generation_type=COPIED`，`origin_task_id` 指向最初来源任务；
- 计划日期为今天，状态直接为 `PUBLISHED`；
- 当前审核人为执行复制的活动主家长；
- 只创建选定学生的 `STUDENT` 目标和 `PENDING_CLAIM` 实例；
- 周期配置关闭，避免一次性复制意外生成后续日期任务；
- 不复制昨日实例状态、暂停、打卡、审核、顺延历史、积分台账或附件关系。

周期配置属于生成控制，不属于单日任务内容。复制任务使用新任务 ID，因此不继承原固定任务的连续完成衰减天数。

## 5. 批次、幂等与失败重试

新增复制批次与复制条目两张不可变业务过程表：

1. `learn_task_copy_batch` 以 `(student_id, target_date)` 唯一约束落实每日每学生一次，保存源/目标日期、操作人、同名确认、总数、成功数、失败数、状态和完成时间。
2. `learn_task_copy_item` 以 `(batch_id, source_task_id)` 唯一约束保存源任务、可空目标任务、标题快照、处理状态、失败码、失败原因、重试次数和最后尝试时间。
3. 批次先独立提交，再由应用服务逐条调用 `REQUIRES_NEW` 事务。单条成功立即生效，失败只更新本条，不回滚其他成功条目。
4. 重复提交同一学生当天复制请求时返回已有批次，不新建任务。失败项只能通过显式单条重试接口处理，成功项永不重放。
5. 单条重试重新锁定条目并核验状态；成功后更新批次计数与最终状态。服务异常信息转换为中性、可展示原因，不向前端泄露 SQL、路径或内部堆栈。

批次状态为 `PROCESSING`、`COMPLETED`、`PARTIAL_FAILED`、`FAILED`。条目状态为 `PENDING`、`SUCCESS`、`FAILED`。

## 6. API 契约

### 6.1 预览

`GET /api/v1/students/{studentId}/previous-day-task-copy/preview`

返回字符串学生标识、学生姓名、源日期、目标日期、候选数量、同名标题列表、是否已经复制及可空既有批次摘要。

### 6.2 执行

`POST /api/v1/students/{studentId}/previous-day-task-copy`

请求体为 `confirmDuplicateTitles` 布尔值。成功返回批次标识、总数、成功数、失败数、批次状态和条目结果；所有雪花标识均按字符串传输。

### 6.3 单条重试

`POST /api/v1/task-copy-batches/{batchId}/items/{itemId}/retry`

仅允许原批次操作人且当前仍为该学生活动主家长。只重试 `FAILED` 条目；成功条目、跨批次条目或状态变化返回 409，越权对象统一返回 404。

## 7. Web 交互

1. 家长学习任务页在任务管理视图显示“复制昨日任务”按钮，独立开关关闭、无角色或无权限时不显示。
2. 点击后先选择活动主关系学生并加载预览。无昨日任务时展示空结果，不出现无效确认按钮。
3. 有同名冲突时列出冲突标题并要求二次确认；无冲突时展示将复制的任务数量。
4. 执行期间按钮保持稳定加载状态。完成后显示“成功复制 X 条，失败 Y 条”，失败项展示任务名称和中性原因，并提供单条重试。
5. 小程序仍是学生执行端，不增加复制入口、管理接口或家长会话。

## 8. 测试与验收

必须覆盖：V1-V33 空库迁移、58 张显式非自增主键表、19 位初始化标识、功能开关、权限、主家长范围、昨日/今日时区、无候选不占额度、同名未确认/已确认、全字段与标签复制、新任务 ID、单学生目标、每日唯一、重复请求幂等、逐条部分失败、失败单条重试、成功项不可重放、连续衰减不继承、Web 入口/预览/确认/结果/重试，以及小程序无入口。

全部验证使用 H2 MySQL 兼容模式和本地前端工具链，不连接远程 MySQL、Redis、微信、共享测试、预生产或生产数据库。
