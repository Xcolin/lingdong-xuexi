# 管理端修改密码设计

入口位于右上角账号菜单，供当前已登录用户修改自己的密码，不接收目标用户ID。弹窗输入旧密码、新密码、确认新密码。复用现有PasswordPolicy：8—20位字母和数字组合；两次新密码一致，并禁止新旧相同。错误保持弹窗和输入，不显示密码明文。

增加认证接口，在事务内验证当前账号状态及旧密码，使用现有PasswordEncoder保存新哈希，并撤销该账号所有设备会话。成功清理Web本地会话、关闭缓存页面并回到登录页。登录账号原始密码不会因开发或验证而变更。

不新增左侧业务菜单，避免常用账号功能依赖可配置菜单被隐藏。界面沿用现有紧凑弹窗、独立操作按钮风格。

验证：旧密码错误、无效新密码、新旧相同不能写库；正常修改使旧密码失效并撤销会话；前端匹配校验、重复提交防止、失败保留输入、成功退出。构建、相关测试和真实页面入口验证。

备选：成功后保留当前设备会话，其他设备退出，使用更方便；推荐全部设备退出，行为清晰且复用现有会话撤销能力。

并发约束：Web、机构及家长密码登录与修改密码持有同一账号行锁直至事务提交，防止旧密码登录在改密完成后插入有效会话。旧密码等可预期错误采用专用400响应与明确提示，不触发令牌自动刷新。
