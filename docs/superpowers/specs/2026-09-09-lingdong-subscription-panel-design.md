# 周报订阅偏好页面

## 范围与入口

对应已确认 V63-D 页面与状态交互，复用成长复盘页面、本人订阅接口，不增加通知模块。公开能力新增 growthReviewSubscriptionEnabled，仅 WEB 且周报订阅、周期复盘两个功能同时启用时为真；缺失字段按关闭处理。入口还要求当前家长且非系统审核员。

默认业务开关不变，仍关闭，调度配置不变。当前页面管理的是系统订阅偏好，不获取微信消息授权，不宣称送达。微信模板和订阅类型未确认，真实消息链路仍待完成。

## 状态与权限

选择孩子后读取本人偏好；读取中和保存中禁用开关、刷新，避免重复写入。开启要求当前订阅和复盘读取权限；已经开启的偏好即使失去开启权限，仍可取消。功能关闭隐藏整个面板；后端保留已有取消接口的独立权限规则。

修改只提交状态和当前版本，不乐观显示保存成功。写入失败后显示错误并禁用再次修改，必须手动刷新读取当前版本。无自动重试写入，网络不确定结果同样重新读取处理。

以学生标识为组件生命周期边界；切换孩子或卸载时递增序号，旧读取、旧写入结果、旧错误不能回填新孩子。已提交的服务端写入不会因卸载被冒充撤销。
