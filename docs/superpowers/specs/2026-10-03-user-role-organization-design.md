# 用户、角色及组织管理设计

用户已确认角色列表授权/批量关联用户，用户授权与角色树一致；扩展组织管理员和组织成员维护，新增用户必须选择组织。

复用现有角色关联及权限决策，角色一对多关联不会复制权限数据。角色列表逐行授权，固定当前角色；关联用户抽屉分页查询及批量勾选，已有关系只读。用户列表逐行授权，树显示继承权限只读、用户额外ALLOW可编辑、DENY保留；统一保存具有用户锁/快照防覆盖。

组织节点提供成员管理抽屉，分页显示用户和管理员；可批量关联已有用户、设置组织管理员，以及在当前组织创建用户。管理员写入成员关联、组织管理员范围及ORG_ADMIN角色，使用事务并验证组织有效状态。新增用户organizationId必填，账号和组织关联事务提交。既有内部CreateUserCommand用于自动建档及测试保持兼容。

界面遵循当前一屏内部滚动、无静态说明、所有新增按钮可配置原则。新增Flyway版本，不修改已应用V96及以前迁移，不改真实角色授权测试数据，不提交历史工作区改动。
