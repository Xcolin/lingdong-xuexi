# V63-B 复盘 PDF 渲染设计

范围：实现日、周、月单份报告的纯渲染组件和安全文件名，供既有异步导出作业后续接入；不新增开放 HTTP 下载、独立文件存储或权限绕过。区间批量、作业、历史下载和开关按 V63-C 单独验收，本组件可用不等于用户已能导出。

输入为已完成对象授权的 GrowthReviewDetailView 与 SIMPLE/DETAILED 模板。核心内容来自同一不可变快照，详细版增加分类、每日趋势和已有补录。所有补录当纯文本处理，不解释 HTML，不加载外部 URL、不执行脚本，不生成 AI 建议。

采用 Apache PDFBox 3.0.8 与嵌入的 Noto Sans SC 中文字体；字体保留原始 OFL 许可与来源。按字形实际宽度换行，A4 固定页边距，自动续页与页码；不能编码的字符必须明确失败，不静默丢字。文件名保留学生、周期、起止日期，对路径分隔符及控制字符替换为下划线。

测试：中文提取及嵌入字体、简洁/详细字段区分、长段落分页、特殊文本不形成链接或脚本、路径字符安全、空明细可渲染。产出合成报告并渲染 PNG 检查布局。不修改 V1-V62，不为空渲染组件创建迁移。
