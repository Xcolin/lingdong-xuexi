# 灵动伴随 V56 通用导入校验作业设计

## 1. 设计目标

V56 在 V55 模板配置管理基础上，建设可复用的 Web 端导入校验作业，完成字段映射、受控文件上传、异步表头与逐行校验、结果台账和错误文件下载。

本专项只形成“可追溯的导入前校验”能力，不写入学生、任务、积分、考勤或其他业务事实。业务写入适配器必须在具体导入场景字段和幂等规则明确后另行接入，不能把校验完成解释为业务导入成功。

## 2. 需求依据与拆分结论

设计只使用以下已确认规则：

1. 所有导入业务统一使用模板配置管理中的模板，模板变更只影响新任务，历史导入记录保留原模板版本。
2. 导入遵循“上传、模板校验、逐行校验、处理结果台账”的异步或受控流程，每条数据成功或失败均可追溯。
3. 所有文件上传、下载和查看统一调用附件管理，不泄露存储路径或永久直链。
4. 批量导入和完整台账以 Web 为主，小程序不承载批量导入与模板配置。
5. 功能停用后入口全部隐藏，后端拒绝全部关联接口；历史作业和文件事实保留，重新启用后按当前权限恢复查询。
6. 所有新表使用应用层生成的 19 位雪花 `BIGINT` 主键，数据库变更通过 Flyway 连续迁移。

导入与导出具有不同数据源、状态机、权限和审批规则。敏感导出还涉及“仅系统管理员提交、系统审核员审批”的系统任务约束，因此 V56 不把导入和导出强行放入同一状态机。导出作业、敏感导出审批、脱敏和文件生成另设专项。

## 3. V56 范围

### 3.1 纳入范围

1. 为导入模板配置有序字段映射。
2. 使用统一附件服务保存待校验的 XLSX 文件和错误文件。
3. 创建导入校验作业并固化模板、字段映射、操作者和组织数据范围快照。
4. 后台异步领取并校验作业，支持多实例竞争下单次领取。
5. 校验工作簿、首个工作表、表头、必填、长度、数据类型和字典值。
6. 按数据行记录有效或无效结果，不保存整行原始敏感数据。
7. 为无效行生成受控 XLSX 错误文件，记录行号、列名、字段编码、错误编码和中文错误说明。
8. 提供作业列表、详情、进度、逐行错误和错误文件下载 API 与 React Web 页面。
9. 通过动态 RBAC、组织数据范围、功能开关和附件开关共同控制入口与接口。
10. 提供后续业务写入适配器的稳定端口，但 V56 不注册生产业务适配器。

### 3.2 不纳入范围

1. 不创建、更新或删除学生、任务、积分、考勤等业务记录。
2. 不实现部分成功业务写入、失败重试写入、业务幂等键或业务回滚。
3. 不实现 CSV、XLS、DOCX、PDF 导入。
4. 不实现异步导出、PDF 生成、敏感导出审批、导出脱敏或导出消息通知。
5. 不接入云对象存储、病毒扫描、宏检测和 Office 在线预览供应商。
6. 不在 uni-app 增加导入页面、路由、API 或管理入口。

## 4. 角色、权限与功能开关

新增全局功能开关 `DATA_IMPORT_VALIDATION`，默认启用。作业入口要求该开关和 `ATTACHMENT_SERVICE` 同时启用。

新增 Web 权限：

| 权限编码 | 能力 |
|---|---|
| `IMPORT_JOB_READ` | 查询授权范围内的导入校验作业、详情和错误文件。 |
| `IMPORT_JOB_CREATE` | 上传待校验文件并创建导入校验作业。 |

模板字段映射继续使用 `IMPORT_EXPORT_TEMPLATE_MANAGE`，不新增重复的模板管理权限。系统管理员默认获得三项允许授权；其他自定义角色由系统管理员按 RBAC 动态分配。

作业读取同时受权限和数据范围约束：

1. 系统管理员可读取全部作业。
2. 具有读取权限的普通用户只能读取本人创建且仍位于本人当前授权组织范围内的作业。
3. 作业没有组织范围时，仅创建人和系统管理员可读。
4. 任何角色停用、用户 `DENY`、组织授权撤回或账号停用都在请求时重新判断，历史快照不能扩大当前权限。

## 5. 模板字段映射

新增 `sys_import_export_template_field`，每条记录属于一个导入模板版本，核心字段如下：

| 字段 | 说明 |
|---|---|
| `id` | 19 位雪花主键。 |
| `template_id` | 关联 V14 模板记录。 |
| `field_code` | 模板内稳定字段编码，同模板唯一。 |
| `column_name` | XLSX 首行表头名称，同模板唯一。 |
| `data_type` | `TEXT`、`INTEGER`、`DECIMAL`、`DATE`、`DATETIME`、`BOOLEAN`。 |
| `required_flag` | 是否必填。 |
| `max_length` | 文本最大字符数；非文本字段为空。 |
| `dictionary_type_code` | 可选数据字典类型编码；配置后单元格值必须是启用字典项编码。 |
| `sort_order` | 表头和错误结果排序。 |
| `created_at`、`updated_at` | 审计时间。 |

字段编码只允许大写英文字母、数字和下划线，最大 64 字符；表头名称最大 100 字符。模板至少配置一个字段。文本最大长度为 1 至 1000；字典校验与布尔类型不能同时配置。

固定数据格式：

- `INTEGER`：十进制整数，不接受科学计数法。
- `DECIMAL`：使用半角小数点的十进制数，不接受千分位分隔符。
- `DATE`：`yyyy-MM-dd` 或 Excel 日期单元格。
- `DATETIME`：`yyyy-MM-dd HH:mm:ss` 或 Excel 日期时间单元格。
- `BOOLEAN`：`是`、`否`、`true`、`false`，英文不区分大小写。

字段映射只能配置在 `IMPORT` 类型模板上。创建新导入模板版本时，模板元数据、文件、文件关系和字段映射必须在同一业务事务中保存；任一步失败都回滚数据库并补偿物理内容，不产生“启用但没有映射”的新模板。已有作业引用模板后，字段映射不可修改；需要调整时必须创建新的模板版本。没有作业引用时，系统管理员可在模板停用状态下整体替换字段映射，替换时携带模板 `versionNo` 并使版本号递增。启用没有字段映射的 V55 历史导入模板时拒绝；历史模板可继续下载，但配置字段前不能创建校验作业。

## 6. 数据模型

### 6.1 导入作业表

新增 `sys_import_job`：

| 字段组 | 字段 |
|---|---|
| 标识 | `id`、`job_code`。 |
| 模板快照 | `template_id`、`template_version`、`template_name`、`field_mapping_snapshot`。 |
| 文件 | `source_file_id`、`error_file_id`。 |
| 范围 | `requester_id`、`organization_id`。 |
| 状态 | `status`、`version_no`、`failure_code`、`failure_message`。 |
| 进度 | `total_rows`、`processed_rows`、`valid_rows`、`invalid_rows`。 |
| 时间 | `created_at`、`queued_at`、`started_at`、`completed_at`、`updated_at`。 |

`field_mapping_snapshot` 使用 JSON 文本保存创建时的有序映射，仅由后端序列化和解析，不参与数据库 JSON 函数查询，保持数据库方言兼容。

### 6.2 逐行结果表

新增 `sys_import_job_row_result`：

| 字段 | 说明 |
|---|---|
| `id` | 19 位雪花主键。 |
| `job_id` | 导入作业标识。 |
| `row_number` | XLSX 中从 2 开始的数据行号。 |
| `status` | `VALID` 或 `INVALID`。 |
| `error_summary` | 该行中文错误摘要，最大 1000 字符。 |
| `created_at` | 结果时间。 |

同一作业和行号唯一。表中不保存整行原文、手机号、姓名或其他可逆敏感值；问题定位依赖原始受控文件、行号和错误文件。

### 6.3 文件关系

源文件使用 `IMPORT_JOB_SOURCE/IMPORT_VALIDATION` 关系，错误文件使用 `IMPORT_JOB_ERROR/IMPORT_VALIDATION` 关系。两个文件都通过统一附件元数据和内容存储端口访问，不向 API 返回 `storage_key` 或摘要原文。

## 7. 状态机与异步执行

作业状态固定为：

| 状态 | 含义 | 可流转状态 |
|---|---|---|
| `QUEUED` | 文件和快照已保存，等待后台领取 | `VALIDATING`、`SYSTEM_FAILED` |
| `VALIDATING` | 后台正在校验 | `VALIDATED`、`VALIDATION_FAILED`、`SYSTEM_FAILED` |
| `VALIDATED` | 表头正确且所有数据行有效 | 终态 |
| `VALIDATION_FAILED` | 表头或至少一行无效，已形成错误结果 | 终态 |
| `SYSTEM_FAILED` | 文件损坏、读取失败或内部异常 | 终态 |

V56 不使用 `SUCCESS`、`PARTIAL_SUCCESS` 等可能被误解为业务写入成功的状态。

调度器按配置周期扫描 `QUEUED` 作业。领取使用期望状态和 `version_no` 条件更新，只有更新成功的实例可以处理；不同作业逐项独立事务，单个作业失败不阻断后续作业。进度每批提交，重复调度不会重复插入同一行结果。系统异常只记录受限错误编码和中文摘要，不保存堆栈、单元格原值或第三方响应。

## 8. 校验规则

1. 源文件不能为空，必须为附件规则允许且文件扩展名为 `.xlsx`。
2. 工作簿必须至少包含一个工作表，只读取第一个工作表。
3. 第一行是表头；表头去除首尾空格后必须与字段映射完全一致，缺失、重复或未知列均失败。
4. 完全空白的数据行忽略；其余数据行按字段映射逐列校验。
5. 必填、长度、数据类型和启用字典项错误可以在同一行累计，错误摘要按列顺序输出。
6. 字典项在作业创建时解析为快照，校验过程中配置变化不改变当前作业结果。
7. 技术安全上限由后端配置 `lingdong.import-validation.max-rows` 控制，默认 10000 行；超出时作业进入 `VALIDATION_FAILED`，不截断后伪造完整结果。
8. Apache POI 必须启用压缩包膨胀比例、单条记录和工作簿大小保护；公式单元格不执行公式，只读取缓存结果，无法读取时按格式错误处理。

错误文件包含“行号、列名、字段编码、错误编码、错误说明”五列，不复制原始单元格值。错误编码固定为 `HEADER_MISSING`、`HEADER_DUPLICATED`、`HEADER_UNKNOWN`、`REQUIRED`、`TOO_LONG`、`TYPE_INVALID`、`DICTIONARY_INVALID`、`ROW_LIMIT_EXCEEDED`。

## 9. 应用服务边界

新增 `importjob` 模块，按以下职责拆分：

1. `ImportTemplateFieldService`：字段映射查询、整体替换、模板状态和引用校验。
2. `ImportJobApplicationService`：动态权限、当前数据范围、文件保存、模板与字典快照、作业创建、列表和详情。
3. `ImportJobClaimService`：单次领取和版本竞争。
4. `WorkbookValidationService`：XLSX 安全解析、表头和逐行校验，不访问用户会话或数据库权限。
5. `ImportJobResultService`：批量保存行结果、更新计数、生成错误文件和终态。
6. `ImportBusinessProcessor`：后续业务写入扩展端口；V56 仅定义契约，不注册生产实现，也不从校验作业自动调用。

解析器和错误文件生成器使用 Apache POI，不自行拼接 XLSX 二进制格式。

## 10. API 契约

模板字段映射：

- `GET /api/v1/import-export-templates/{id}/fields`：读取模板字段映射。
- `PUT /api/v1/import-export-templates/{id}/fields`：为未被作业引用的停用模板整体替换字段映射，携带期望模板版本号。

V55 的 `POST /api/v1/import-export-templates` multipart 契约增加 `fields` JSON 部件：导入模板必填且至少一项，导出模板必须为空。后端在创建事务中同时写入模板和字段映射。

导入校验作业：

- `GET /api/v1/import-jobs/options`：返回当前用户可选择的启用导入模板和授权组织。
- `POST /api/v1/import-jobs`：multipart 上传 XLSX，提交模板标识和可选组织标识，创建 `QUEUED` 作业。
- `GET /api/v1/import-jobs`：按作业编码、模板、组织、状态和时间筛选，默认每页 20 条，最大每页 100 条。
- `GET /api/v1/import-jobs/{id}`：返回模板快照、状态、计数、受限失败摘要和最近无效行。
- `GET /api/v1/import-jobs/{id}/errors`：分页查询无效行结果。
- `GET /api/v1/import-jobs/{id}/error-file`：受控下载错误文件；无错误文件时返回 404。

所有 19 位标识按字符串返回。列表、详情和下载每次都重新校验两个功能开关、动态权限和当前数据范围。任一开关停用后，菜单、页面、按钮和全部关联接口不可用；历史作业、行结果和文件关系只保留、不删除，重新启用后按当前权限恢复查询。

## 11. Web 交互

模板管理页的新增模板弹窗增加字段映射编辑区，仅在选择导入模板时显示。字段使用紧凑可编辑表格，可新增、删除、排序并配置表头、编码、类型、必填、长度和字典；导出模板不显示该区域。历史导入模板在停用且未被作业引用时可通过独立抽屉补齐映射。

新增 `/import-jobs` 页面，包含筛选区、作业台账和“新建校验作业”弹窗。作业状态使用文字和 Tag，进度使用稳定宽度进度条；详情抽屉展示模板快照、计数和分页错误，不展示原始敏感值。错误文件下载使用图标按钮和工具提示。

页面入口要求 `DATA_IMPORT_VALIDATION`、`ATTACHMENT_SERVICE` 和 `IMPORT_JOB_READ`；新建按钮另要求 `IMPORT_JOB_CREATE`。390px 视口下筛选和弹窗改为单列，宽表只在表格内部横向滚动。uni-app 公共能力不增加导入字段或页面。

## 12. 异常与补偿

1. 作业数据库写入失败时删除已保存源文件内容；删除失败作为 suppressed 异常保留，不能覆盖原始异常。
2. 解析失败后保留源文件和作业事实，状态为 `SYSTEM_FAILED`，便于授权用户排查和重新创建作业。
3. 错误文件写入成功但关系或终态更新失败时清理错误文件内容，事务回滚后作业可由恢复任务重新处理。
4. 字典、模板或权限在排队后变化时，校验使用创建快照；查询和下载仍使用当前权限。模板停用不取消已创建作业。
5. 功能开关关闭时不领取新的 `QUEUED` 作业；已进入 `VALIDATING` 的单个作业完成当前校验并写入终态，避免留下不确定状态。

## 14. 完成口径与后续边界

V56 完成后可以声明：模板字段映射和通用 XLSX 异步校验作业已本地闭环。不能声明：学员、任务或其他业务数据已完成导入。

后续业务导入适配器必须分别明确字段样例、数据范围、重复识别、幂等键、逐行事务、账号凭证一次性返回和失败重试规则。异步导出、敏感审批、脱敏、文件保留和通知按独立专项设计，继续遵守系统审核员只审批系统管理员系统任务的边界。
