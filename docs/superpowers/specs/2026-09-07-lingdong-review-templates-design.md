# V63-A 周/月复盘模板呈现设计

依据：原始素材 4.2.5.2 与已确认 V63 执行拆解。仅修改现有 Web 周/月报告呈现，不增加权限、接口、数据库、AI 分析或小程序复杂统计页面。

1. 周/月报告提供“简洁版、详细版”分段控件；默认为详细版，保持现有可见内容。日报保持原样，不出现模板控件。
2. 简洁版保留学生、周期、快照版本、完成率、获取积分、进行中、暂停及待优化核心值。详细版在此基础上展示现有分类、每日趋势和补录，不改变统计口径或快照。
3. 成长分析只用快照中的任务、完成及待优化数量描述事实。改进计划只展示已有 NEXT_PLAN 补录，没有则明确为空，不自动编造建议、不推断情绪原因。现有周/月快照若无补录，不创建新补录或擅自扩大补录期限。
4. 模板切换只改变本页呈现，不发请求、不写本地存储、不生成快照。切换日报仍显示完整日报；本页周/月选择保留，离页恢复默认。
5. 验收覆盖周/月双向切换、核心值不变、详细区隐藏/恢复、无额外 API 请求、日报无模板入口，以及桌面/390px 控件不溢出。

本项不代表 PDF、订阅、排行完成；后续 PDF 复用同一模板含义，不把页面隐藏视作权限裁剪。
