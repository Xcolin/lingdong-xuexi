# 管理用户密码及组织筛选设计

用户同意补齐初始密码和管理员重置，并要求用户管理增加所属组织机构查询条件。

平台/机构/家长账号创建时设置8至20位字母数字密码和确认字段，没有共享默认密码。创建、密码Hash和组织关联原子保存，密码不回显；学生保持独立学生登录码流程。沿用IAM_USER_PASSWORD_SET和POST/users/{id}/password，只允许系统管理员重置非注销非学生账号，重置后所有旧会话失效。用户列表提供带图标颜色的重置入口，密码弹窗关闭销毁值。已有无密码账号可通过重置设置。

组织筛选使用组织树，包括停用组织用于历史成员查询，选中组织只筛选直接关联用户，不默认包含下级。后端select和count均使用EXISTS成员关系，避免多角色/多组织造成重复用户；查询重置和翻页携带一致过滤条件。

V101新增密码操作菜单节点、复用已有权限，初始化SYS_ADMIN缺失授权。保留业务数据，本次不再次清空数据库。相关功能回归通过后打包、迁移、重启和登录验证。
