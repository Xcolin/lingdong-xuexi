# 复盘创建模板选项

属于既定 V63 PDF 创建链路，不新增模板管理权限或表结构。

家长创建表单不能使用管理员模板管理列表。专用 options 接口必须携带 studentId，按生成资格检查 Web 家长、非审核员、启用账号、活动亲子关系、读取/创建权限及生成依赖开关；拒绝时不读取配置附件。

复用统一模板存储，选择启用的 EXPORT/REPORT 配置，通过与创建校验相同的严格 JSON 解析器提取模式。非复盘配置、无效配置、失效附件不显示；数据库或存储系统故障继续报错。仅返回字符串模板标识、名称、版本和固定顺序的支持模式，不暴露原始文件或配置全文。

专用 SQL 同时要求附件 AVAILABLE，按更新时间和标识倒序取最多 200 条候选，沿用现有配置列表上限；解析失败的候选不补读其他页。创建时保留原来的版本和状态复核，不将查询结果作为永久授权。

配置可能在用户选择后变更，正式创建服务仍重新校验模板。没有可用模板时，前端应显示空选项并禁止提交，不自动注册模板、不允许手输内部标识。Web API 封装已补齐；创建弹窗随后接入。
