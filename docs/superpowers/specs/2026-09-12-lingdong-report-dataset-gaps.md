# R06 数据集与执行适配核对

依据《统计口径与报表设计》第 2–4 节与当前源码。这里只记录实际差距和复用边界，不以模板配置或页面数认定报表已实现。R04 其他角色操作仍在推进，R06 尚未整体完成。

## 已有执行能力

`ExportJobType` 当前仅有 `GROWTH_POINT_LEDGER`、`IAM_CHANGE_AUDIT`、`GROWTH_REVIEW_PDF`。前两项分别由 `GrowthPointLedgerExportAdapter`、`IamChangeAuditExportAdapter` 执行，PDF 使用已有专门报告快照与渲染流程。`ExportAdapterRegistry` 没有任意数据集动态执行能力。现有异步作业、受控列、字段脱敏、敏感审批及下载前权限校验应复用。

通用 `importjob` 已有 XLSX 格式/逐行校验、错误结果；实际学生写入由独立 `studentimport` 执行，不能把其他模板的校验通过当作业务已经导入。后续先对照既有 `StudentImportRowProcessor` 与相关回归验证幂等、逐行事务及一次性凭证；不重建学生导入。

## 报表逐项对应

| 设计数据集 | 当前执行适配 | 后续边界 |
|---|---|---|
| 权限变更日志 | 已有 IAM_CHANGE_AUDIT | 保留系统管理员提交、审核员审批和前后摘要脱敏 |
| 积分明细 | 已有 GROWTH_POINT_LEDGER | 保留家长关系、来源与下载时权限复核，不扩入机构家庭私有数据 |
| 家庭复盘 PDF | 已有 GROWTH_REVIEW_PDF | 复用不可变快照、历史授权与文件访问，不重复实现 |
| 系统任务审批台账 | 无通用导出适配 | 先完成 R07 任务载荷/范围，再导出类型、申请人、审核人、状态、时间、意见 |
| 附件管理台账 | 无适配 | 仅有业务权限的元数据；不得输出存储绝对路径、签名链接或绕过业务引用 |
| 缓存操作日志 | 无适配 | 系统管理员范围；类型、操作、时间、结果，不携带缓存内容 |
| 数据字典台账 | 无适配 | 类型、编码、名称、排序、状态、更新时间；按既有权限筛选 |
| 导入导出模板台账 | 无适配 | 模板元数据与版本，不能将模板载荷中的敏感信息原样导出 |
| 接口服务台账 | 无适配 | 名称、用途、调用方、范围、状态、责任人；绝不导出密钥 |
| 学生任务报表 | 无独立执行适配 | 家长按亲子关系；教师/机构按公开来源及授权范围，先固定失效/转班/顺延日期规则 |
| 奖励兑换报表 | 无适配 | 主家长家庭私有；使用兑换快照及真实扣分台账，申请数不等于消费积分 |

## 口径冲突与验证要求

当前 `GrowthReviewGenerationService.completionRate` 与 FSD 固化为 `已完成/(任务总数-进行中)`，分母不大于零取 0，免执行保留在分母。统计文档前部 R-001 仍写待确认，与后续实现/FSD 表述不一致；后续同步说明时记录这一差异，不擅改现有快照和公式。合成周报展示样例采用总数 10、完成 6、进行中 2、待优化 1、免执行 1，服务端完成率 0.75，前端只格式化为 75.0%。

R-002 活跃行为与阈值、R-003 综合成长得分、R-004 机构任务范围不能由前端自行补公式。已有原始完成、积分、暂停趋势可以复用；生成新的综合指标或机构汇总前必须确认已有需求是否已在后续设计中明确。

每个新执行适配必须固定字段、时间范围、分页、当前角色/组织范围和脱敏；覆盖执行前及下载前撤权、越权、空数据、异步失败和敏感审批。导入需区分整文件拒绝与逐行部分失败的事务边界。最终用同一固定业务样例核对数据库、接口、页面和文件，不只测试模板 CRUD。
