# 灵动学习 V28 成长复盘设计

## 1. 目标与范围

V28 建立学生日、周、月成长复盘的不可变事实快照、自动生成、受控补算、安全查询和当天/次日补录闭环，为后续 Web 趋势、小程序摘要、PDF 导出、周报订阅和匿名排行提供稳定数据源。

V28 不实现 PDF 文件生成、微信实际推送、匿名排行和积分生命周期扣减。积分衰减与休眠清零沿用同一 WBS 连续推进，但使用后续顺序迁移，不能修改 V28。

## 2. 已确认业务口径

1. 业务时区固定为 `Asia/Shanghai`。日按自然日，周按周一至周日，月按自然月。
2. 日复盘每日 21:00 生成当日初稿；周报每周一 00:00 生成上周；月报每月 1 日 00:00 生成上月。
3. 任务完成率为 `COMPLETED 数 / 非 IN_PROGRESS 任务实例数`。进行中任务只计进行中数量，不进入分母；分母为 0 时完成率为 0。
4. 累计获取积分只统计期间内 `TASK_REWARD.amount + CORRECTION.amount`，排除 `REDEMPTION` 和 `DORMANCY_CLEAR`，避免把消费和休眠处理误算成成长退步。
5. 暂停次数按暂停开始时间落入统计期间的记录数计算；待优化数量按任务实例当前状态为 `PENDING_OPTIMIZATION` 计算。
6. 周/月趋势按期间内每个自然日保存日粒度指标；任务类型分布按任务分类编码保存任务数和完成数。
7. 家长或学生可在复盘所属日当天及次日补录成长感悟、优缺点总结、次日改进计划。补录不限次数，每条独立留存，不覆盖历史；超过次日 23:59:59 拒绝。
8. 功能关闭后停止新生成、补算和补录，但学生本人和活动主家长仍可读取历史复盘。

## 3. 数据模型（5 张表）

### 3.1 `growth_review`

复盘逻辑主记录，字段包括 19 位雪花主键、学生、周期类型、开始/结束日期、当前快照标识、状态、创建和更新时间。`student_id + period_type + period_start + period_end` 唯一，重复调度只能复用同一逻辑记录。

### 3.2 `growth_review_snapshot`

不可变统计版本，字段包括复盘标识、版本号、任务总数、完成数、进行中数、待优化数、免执行数、完成率、累计获取积分、暂停次数、生成来源、数据截止时间和生成时间。`review_id + content_version` 唯一，补算生成递增版本并切换主记录的当前快照，不更新旧快照。

### 3.3 `growth_review_category_stat` 与 `growth_review_daily_trend`

两表均归属快照。分类统计保存分类编码、任务数和完成数；日趋势保存自然日及当日核心指标。全部主键使用应用层 19 位雪花标识，不能使用自增列。

### 3.4 `growth_review_supplement`

保存补录类型、正文、操作者、操作者角色和补录时间。正文去除首尾空白后为 1 至 1000 字；历史只追加不编辑、不删除。

## 4. 生成与补算

1. `GrowthReviewGenerationService` 接收学生、周期和明确的起止日期，读取任务实例、积分台账和暂停事实，计算快照后在单一事务内写入逻辑记录、快照、分类和趋势，并条件切换当前版本。
2. 自动调度按批次扫描期间内有任务、积分、暂停或既有复盘的学生；同一周期重复执行时，若事实摘要未变化则直接返回当前版本，保持幂等。
3. 迟到数据通过受控补算生成新版本。补算必须写生成来源和数据截止时间，旧版本永久保留。
4. 一个学生生成失败不能回滚其他学生；批处理逐学生使用独立事务并记录成功、跳过和失败结果。

## 5. API 与权限

1. 学生 `MINIAPP` 会话使用 `GROWTH_REVIEW_READ_SELF` 查询本人复盘，不接受学生标识。
2. 家长 `WEB` 会话使用 `GROWTH_REVIEW_READ_CHILD` 查询活动主关系孩子；跨学生统一返回 404。
3. 补录分别使用 `GROWTH_REVIEW_SUPPLEMENT_SELF` 和 `GROWTH_REVIEW_SUPPLEMENT_CHILD`。服务端从会话和复盘对象反查学生，不接收操作者、学生或周期字段。
4. 查询采用页码 1 至 1000000、每页 1 至 100；19 位标识全部按 JSON 字符串返回。
5. 教师、机构管理员、系统管理员和系统审核员不获得家庭复盘内置权限。机构统计后续使用独立公开来源聚合，不能复用家庭复盘接口。

## 6. 错误与安全边界

参数非法返回 `400 VALIDATION_ERROR`；角色、权限或客户端不符返回 `403 ACCESS_DENIED`；跨对象或复盘不存在返回 `404 RESOURCE_NOT_FOUND`；补录超时、版本竞争或非法状态返回 `409 STATE_CONFLICT`；功能关闭后的生成和补录返回 `409 FEATURE_DISABLED`。

所有统计 SQL 必须按学生和周期范围过滤并使用 MyBatis 参数绑定。接口不返回内部摘要、账户版本或真实班级排行身份，不记录补录全文到应用日志。

## 7. 验收基线

覆盖 21:00、周一 00:00、月初、跨月、空分母、重复生成、迟到补算、功能停用、跨学生、教师越权、补录截止和 19 位字符串标识。Flyway 必须从空库连续迁移至 V28，全部表主键显式为非自增 `BIGINT`。
