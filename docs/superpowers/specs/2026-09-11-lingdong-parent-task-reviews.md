# 小程序家长待审核任务闭环（R04）

按既有角色与端矩阵复用 `/task-reviews`；仅独立家长 MINIAPP 会话可进入本页。首页显示服务端 `total`，不把当前页条数当全部待办，也不声称覆盖奖励兑换等其他业务。

- 独立页面提供分页、详情、打卡文字和鉴权附件预览、审核通过及填写原因退回；家庭任务不依赖机构选择。
- 每次进入、恢复和操作前复核动态权限及功能开关；混合 SYS_AUDITOR 角色明确拒绝。隐藏页面使在途响应失效。
- 加载失败不显示假空态；提交失败保留退回原因，禁用旧操作，要求刷新。审核请求携带当前显示打卡的字符串 `expectedCheckInId`，由服务端锁后比较；前端提交前重读不能替代这个服务端检查。
- 家长令牌显式传入，不回退到学生/机构会话；附件令牌放在请求头，不放 URL。

验证入口：`node scripts/test-parent-task-reviews.cjs`（角色/功能/动态权限与过期响应）、`node scripts/verify-parent-task-reviews.cjs`（合成 H5 家长会话；首页总数、分页、详情、打卡 ID、冲突锁定、通过/退回、空态、功能关闭及混合审核员拦截）。后者用 PLAYWRIGHT_MODULE 指向本地 Playwright，MINI_URL 默认 `http://127.0.0.1:5175`。

本项不使用真实数据库或微信设备。H5 合成验证和微信构建不能替代真实小程序 UAT；六角色全工作台、家长奖励兑换待办等仍按 R04 矩阵后续推进。
