# V63 复盘 PDF 统一模板适配

## 范围

复用 `sys_import_export_template` 的文件、版本和启停管理，使用现有 `EXPORT` 类型、`REPORT` 模块；不新增模板表，不改既有 XLSX 模板解析器。模板通过受控文件声明本版本可用的简洁/详细模式，布局仍使用已有中文 PDF 渲染器，不增加任意排版编辑器或模板脚本引擎。

## 文件契约

示例位于 `docs/templates/成长复盘PDF模板-V1.json`。仅允许 `schemaVersion`、`reportType`、`templates` 三个字段，格式版本必须是整数 1，报告类型必须是 `GROWTH_REVIEW`。模式列表包含 `SIMPLE`、`DETAILED` 中的一项或两项，不允许空集、重复或未知模式。单文件最多 64KB。

未知字段、重复 JSON 键、第二份尾随文档、非对象根节点、不支持的版本以及不合法模式均拒绝。解析不执行 HTML、脚本或表达式，不下载远程 URL，不接受任意字体和布局指令。独立复制严格 ObjectMapper，不影响其他接口的序列化行为。

## 创建与固化

`GrowthReviewPdfTemplateService` 通过统一模板 Mapper 查记录，通过统一附件内容服务读取文件。创建必须核对模板类型、模块、启用状态、标识对应的名称和版本，以及所选模式是否在文件中声明；任一步失败都不固化报告内容。

`GrowthReviewExportPayloadStore.freeze` 已在生成授权之后、内容入库之前调用模板检查。固化内容原本就保存模板标识/版本及所选模式；执行时应继续用固化模式，不因后来修改默认模板而改变旧任务。不将当前默认 XLSX 模板自动当作 PDF 模板使用。

## 当前边界

本次只接通后端统一模板检查和内容固化入口。示例是本地文件，不代表已注册业务模板；上传仍须满足统一附件 `IMPORT_EXPORT_TEMPLATE/TEMPLATE_FILE` 的规则，不全局放宽扩展名限制。管理端文件选择、模板选择与正式 PDF 创建入口仍需后续接入，执行分支及用户下载尚未完成。

不新增数据库迁移，下一迁移仍为 V65；不变更其他报表、小程序或权限范围。不把 JSON 配置声明能力说成任意 PDF 版式设计能力。
