# 灵动学习功能开关核心实施计划

**Goal:** 建立后台功能启停的持久化与运行时判定能力，使功能开关优先于角色和数据权限，并让后端能统一拒绝停用功能的操作。

**Architecture:** 全局开关与机构范围开关存于同一表；全局关闭为绝对禁用，不能由机构级启用覆盖。业务模块通过`FeatureAccessService`判断或强制校验，不允许只依靠前端隐藏。全局开关变更审批将在系统任务执行处理器阶段接入。
