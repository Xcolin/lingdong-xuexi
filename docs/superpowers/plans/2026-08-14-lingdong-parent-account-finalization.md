# 灵动伴随 V43 家长账号最终注销与匿名化实施计划

> **执行说明：** 必须使用 `superpowers:subagent-driven-development` 或 `superpowers:executing-plans` 按任务执行；使用复选框跟踪状态。

**目标：** 对冷静期已结束且仍满足条件的家长账号执行不可逆终结、身份匿名化和会话撤销。

**架构：** 到期扫描只读取申请标识，单账号终结使用独立事务并锁定申请和用户。直接身份信息删除或匿名化，任务、积分、审核和关系历史继续引用内部用户标识；关系恢复时登记延后，功能停用时暂停执行。

**技术栈：** Spring Boot 3、JDK 17、Maven、MyBatis XML、Flyway、H2/MySQL 兼容 SQL、JUnit 5、Mockito、React/Ant Design、uni-app/Vue 3/TypeScript。
