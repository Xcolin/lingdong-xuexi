# 灵动学习系统高风险任务审核实施计划

**Goal:** 建立系统管理员提交、系统审核员审核的高风险系统任务工作流，为全局功能开关、敏感导出、缓存清理等配置变更提供统一审批台账。

**Boundary:** 仅处理系统管理员提交的高风险系统任务；不复用、不介入学习任务、积分、兑换或学生打卡的业务审核。审批通过只表示可以执行，具体配置生效由后续对应业务处理器完成。

### Task 1: 测试优先定义工作流

- [x] 创建系统管理员、系统审核员与普通家长测试数据。
- [x] 验证管理员可创建草稿并提交，审核员可通过或驳回，驳回意见必填。
- [x] 验证非系统管理员不能提交、非系统审核员不能审核、提交人与审核人不能为同一账号。

### Task 2: 迁移与持久化

- [x] 通过 V5 创建`sys_system_task`，保存任务类型、标题、说明、影响范围、提交人、审批人、审批意见和状态时间。
- [x] 扩展用户角色 Mapper，按角色编码验证提交人与审核人身份。
- [x] 使用 MyBatis XML 实现草稿写入、按主键读取和状态更新，禁止 SQL 拼接。

### Task 3: 应用服务

- [x] 建立任务类型、状态、不可变领域对象和命令对象。
- [x] 在事务内实施草稿创建、提交、通过、驳回状态流转与角色边界校验。
- [x] 为状态转换和审核隔离添加简洁的架构注释。

### Task 4: 验证

- [x] 运行系统任务专测。
- [x] 运行完整后端回归。
