# 灵动学习 V26 积分纠错闭环实施计划

1. 在 Flyway 集成测试中先声明 V26 迁移、功能开关、权限、主家长授权、纠错唯一约束、纠错检查约束和任务事件约束的预期。
2. 新增 `V26__add_growth_point_correction.sql`，调整台账唯一性并种入最小权限数据，确保全部主键为显式 19 位雪花数字。
3. 在后端集成测试中先覆盖成功纠错、整笔冲销、任务与打卡回退、审计留痕、重复纠错、超时、非本人奖励、机构学生越权、功能关闭和重新审核再次发奖。
4. 实现纠错命令、事务服务、锁定查询、账户扣减、台账工厂、任务/打卡回退、事件写入、控制器和响应模型。
5. 扩展积分台账查询契约，服务端计算主家长可纠错状态和截止时间，学生端始终不可操作。
6. 在 Web 测试中先覆盖能力开关、纠错按钮、确认表单、失败提示和成功刷新，再实现 API、类型与页面交互。
7. 同步 uni-app 小程序台账类型和纠错记录展示，不增加家长操作入口。
8. 更新 FSD、交互、HLD、数据库、Flyway、API、权限安全、测试、追溯和一致性核对等中文文档。
9. 执行后端全量测试、Web 全量测试与构建、小程序类型检查及双目标构建，并对 Web 桌面/移动视口和小程序移动视口做可视化核验。
