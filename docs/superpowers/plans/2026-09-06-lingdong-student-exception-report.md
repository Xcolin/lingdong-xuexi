# 灵动伴随 V61 学生异常报备实施计划

> **执行要求：** 按任务逐项使用 TDD 实施，复用现有组织范围、教师班级和学生班级事实，不连接远程环境。

**目标：** 完成教师异常报备、机构管理员处理、永久动作历史和本地消息事件出口的 Web 与 uni-app 闭环。

**架构：** 后端新增独立 `exceptionreport` 模块，主记录维护单向状态，只追加动作表保留永久历史，并在业务事务内写入待分发本地消息事件。Web 与 uni-app 使用同一 REST 契约，但保持独立页面和路由。

**技术栈：** Spring Boot 3、JDK 17、MyBatis XML、Flyway、H2/MySQL 兼容 SQL、React 18、Ant Design、Vue 3、uni-app。
