# 移动账号流程验收清单

## 账号与凭据

- Web创建的家长、机构、教师及公开注册账号均可按真实账号密码登录，学生专属登录不变。
- 邮箱和手机登录只能定位已验证绑定的既有账号；不存在时不会自动创建。
- 微信未绑定时让用户主动选择绑定已有账号或注册，绑定必须证明拥有已有账号。
- 禁止因联系方式匹配自动合并组织、角色或账号。
- 手机邮箱更换验证当前身份与新联系方式，已占用拒绝，保留可用登录途径。
- 初始密码和管理员重置密码需首次修改，后端约束与前端入口一致。
- 关闭、锁定、注销账号对各种登录方式行为一致。

## 移动端完成能力

- 注册、协议阅读、验证码、账号设置、首次改密、绑定更换、组织选择、入驻进度均无需Web跳转。
- 微信授权仅微信小程序显示；H5不显示无效按钮。
- 管理员重置入口按原有权限与组织范围，服务端再次校验；普通用户不可访问。
- 多身份会话刷新只更新同账号同旧令牌别名，不影响其他账号或组织选择。

## 样式与交互

- 登录与两步注册按已批准原型：深绿暖白、对齐的48px触控区域、紧凑品牌、当前方式提醒。
- 错误保持输入，重复提交防护，验证码倒计时，联系方式改变后清除旧验证状态。
- 第一步验证码未被后端验证时不得称已完成身份验证。
- 手机尺寸不横向溢出，键盘弹起可滚动操作；学生入口保留。
