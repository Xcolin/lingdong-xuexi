## 1. 口径说明

1. **六角色**：系统管理员（SYS_ADMIN）、系统审核员（SYS_AUDITOR）、机构管理员（ORG_ADMIN）、教师（TEACHER）、家长（PARENT）、学生（STUDENT）。自定义角色由 SYS_ADMIN 按最小权限原则配置，不改变六类内置角色的入口基线。
2. **判定规则**：功能开关优先于角色权限和数据权限（BRD §2.2 原则 4）；无权限或功能停用时，菜单、入口、页面、按钮、弹窗、操作项全部隐藏，且直达 API 被服务端拒绝（`FEATURE_DISABLED`→409、权限不足→403、范围外→403）。矩阵中"可见条件"列即该双重判定。
3. **数据范围口径**：SYS_ADMIN/SYS_AUDITOR 全局；ORG_ADMIN 按 `sys_organization_admin` 授权组织树（数据范围权限可再收敛）；TEACHER 按授权班级；PARENT 按亲子关系（主家长可操作，副家长只读）；STUDENT 仅本人。
4. **测试口径**：每条入口以"服务端集成测试 + 前端页面测试"核对，不以模拟调用认定闭环。

## 5. 缺口与结论（任务 3.2 已闭环）

1. **无机构学生独立使用**：✅ 已验证——家长独立创建的学生无任何 edu_student_organization 行，家庭功能可用、机构 API 403（`studentWithoutOrganizationUsesFamilyFeaturesOnly`）。
2. **角色动态变更**：✅ 已验证——用户停用即时撤销会话且旧会话不可复活（`userStatusChangeTakesEffectImmediately`）；角色移除后同会话立即 403、重新授予后恢复（`roleRemovalTakesEffectImmediately`）。
3. **组织范围**：✅ 已验证——移除机构管理员/用户-组织关联后直达学生 404、范围内列表不受影响（`organizationScopeChangeRestrictsAccessImmediately`）。
4. **功能停用双拒绝**：✅ 已验证——REWARD_EXCHANGE 停用后能力位 false（入口隐藏依据）且直达 API 409 FEATURE_DISABLED，恢复后 200（`featureDisabledHidesEntryAndRejectsApi`）。
5. **地理考勤/轨迹记录**：默认停用已落实；2026-09-29 任务 5.4 已确认保持关闭，从剩余范围移除，任务 7.3 UAT 需明列。
6. 覆盖结论：BRD 72 条功能拆解全部有落点（其中 2 条 ➖ 为默认停用项），Web 端 25 个入口、小程序端 33 个页面均建立“角色 ∧ 权限 ∧ 开关”三重判定；覆盖判定基于逐条功能对照而非页面总数。
