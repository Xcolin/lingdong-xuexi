# 灵动学习统计口径与报表设计

**版本**：V1.0（设计基线草案）  
**状态**：待评审  
**业务依据**：BRD 第 4 章；原始素材中的复盘生成与完成率规则仅在不冲突处补充  
**关联设计**：[FSD](01-功能详细设计-FSD-V1.0.md)、[数据库设计](04-数据库设计-V1.0.md)、[API 设计](06-API接口设计-V1.0.md)

## 1. 统计通用原则

1. 统计仅从用户有权访问的数据集计算，不得先聚合全量数据再通过前端隐藏。
2. 复杂统计、全量台账、复杂筛选和导出以 Web 为主；小程序只显示与当前角色相关的摘要和待办。
3. 所有时间范围按中国标准时间计算；日统计按自然日、周统计按自然周、月统计按自然月。明确生成时点的复盘按每日 21:00、每周一 00:00、每月 1 日 00:00 生成。
4. 功能关闭后不生成新的受控功能统计、复盘或导出；历史数据是否可读遵循 FSD 和具体功能开关规则。
5. 所有导出记录导出人、时间、筛选条件、范围、原因和文件；敏感导出须先有系统任务审批，并执行脱敏。

### 2.2 V27 兑换统计口径

1. 学生提交申请时不变更积分账户，因此不能按申请数推算已消费积分；兑换消费只统计状态已进入 `PENDING_VERIFICATION` 或 `VERIFIED` 且存在唯一 `REDEMPTION` 台账的数据。
2. 兑换台账固定 `amount=0`、`available_delta=-required_points_snapshot`。累计总积分不因兑换减少，可用积分在主家长同意时减少；驳回、自动驳回和到期均不产生扣分台账。
3. 奖励名称、所需积分和描述以兑换快照为历史口径，不能通过关联当前奖励值回算；当前奖励被编辑、下架或逻辑删除不改变历史报表。
4. 待办数只统计 `PENDING_APPROVAL`；待核销数只统计 `PENDING_VERIFICATION`；已核销数只统计 `VERIFIED`。按状态分组时不得把 `REJECTED`、`AUTO_REJECTED`、`EXPIRED` 合并为已消费。
5. 家庭奖励和兑换只对主家长及学生本人展示，教师和机构统计不得通过统一积分账户或学生标识反推、汇总或导出家庭私有奖励。

### 2.3 V29 积分生命周期口径

1. 固定任务连续天数按同一任务标识、学生、来源类型、来源主体和相邻计划自然日计算；同标题的新任务或复制任务不合并连续天数。
2. 第 1 至 7 天实发比例为 100%，第 8 至 15 天为 80%，第 16 天起为 60%；台账同时保留基础积分、实发积分、衰减比例、连续天数和命中规则标识。
3. 纠错后的原奖励从连续历史中排除；纠错后重新审核形成的新奖励按其计划日期参与计算，统计报表以不可变台账实发值为准。
4. 沉睡天数从任务有效操作、非休眠清零积分变动和用户主动复盘补录三类事实的最后发生时点计算。登录、查看、自动生成复盘、提醒创建和清零自身不计活跃。
5. 第 30 天清零只减少可用积分，累计总积分不变；`DORMANCY_CLEAR` 不计入累计获取积分，也不作为下一沉睡周期的活跃事实。
6. 第 27 天提醒记录按学生和沉睡周期去重。`PENDING` 只代表待消息系统投递，`NO_RECIPIENT` 代表当时无活动主家长，两者都不能统计为送达。
7. V30 每日固定计划只负责生成任务实例；统计继续以实例计划日和最终状态为事实。停止计划不删除已生成实例，未生成的未来日期不得补记为任务总数或未完成数。
8. V31 图片附件不新增任务完成事实。打卡次数按 `learn_task_checkin` 提交记录计数，不按附件数量计数；图片大小、数量和格式只进入附件管理台账，不改变任务完成率、连续完成或积分口径。
9. V32 顺延迁移同一任务实例的 `scheduled_date`，不在来源日期继续计入任务总数、待优化数或完成率分母；迁移后从目标日期事实集中统计。顺延不产生积分、完成或打卡事实。
10. V33 复制成功后以新任务和新实例计入目标日期统计，不回写昨日统计，不继承来源任务完成、打卡、暂停、顺延或积分事实；复制批次成功数和失败数属于过程审计，不计作学生任务完成数。
11. V34 模板本身不是任务事实，不进入任务总数、完成率、积分、复盘或排行。只有选用模板后通过现有流程创建并发布的新任务，才按其计划日期和目标学生进入统计。
12. 已生成的日/周/月复盘快照保持不可变。顺延造成历史期间事实变化时，后续受控重算以新版本快照反映，并保留旧版本，不直接改写历史快照。

### 2.4 2026-09-28 已确认的业务口径

用户已明确采用以下四项规则。确认口径不等于对应页面和报表已实现，实际交付以执行计划及验证结果为准。

| 编号 | 指标 | 已确认规则 | 实施状态 |
|---|---|---|---|
| R-001 | 免执行任务与完成率 | 分母为任务总数减进行中数再减免执行数；分母为 0 时取 0。免执行仍作为事实数量展示。 | 日/周/月及每日趋势本地验证通过；历史快照不覆盖，受控重算产生新版本。 |
| R-002 | 学员活跃度 | 当天至少一次任务认领、打卡、有效任务操作或主动复盘补录计活跃；登录及自动积分变动不计。 | 服务端聚合 API 已实施，行为集合与范围口径见 2.7 节，固定业务样例集成测试通过；看板呈现接线属角色看板任务。 |
| R-003 | 成长趋势 | 分别展示完成率、积分、待优化数和暂停次数，不生成综合分。 | Web 四项每日趋势、小程序家长周报摘要本地验证通过；真实设备验收仍待进行。 |
| R-004 | 机构统计范围 | 仅已生成的机构公开任务实例，按计划日期和实例来源班级归属；未下发生成实例的不计，转班不改历史归属。 | 机构任务统计数据集已实施（详见 2.5 节）；转班不改历史归属已由固定业务样例集成测试核对通过。 |

原有历史快照保持不可变，受控重算因口径或事实变化生成新版本；不得静默覆盖历史报表。除上述已确认变更外，不扩充状态排除或发明综合指标。

### 2.5 2026-09-29 机构任务统计数据集固化口径

2026-09-29 用户确认以下四点，作为机构任务统计数据集（`ORGANIZATION_TASK_STATISTICS`）实施口径：

1. **行粒度与归属**：每行按任务实例来源组织（`learn_task_assignment.source_organization_id`）聚合，展示所属学校（按组织路径上溯 `SCHOOL` 节点）与来源组织名称；仅统计 `source_type='ORGANIZATION'` 且任务已发布（`learn_task.status='PUBLISHED'`）的已生成实例，家庭与教师来源排除；来源组织在发布时固化，转班不改历史归属；来源组织已停用则不参与统计。
2. **指标公式**：任务数为计划日期范围内实例数；完成数为已完成实例数；完成率按 R-001 公式（已完成/(总数-进行中-免执行)，分母为 0 取 0）以百分比保留两位小数输出；已失效（`INVALIDATED`）实例排除在任务总数与完成率分母之外；平均积分为已完成实例的净积分（`TASK_REWARD` 与 `CORRECTION` 台账合计，与学生任务报表积分口径一致）的平均值，无完成实例时取 0。
3. **导出角色与筛选**：仅机构管理员可创建导出，范围限定授权组织树；筛选支持计划日期范围（`scheduled_date`）与授权范围内的来源班级；区域/学校维度由授权组织树限定，不提供跨树筛选。
4. **脱敏与快照**：输出仅含学校、班级组织名称与聚合计数，不含学生个人字段，无需姓名脱敏；创建时冻结授权来源组织集合与实例主键上界，执行与下载前复核角色、组织授权与功能权限，撤权后拒绝旧文件；支持 Excel 与 PDF。

### 2.6 2026-09-29 考勤台账数据集固化口径

2026-09-29 用户确认四身份沿用与事实台账行形态，作为考勤台账数据集（`ATTENDANCE_LEDGER`）实施口径：

1. **行粒度**：每行一条 `attendance_record` 事实（班级×学生×上海自然日唯一），输出学生姓名（双姓名脱敏）、班级名称、考勤日期（业务日期，不用创建或更新时间替代）、考勤状态（NORMAL/LATE/EARLY_LEAVE/ABSENT/LEAVE）、签到时间与签退时间；更正动作历史不进入导出；不计算出勤率、应到人数或跨班级人数相加。
2. **导出身份与范围**：沿用考勤台账四身份范围——机构管理员按授权组织树内班级、教师按授权班级（两者创建时冻结班级集合，执行与下载前复核当前有效班级包含冻结集合）；家长按活动亲子关系（不要求主家长）、学生本人按 `edu_student.student_user_id`（两者创建时必须指定 `studentId`，执行与下载前复核关系仍有效）；系统审核员兼任拒绝；依赖 `ATTENDANCE_MANAGEMENT` 开关、`ATTENDANCE_READ` 与新增 `ATTENDANCE_LEDGER_EXPORT` 权限。
3. **筛选**：教师与机构管理员可选授权范围内班级；家庭身份必须指定本人学生；日期区间映射 `attendance_date`；学校维度由授权组织树限定，不提供状态筛选或跨树筛选；其他数据集筛选字段一律拒绝。
4. **脱敏与快照**：学生姓名按 FAMILY_NAME_STAR 脱敏，`sensitive_flag=0` 不走敏感审批；创建时固化班级集合或学生身份与实例主键上界；支持 Excel 与 PDF。

### 2.7 2026-09-29 学员活跃度聚合固化口径（R-002）

2026-09-29 用户确认行为集合与服务端落点，作为 R-002 实施口径：

1. **行为事实**：学生本人任务事件 `CLAIMED`、`CHECKED_IN`、`PAUSED`、`RESUMED`、`ABANDONED`（`learn_task_assignment_event.occurred_at`）与学员复盘主动补录（`growth_review_supplement.supplemented_at`，编辑者为学生或家长，均为学员复盘事实）计活跃；审核驳回、审核转交、免执行设置属他人行为不计，积分账本变动（自动产生）与登录不计。同一学员同日多次行为按一人计。
2. **归属与范围**：按学员当前 `ACTIVE` 班级关系（`edu_student_organization` relation_type='CLASS'）归属授权组织树；任务来源不限（家庭、教师、机构任务的学员主动行为均计）；仅机构管理员（ORG_ADMIN）可查，数据范围沿用组织数据范围服务，非机构管理员拒绝。
3. **聚合与呈现**：按业务日（事件时间转日期）输出去重活跃学员数；参数为日期区间，缺省取近 30 天；不计算活跃率，不与考勤出勤混算。呈现为机构管理员看板活跃度趋势（Web 完整、小程序摘要），看板接线属角色看板任务；本节仅固化服务端聚合。

## 5. 成长复盘数据集

### 5.1 日复盘

| 项目 | 规则 |
|---|---|
| 生成 | 每日 21:00 自动生成当日初稿；受每日复盘功能开关控制。 |
| 指标 | 当日任务完成率、积分获取总量、情绪暂停次数、待优化任务数；进行中和免执行任务不计任务完成率分母。 |
| 补录 | 家长/学生可补充成长感悟、优缺点总结、次日改进计划；仅当天及次日内，补录标记需保存。 |
| 关闭状态 | 停止新复盘生成，保留历史复盘查询。 |

V28 固化口径如下：完成率分母原为“任务总数减进行中数量”，2026-09-28 R-001 确认后再减免执行数量，分子为已完成数量，分母为 0 时完成率为 0；累计获取积分只合计期间内 `TASK_REWARD` 与 `CORRECTION` 的 `amount`，`REDEMPTION` 和未来 `DORMANCY_CLEAR` 不计入获取积分。任务分类来自任务快照分类，暂停次数来自期间内暂停事实。免执行数量保留在事实展示中，但不纳入完成率分母。

### 5.2 周/月复盘

| 项目 | 规则 |
|---|---|
| 生成 | 每周一 00:00 生成上周；每月 1 日 00:00 生成上月。 |
| 指标 | 任务完成率、累计获取积分、任务类型分布、待优化任务占比、情绪暂停频次、成长趋势曲线。 |
| 模板 | 简洁版展示核心数据；详细版包含数据明细、成长分析和改进建议。 |
| 导出 | 支持单日、单周、单月和指定时间段；PDF 功能关闭后隐藏新导出入口，历史文件按权限可查看。 |

V28 已实现自然周、自然月快照和每日趋势数据，但“简洁/详细模板”、指定时间段报告、PDF 文件生成和订阅投递尚未实现。每次生成对统计事实计算 SHA-256 指纹：指纹不变时复用当前版本，迟到事实导致指纹变化时新增连续版本并更新逻辑复盘的当前快照指针，历史版本保持不可变。

## 6. 数据刷新与性能边界

1. 待办、任务状态、积分余额、消息状态等需实时读取的指标从业务事实表或受控缓存读取。
2. 日/周/月复盘、趋势、匿名排行、机构汇总等可通过定时生成或快照加速；快照须带生成时间和统计范围，不能掩盖数据延迟。
3. 大数据量导出使用导出任务，不在同步请求中生成长时间文件；完成后通知用户下载。
4. 每个报表接口必须限制时间范围、分页/聚合粒度和数据范围，防止通过超大筛选或跨组织聚合规避权限。
5. V35 二维码票据属于短时认证安全数据，不进入学习任务、积分、成长复盘、机构统计或业务报表；后续登录安全报表只允许按脱敏聚合结果统计，不导出原始票据或摘要。

## 10. V36 认证数据报表边界

验证码、验证码摘要、访问令牌、刷新令牌、来源地址摘要和设备标识不进入业务统计或导出。后续如建设登录安全报表，只允许按时间、客户端、结果类型和脱敏区域进行聚合，不允许反推出完整手机号或原始认证凭证。协议版本接受数量和首次引导完成率属于运营安全指标，不并入学习任务、积分或成长复盘口径。

## 11. V37 微信认证统计边界

V37 不新增业务报表。微信临时凭证、`session_key`、绑定票据、完整 `openid`、完整手机号和设备标识不得进入统计快照、导出或运营报表。后续安全运营如需统计，只允许基于调用时间、脱敏结果类型、绑定成功/失败数量和客户端进行聚合；绑定关系明细仅用于受控安全审计，不并入学习任务、积分和成长复盘口径。

## 12. V38 家长关系统计边界

V38 不新增业务报表或改变既有任务、积分、奖励和复盘口径。主副关系变更只影响当前访问范围和家庭待审核任务的审核人，不重算历史业务事实；关系邀请标识、完整手机号、验证码、来源地址和设备信息不得进入统计或导出。后续关系运营统计只能使用脱敏聚合数量，关系明细仅供具有权限的安全审计。

## 13. V39 账号安全统计边界

V39 的事件列表属于当前用户操作视图，不是复杂统计报表，不改变任务、积分、奖励或复盘口径。后续安全运营统计只允许按事件类型、客户端、风险级别和时间区间聚合；不得导出用户令牌、原始设备标识、设备摘要或内部范围键。安全事件明细默认不进入普通业务报表。

## 14. V40 机构工作台统计边界

V40 工作台的直接管理组织列表属于身份上下文，不是统计报表，不新增指标、导出或历史重算。机构复杂统计继续限定在 Web 端；小程序不得据此自行汇总跨组织业务数据。登录凭据、令牌、原始设备标识和组织管理员关系明细不得进入普通业务报表。

## 15. V41 学生机构关系统计边界

转班和转出不重算历史任务、积分、考勤或复盘事实。历史机构统计继续按业务事实发生时保存的来源组织和班级口径归档，新班级只从关系生效后接收新任务。小程序学员关系页属于操作页面，不提供复杂统计；变更原因和操作者明细只用于受控审计，不进入普通班级报表或家庭数据导出。

## 16. V42 账号生命周期统计边界

手机号换绑和注销冷静期不重算任务、积分、奖励、复盘或组织历史事实。换绑审计只可用于受控安全追溯，不得导出手机号摘要、票据或验证码；注销状态属于账号操作状态，不作为已注销用户统计。只有后续最终注销执行成功后，才可按另行确认的业务口径计入注销数量和匿名化结果。

## 17. V43 最终注销统计边界

账号只有在申请状态成功写入 `FINALIZED` 后才可计入最终注销数量；处于冷静期、已撤销、因活动关系延后或技术失败的申请均不得计入。终结不重算任务、积分、奖励、审核、复盘或组织历史指标，历史报表继续按事实发生时的内部用户标识归档并以匿名名称展示。普通导出不得包含原用户名、手机号、微信标识、终结错误详情或会话信息。

## 18. V44 人工换绑统计边界

V44 不改变任务、积分、奖励、复盘或组织统计口径，也不新增普通业务报表。人工换绑审计仅供受控安全追溯；如后续形成运营统计，只能按组织、客户端、日期和成功数量聚合，不得导出手机号摘要、核验原因、家长或学生明细。

## 19. V45 学生注销统计边界

V45 不改变历史任务、积分、奖励、复盘、机构或家长关系事实的统计归属，注销学生仍以稳定 `student_id` 保持历史外键完整。普通页面不得展示注销审计明细；如后续形成合规统计，只能按组织、客户端、日期和注销数量聚合，禁止导出原因、操作者、学生标识或匿名化前身份。活跃学生指标必须排除 `edu_student.status = 'CANCELLED'`。

## V48 班级停用统计边界

V48 不新增复杂统计页面、指标或报表公式。班级停用保留历史任务、打卡、积分、教师关系和学生关系事实，不重算已经完成或免执行的任务；`INVALIDATED` 是业务终态，必须与完成、免执行和进行中状态分开呈现。具体完成率、机构统计和报表分母仍以既有已确认口径为准，V48 不擅自修改；后续报表开发必须明确记录是否以及如何展示失效任务。

## V49 权限统计边界

V49 不新增业务统计指标、报表或导出。角色与用户显式权限列表是当前配置查询，不是不可变审计台账，也不能用于还原历史权限。后续权限变更审计专项应保存操作人、主体类型、主体标识、权限标识、变更前后效果、时间和结果，并仅向系统管理员提供受控 Web 查询；普通业务报表不得包含授权明细。

## 通用组织数据范围统计边界

统计和导出必须复用服务端解析的组织范围，空范围不得返回全局零值以外的明细或聚合，`SELF` 只能统计对应业务对象本人数据。当前专项未改动既有统计公式，也未把全部报表查询迁移完成；复杂统计接入时仍需逐项验证跨区域、跨学校和跨班级聚合边界。

## V50 权限变更日志口径补充

权限变更日志以 `sys_iam_change_audit` 一行为一次成功提交事件，按 `occurred_at/id` 倒序。当前 Web 查询不是业务统计报表，也不提供导出；前后值只统计非敏感枚举状态。未来报表工作包若增加导出，必须继续执行 `IAM_AUDIT_READ`、字段脱敏和数据保留策略。

## 统一访问边界统计说明

本专项不改变指标公式。跨组织列表裁剪结果证明后续统计和导出必须在服务端复用相同范围；当前尚未据此宣称全部报表查询完成接入。

## V51 数据字典统计说明

当前页面是配置维护工作区，不新增业务指标、统计口径或导出。类型和字典项列表包含停用历史数据以支持追溯；后续数据字典台账与导出仍归 WBS-08，必须复用 `DICTIONARY_READ` 并执行脱敏和导出权限校验。

## V52 缓存管理统计说明

V52 不新增经营或学习指标。缓存操作台账保留缓存域、类型、结果和时间，可作为后续运维报表事实来源；当前页面仅展示最近 200 条，不等同于统计报表。后续成功率、失败率、平均执行耗时和审核时长需要单独定义时间窗口、去重及失败分类后实现，不能直接从当前页面行数推导。

## V53 接口服务管理统计说明

V53 不新增经营或学习指标。接口调用台账可作为后续服务可用性报表事实来源，当前 Web 只展示最近受限条数，不等同于统计报表。后续调用量、成功率、失败率、耗时分位、调用方排行和告警指标必须明确时间窗口、重试去重、超时分类和脱敏规则后实现；当前表没有耗时字段，不得据此推导性能指标。

## V54 附件台账统计说明

V54 不新增学习任务完成、积分或经营指标。文件台账每行代表一个受管文件事实，业务关系台账每行代表一次关系状态事实；附件数量不得替代打卡次数，已解除关系不得删除历史。当前 Web 最多查询 200 条安全元数据，不等同于附件统计报表或导出。后续容量、类型分布、失败率和存储成本指标必须先定义时间窗口、重复文件处理、退役口径和权限范围，且不得导出存储键、摘要原文或未脱敏个人信息。

## V55 模板台账统计说明

V55 不新增学习、经营或导入成功率指标。模板列表每行代表一个配置版本，可按类型、模块和状态筛选，但列表行数不等于导入次数、导出次数或业务处理量；默认标记只表示后续执行选择，不改变历史事实。当前 Web 最多查询 200 条安全模板元数据，不是统计报表，也不提供导出。后续导入成功率、错误分类、导出耗时和下载量必须基于独立执行任务及审计事实定义时间窗口、重试去重、失败归因、脱敏和数据权限后实现。

## V56 导入校验作业统计说明

作业台账中的总行数、已处理行数、有效行数和无效行数只表示一次文件校验结果；`VALIDATED` 不表示业务数据已创建、更新或生效，因此不得据此计算学生导入成功率。逐行结果按作业和行号唯一，重复调度不重复计数；`SYSTEM_FAILED` 与 `VALIDATION_FAILED` 必须分开统计。当前 Web 提供分页操作台账和进度展示，不是复杂统计报表。后续业务导入率、重复数据率、写入耗时和失败归因必须基于具体业务适配器的独立事实、幂等键、重试口径、时间窗口和数据权限另行定义。

## V57 异步导出作业统计说明

导出作业的总行数和已处理行数只表示一次异步生成进度，不是业务指标；`SUCCEEDED` 表示文件生成成功，不表示文件已下载、已使用或数据已被人工确认。创建时捕获数据标识上界，计数和分页均限定在该上界，作业执行期间新增事实不计入本次文件。重复调度依靠状态、版本和事件终态避免重复计数。

V57 只落地积分台账和权限变更审计两个数据集，不能据此认定 14 类报表完成。当前不统计导出成功率、下载率、耗时分位、存储量或角色排行；如后续建设，必须明确时间窗口、重试去重、取消与失败归因、下载审计、保留期限、脱敏和组织数据范围。权限审计导出本身属于受控操作事实，不得与 IAM 变更数量混为同一指标。

## V58 学员批量导入统计说明

执行总数、成功数和失败数以一次唯一校验作业对应的业务执行为口径；失败重试更新同一行事实，不新增导入人数，最终成功数与失败数互斥。`VALIDATED` 仍只表示校验通过，只有 V58 行状态 `SUCCEEDED` 才表示开户完成。当前页面为操作台账，不形成跨学校成功率、耗时、排名或经营报表；凭证下载状态不得作为学生首次登录完成指标。

## V60 任务进度口径说明

V60 学生进度列表以任务实例为最小事实，每个学生展示当前状态和关键时间，不新增汇总快照。机构管理员总数为授权任务下可见实例数，教师总数还受当前有效班级关系裁剪；二者因数据范围不同不可直接比较。机构任务对教师可见不产生重复任务或重复实例。当前能力是操作明细，不代表完成率趋势、班级排行、教师绩效、跨校对比或复杂报表已经完成，这些指标仍需在后续统计专项中定义时间窗、去重、状态口径和数据权限。

## V62 人工考勤口径说明

台账最小事实为班级、学生、上海自然日三元组合；更正后的五种状态互斥，动作次数不得计入考勤人数，同一学生跨班级不能不经去重直接相加为人数。记录日期为业务日期，不用创建或更新时间替代。列表总数与列表使用同一实时数据范围。

无排班和应到名单快照时，“未登记”不等于“缺勤”，不得将活动学生总数作为历史应到人数计算出勤率。请假只是人工结果，不表示已有请假审批。V62 只提供可筛选事实台账，不实现出勤率、教师绩效、跨校对比、Excel/PDF、订阅或复杂考勤统计；这些仍归 V64-V65。

## V61 异常报备口径说明

V61 台账以一条 `edu_exception_report` 为最小事实，动作记录不重复计为报备数量，本地消息事件也不得作为报备或处理数量。待处理和已处理按主记录当前状态互斥；处理时间只在首次成功处理时形成。教师口径受本人当前有效班级与报备人共同限制，机构管理员口径受当前组织数据范围限制，两者不可直接比较。

当前只提供操作台账和组合筛选，不形成异常率、处理时长达标率、班级排行、教师绩效、心理风险判断或跨校比较。后续复杂报表必须另行定义时间窗、学生去重、班级变更归属、已删除主体保留、敏感内容脱敏和最小样本阈值。
