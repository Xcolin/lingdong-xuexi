# 灵动学习统计口径与报表设计

**版本**：V1.0（设计基线草案）  
**状态**：待评审  
**业务依据**：BRD 第 4 章；原始素材中的复盘生成与完成率规则仅在不冲突处补充  
**关联设计**：[FSD](01-功能详细设计-FSD-V1.0.md)、[数据库设计](04-数据库设计-V1.0.md)、[API 设计](06-API接口设计-V1.0.md)

## 1. 统计通用原则

1. 统计仅从用户有权访问的数据集计算，不得先聚合全量数据再通过前端隐藏。
2. 复杂统计、全量台账、复杂筛选和导出以 Web 为主；小程序只显示与当前角色相关的摘要和待办。
3. 所有时间范围按中国标准时间计算；日统计按自然日、周统计按自然周、月统计按自然月。明确生成时点的复盘按每日 21:00、每周一 00:00、每月 1 日 00:00 生成。
4. 功能关闭后不生成新的受控功能统计、复盘或导出；历史数据是否可读遵循 FSD 和具体功能开关规则。
5. 所有导出记录导出人、时间、筛选条件、范围、原因和文件；敏感导出须先有系统任务审批，并执行脱敏。

## 2. 指标口径

### 2.1 已明确指标

| 指标 | 公式/定义 | 数据来源 | 维度与筛选 | 展示角色 |
|---|---|---|---|---|
| 区域数、学校数、机构数 | 统计状态为启用的对应组织节点数；停用节点不计入当前数 | `sys_organization` | 区域、组织类型、状态 | 系统管理员 |
| 用户数 | 授权范围内用户数量，按用户状态和角色可筛选 | `sys_user`、`sys_user_role`、`sys_user_organization` | 组织、角色、状态、时间 | 系统管理员/授权管理员 |
| 待审系统任务数 | `sys_system_task.status = 待审核` 的数量 | `sys_system_task` | 任务类型、状态、时间、影响范围 | 系统审核员、系统管理员 |
| 任务完成数 | 统计期间任务实例状态为“已完成”的数量 | `learn_task_assignment` | 学生、来源、组织、班级、时间 | 家长、教师、机构管理员、学生本人 |
| 任务完成率 | `已完成任务实例数 / (统计期间任务实例总数 - 进行中任务实例数)`；原始素材明确“进行中不计入分母” | `learn_task_assignment` | 学生、任务来源、班级、组织、日期范围 | 家长、教师、机构管理员、学生本人 |
| 当日待优化数 | 统计日内状态转为“待优化”的任务实例数 | `learn_task_assignment`、`learn_task_adjustment` | 学生、来源、组织、日期 | 家长、教师、机构管理员、学生本人 |
| 暂停次数 | 统计期间情绪暂停或难题搁置记录数，按暂停类型可分组 | `learn_task_pause` | 学生、班级、类型、日期 | 家长、教师、机构管理员、学生本人 |
| 累计总积分 | 学生积分账户的累计总积分；兑换不得减少该值 | `growth_point_account` | 学生、日期快照 | 家长、学生 |
| 可用积分 | 学生积分账户当前可用积分 | `growth_point_account` | 学生、日期快照 | 家长、学生 |
| 累计获取积分 | 统计期间积分台账中“任务发放/正向纠错”等正向获取项之和；兑换和休眠清零不计入 | `growth_point_ledger` | 学生、来源任务、来源组织、时间 | 家长、教师、机构管理员（仅机构公开来源）、学生 |
| 兑换待办数 | 当前状态为“兑换待审批”的兑换申请数 | `growth_reward_exchange` | 学生、状态、申请时间 | 主家长、学生本人 |
| 考勤状态统计 | 按签到、签退、迟到、早退、缺勤、请假状态分组计数 | `attendance_record` | 学校、班级、学生、日期 | 机构管理员、教师、家长仅本人、学生本人 |
| 异常报备数 | 统计期间异常报备记录数，按异常类型、状态分组 | `edu_exception_report` | 班级、学生、类型、状态、时间 | 教师、机构管理员 |

### 2.2 需要业务确认后固化的指标

| 编号 | 指标 | 当前缺口 | 实施要求 |
|---|---|---|---|
| R-001 | 免执行任务是否计入完成率分母 | 原始素材只明确“进行中不计入分母”，未明确免执行处理 | 确认后统一修订任务完成率、待优化占比、班级完成率和验收用例。 |
| R-002 | 学员活跃度 | BRD 要求展示活跃度趋势，但未给出“活跃”的行为集合与阈值 | 明确任务认领、打卡、积分变动、登录等是否计入及最小次数。 |
| R-003 | 成长趋势曲线的数值 | BRD 要求趋势，但未定义单一得分或展示多个原始指标 | 明确是完成率、积分、待优化、暂停次数的多折线，还是综合指标。 |
| R-004 | 机构任务完成率的任务范围 | 未明确是否包含机构下发后未被教师再次下发的任务，以及跨班级转移处理 | 明确任务实例纳入条件和时间归属。 |

在 R-001 至 R-004 未确认前，界面可以展示已明确的原始指标，但不得将推测公式标记为最终业务口径。

## 3. 首页与角色看板

| 看板对象 | 卡片与图表 | 数据范围 | 刷新规则 |
|---|---|---|---|
| 系统管理员 | 区域、学校、机构、用户数；功能开关状态；待审系统任务；趋势/列表 | 全局且按审计需要 | 实时/日，复杂统计 Web 完整展示 |
| 系统审核员 | 待审核、已审核、驳回系统任务 | 仅系统任务 | 实时 |
| 机构管理员 | 班级数、学员数、机构任务完成率、考勤统计、活跃度趋势 | 授权机构/学校树 | 日/周/月；Web 完整，小程序摘要 |
| 教师 | 本班任务完成率、学生考勤状态、异常报备数 | 授权班级 | 实时/日 |
| 家长 | 当日完成率、待审核数、累计/可用积分、待优化任务数 | 已绑定学生；家庭和机构结果分区 | 实时/日 |
| 学生 | 当日任务、累计/可用积分、成长徽章、复盘入口 | 本人 | 实时，小程序主展示 |

## 5. 成长复盘数据集

### 5.1 日复盘

| 项目 | 规则 |
|---|---|
| 生成 | 每日 21:00 自动生成当日初稿；受每日复盘功能开关控制。 |
| 指标 | 当日任务完成率、积分获取总量、情绪暂停次数、待优化任务数；进行中任务不计任务完成率分母。 |
| 补录 | 家长/学生可补充成长感悟、优缺点总结、次日改进计划；仅当天及次日内，补录标记需保存。 |
| 关闭状态 | 停止新复盘生成，保留历史复盘查询。 |

### 5.2 周/月复盘

| 项目 | 规则 |
|---|---|
| 生成 | 每周一 00:00 生成上周；每月 1 日 00:00 生成上月。 |
| 指标 | 任务完成率、累计获取积分、任务类型分布、待优化任务占比、情绪暂停频次、成长趋势曲线。 |
| 模板 | 简洁版展示核心数据；详细版包含数据明细、成长分析和改进建议。 |
| 导出 | 支持单日、单周、单月和指定时间段；PDF 功能关闭后隐藏新导出入口，历史文件按权限可查看。 |

## 6. 数据刷新与性能边界

1. 待办、任务状态、积分余额、消息状态等需实时读取的指标从业务事实表或受控缓存读取。
2. 日/周/月复盘、趋势、匿名排行、机构汇总等可通过定时生成或快照加速；快照须带生成时间和统计范围，不能掩盖数据延迟。
3. 大数据量导出使用导出任务，不在同步请求中生成长时间文件；完成后通知用户下载。
4. 每个报表接口必须限制时间范围、分页/聚合粒度和数据范围，防止通过超大筛选或跨组织聚合规避权限。

## 7. 统计验收清单

- [ ] 指标分子、分母、状态集合、时间边界、数据范围和排除条件均有明确来源。
- [ ] 进行中任务不计入复盘任务完成率分母；免执行处理按 R-001 确认结果统一。
- [ ] 家庭报告、奖励和家庭积分不会被机构或教师报表统计或导出。
- [ ] 机构统计不会跨越授权组织树、班级或停用范围。
- [ ] 导出字段、筛选和脱敏与角色范围一致，敏感导出必须存在审批记录。
- [ ] Web 完整统计与小程序摘要使用同一后端口径，不出现数值不一致。
