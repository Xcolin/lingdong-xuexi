## 1. 设计边界与通用约定

### 1.1 功能编号

| 编号前缀 | 功能域 |
|---|---|
| FSD-ORG | 组织、组织类型与组织管理员 |
| FSD-IAM | 用户、角色、权限与数据范围 |
| FSD-SYS | 系统配置、系统任务审核与功能开关 |
| FSD-AUTH | 账号、登录、会话与设备 |
| FSD-STU | 学生账号、亲子关系与家校关联 |
| FSD-TASK | 家庭、机构、教师任务与学生执行 |
| FSD-POINT | 积分、奖励与兑换 |
| FSD-GROW | 成长复盘、报表订阅与匿名排行 |
| FSD-INST | 学校、班级、教师、学员与异常报备 |
| FSD-ATT | 地理考勤与轨迹 |
| FSD-COM | 附件、字典、模板、缓存、消息、帮助与维护 |
| FSD-RPT | 统计、台账、导出 |

### 1.2 全局规则

1. 业务角色固定为系统管理员、系统审核员、机构（学校）管理员、教师、家长、学生；系统管理员可创建自定义角色，但不得授予超过其可授权范围的功能、组织或数据权限。
2. 访问决策顺序固定为：**功能开关 > 用户明确禁止 > 角色允许 > 用户补充允许 > 数据范围 > 组织范围**。前端仅按结果展示，后端必须重复校验并拦截未授权操作。
3. 功能关闭后，菜单、入口、页面、按钮、弹窗和操作项均隐藏；旧链接或收藏地址也不能绕过后端校验。历史数据按具体业务规则保留，只读或可导出不代表可以新增、编辑、审核。
4. 家庭任务、奖励、家庭积分配置和家庭复盘是家庭私有数据；机构关联家长后，仅可取得学生维度的机构公开数据，不得取得家庭私有数据。
5. 所有附件、下拉字典、导入导出模板和接口服务分别使用统一公共能力，业务模块只声明归属、用途和数据权限。
6. 操作日志应覆盖权限变更、系统配置、审核、导出、缓存、围栏、数据恢复和业务关键状态变更；热存储 180 天后冷归档。
7. 所有需要主动通知的功能遵循 22:00 至次日 07:00 夜间抑制规则；用户主动操作不受影响。消息必须能跳转到相应业务详情。

### 1.3 端应用边界

| 能力类型 | Web 端 | 小程序端 |
|---|---|---|
| 权限、组织、字典、模板、接口、缓存配置 | 完整提供 | 不提供完整配置 |
| 系统任务审核与台账 | 完整提供 | 可提供待办与简化审批；不替代 Web 完整台账 |
| 机构、教师、家长高频单笔操作 | 提供 | 提供 |
| 学生任务执行 | 可展示关联页面 | 主使用端 |
| 批量导入、全量台账、复杂统计、复杂导出 | 主使用端 | 仅摘要查看 |
| 定位、轨迹、地图 | 首次个人主体发布包不包含 | 首次个人主体发布包不包含 |

## 2. 组织与权限

### FSD-ORG-01 组织类型与组织树

**使用角色**：系统管理员；被授权的组织管理员仅在其组织范围内执行授权事项。  
**业务对象**：区域、学校、校区、年级、班级和自定义组织类型。

**主流程**：维护组织类型 -> 创建区域/学校等树节点 -> 校验同级名称、组织编码和父子层级 -> 配置启用状态 -> 记录操作日志。

| 功能点 | 输入与校验 | 结果与联动 |
|---|---|---|
| 新增组织类型 | 类型编码、名称、排序、启停状态；编码和名称唯一 | 可作为组织树节点分类；停用后不能用于新增节点 |
| 新增组织节点 | 组织编码、名称、类型、上级、排序、状态 | 生成并维护组织树路径；同一上级下名称不得重复 |
| 编辑组织节点 | 允许更新名称、排序、状态等业务允许字段 | 变更写入操作日志；不得破坏既有父子关系与数据范围 |
| 停用组织节点 | 二次确认；重要组织停用属于高风险系统任务 | 本节点及下级不产生新业务；历史数据保留查询 |
| 配置组织管理员 | 选择已存在用户，且其组织关联满足授权边界 | 管理范围限定为绑定节点及子树中被授予的事项 |

**异常与边界**：家长不是组织树节点；学生可以仅由家庭创建而不属于机构；教师可关联多个班级；组织停用不删除历史数据；跨区域扩大组织管理员范围须走系统任务审核。

### FSD-IAM-01 用户、角色与权限

**使用角色**：系统管理员。  
**主流程**：创建或维护用户 -> 关联组织 -> 分配内置或自定义角色 -> 分配角色权限与数据范围 -> 按需配置用户补充允许/禁止权限 -> 记录变更日志。

| 功能点 | 关键规则 |
|---|---|
| 用户管理 | 账号全局唯一；状态为启用、停用或锁定。停用后不可登录，已有历史数据保留。 |
| 角色管理 | 内置角色不可删除；自定义角色可新增、停用。角色含菜单、页面、按钮、操作、数据和组织范围。 |
| 角色权限 | 未授权菜单和按钮不展示；权限变更后下一次进入页面按最新结果生效。 |
| 用户权限 | 仅用于补充或明确限制；明确禁止优先于允许；不得以用户权限扩大组织/数据范围。 |
| 数据范围 | 支持全部、本区域、本学校、本班级、本人、自定义。实际访问还必须同时满足用户组织关联和组织管理员范围。 |
| 组织管理员 | 不是一个越权角色；只能管理对应组织子树中已授予的事项。 |

**数据隔离规则**：系统管理员按审计和管理需要查看全局数据；系统审核员仅查看待审系统任务与审批历史；机构管理员按授权机构；教师按授权班级；家长按已绑定学生；学生仅本人。

## 3. 系统配置、系统审核与功能开关

### FSD-SYS-01 系统任务与审核

**发起角色**：系统管理员。**审批角色**：系统审核员。  
**任务状态**：草稿 -> 待审核 -> 已通过/已驳回 -> 已生效；已驳回可修改后重新提交。

| 功能点 | 处理规则 |
|---|---|
| 创建系统任务 | 填写任务类型、标题、说明、影响范围；任务类型包括公告发布、机构停用、数据恢复、敏感导出、功能开关调整和系统配置调整。 |
| 提交审核 | 仅发起人可提交自己的草稿；审批中不得重复提交。 |
| 审批通过 | 系统审核员记录审批人、时间、意见；后续由具体业务变更执行并标记已生效。 |
| 审批驳回 | 驳回意见必填，最长 500 字；不能直接生效。 |
| 审批边界 | 审核员不得审批自己提交的任务，且不进入学习任务、打卡、积分、兑换或考勤的业务审核流。 |

**必须经系统审核的高风险事项**：全局公告发布、重要组织停用、数据恢复、敏感导出、全局功能开关、全量或用户会话缓存清除、接口服务新增/停用/扩大授权、跨区域组织管理员授权、关键字典变更、超出原组织范围的数据权限调整。

### FSD-SYS-02 附件管理

**功能目标**：统一上传、下载、查看、预览、删除规则，业务模块不单独定义文件能力。

| 配置项 | 规则 |
|---|---|
| 附件类型与格式 | 由附件规则配置；业务需求列举图片、文档、表格、PDF、音视频等类型，实际白名单应以配置为准。 |
| 文件大小与批量上传 | 由附件规则配置，超出规则不允许上传。 |
| 预览与下载 | 依据附件规则和所属业务数据权限决定；不支持预览时只显示下载入口。 |
| 删除 | 默认解除业务可见关系；归档业务保留追溯记录；物理删除申请属于受控操作。 |
| 归属 | 每个附件必须关联所属模块、业务对象、上传人和上传时间。 |

### FSD-SYS-03 缓存、字典、模板和接口服务

| 功能 | 操作 | 关键规则 |
|---|---|---|
| 缓存管理 | 按权限、字典、组织、功能开关、用户会话、业务统计等类型刷新或清除 | 默认按模块处理；全量清除和清除用户会话需说明影响范围、二次确认并走系统审核；失败保留失败记录。 |
| 数据字典 | 字典类型、字典项新增、编辑、排序、启停、默认项 | 所有下拉、状态、类型和枚举统一来源；同一类型编码唯一、最多一个默认项；停用项不可新选，历史仍原值展示；关键字典变更需审核。 |
| 导入导出模板 | 模板类型、适用模块、版本、默认项、启停 | 同模块同类型只有一个默认模板；新变更只影响新任务，历史导入记录和导出文件保留原模板版本。 |
| 接口服务 | 服务名称、方向、用途、调用方、授权范围、状态、责任人 | 未具备授权范围、责任人或状态不能启用；新增、停用、扩大范围均需审核；保留调用结果和异常说明。 |

### FSD-SYS-04 功能开关

**主流程**：系统管理员创建全局开关调整任务 -> 系统审核员审批 -> 审批通过后变更生效 -> 清理或刷新受影响缓存 -> 前后端按最新开关执行。

**通用结果**：关闭后阻止新建、编辑、审核、采集、生成新待办、新通知和新数据；历史数据保留，具体待办处理以所属功能的规则为准。

**定位专项**：`GEO_ATTENDANCE` 和 `STUDENT_LOCATION_TRACK` 默认关闭。关闭时两端均隐藏围栏、考勤、轨迹和位置授权入口，后端拒绝位置、地图、自动签到签退和轨迹请求。个人主体工具类目首次小程序构建包不得包含相关能力；未来启用前同时满足高风险任务审批、可发布主体条件和家长位置授权。

## 4. 账号、学生与家校关系

### FSD-AUTH-01 多角色登录、会话与设备

| 功能点 | 规则 |
|---|---|
| 家长登录 | 支持手机号验证码、密码；小程序支持微信授权。微信与手机号一对一绑定，授权失败回落至验证码登录。 |
| 学生登录 | V21 已实现小程序 8 位学生账号加 4 位登录码登录；V35 已实现学生扫码后再输入 4 位登录码。学生不得自主注册，微信登录仍为后续能力。Web 密码登录明确拒绝学生账号。 |
| 登录安全 | V21 已实现登录码连续错误 5 次后要求账号与设备绑定的单次图形验证码，连续错误 10 次锁定 15 分钟；登录按账号设备及来源地址限流。V35 二维码票据固定 5 分钟、只允许消费一次，错误登录码同样使票据失效。 |
| 设备管理 | 查看已登录设备、退出当前设备、一键下线；状态变更留痕。 |
| 密码与验证码 | 密码为 8 至 20 位字母加数字；验证码 6 位、5 分钟有效、1 分钟内最多发送 3 次。 |

### FSD-STU-01 学生账号与亲子关系

**V19-V21、V35、V38、V41-V46 已实现边界**：已实现学生姓名、可选年级编码、启用状态、主副家长关系和直接机构关系的创建、查询与生命周期。V20 已实现机构家长绑定邀请；V21 在同一事务建立学生用户、`STUDENT` 角色、8 位年度账号和 4 位登录码；V35 实现 5 分钟一次性登录二维码；V38 实现主副家长关系；V41 实现校内转班、机构关系停用和不可变审计；V42-V45 实现家长换号、家长与学生账号注销边界；V46 实现学生微信自助双重绑定、快捷登录和主监护人解绑。当前仍不包含学生头像、消息实际投递、独立家庭人工恢复或真实环境联调。

**主流程一（家庭）**：家长登录 -> 创建学生 -> 同事务生成学生账号和一次性初始登录码 -> 建立主家长关系 -> 学生在小程序登录。

**主流程二（机构）**：机构管理员创建学生 -> 同事务生成学生账号和一次性初始登录码 -> 发送家长绑定邀请 -> 家长确认 -> 建立亲子与家校关联。

**历史学生流程**：主家长或直接机构管理员初始化登录凭证 -> 一次性安全转交账号和登录码 -> 学生登录；遗失后由同一对象范围内的操作者重置，旧会话立即撤销。

| 功能点 | 关键规则 |
|---|---|
| 学生创建 | 仅家长或机构管理员可创建；当前字段为学生姓名、可选年级和机构侧可选组织。账号采用创建年份后两位加 6 位年度序号（`YYNNNNNN`），每年从 `000001` 递增，达到 `999999` 后拒绝继续分配。 |
| 登录凭证 | 登录码为 `SecureRandom` 生成的 4 位数字；数据库只保存独立随机盐、HMAC-SHA256 摘要和密钥版本。初始或重置明文只在对应成功响应出现一次，普通学生详情和日志不得返回。 |
| 功能开关 | `STUDENT_CODE_LOGIN` 关闭后，小程序首页隐藏学生登录入口，登录页直达显示不可用，验证码和登录接口均由后端拒绝且不创建会话。 |
| 扫码登录 | `STUDENT_QR_LOGIN` 关闭后 Web 与小程序入口同时隐藏且后端拒绝；二维码只包含安全随机票据，不含学生账号、姓名、登录码和业务主键。新票据撤销同学生旧票据，扫码消费使用数据库行锁。 |
| 主副家长 | 首次绑定为主家长；副家长默认查看与接收指定消息，无编辑、审核、奖励配置权限。 |
| 主家长变更 | 主家长解绑后，最早绑定的副家长自动升级；无副家长时家庭审核暂停，历史可查看。 |
| 机构邀请 | V20 已实现机构不得强制绑定家长；仅学生直接所属组织的直接机构管理员可签发；邀请固定有效期 7 天，拒绝或过期不建立关系，可重新发送。每名学生至多一个未过期待处理邀请，接受时原子建立唯一主家长关系。当前由机构线下受控转交一次性令牌，不含消息投递和小程序页面。 |
| 账号注销 | 家长先解除学生绑定；学生注销须满足无机构关联等 BRD 条件，状态不可逆。 |
| 转班转学 | 由机构侧维护组织关联，家庭关系和历史家庭数据不因机构关系变化而向机构开放。 |

## 5. 学习任务与学生执行

### FSD-TASK-00 V24 当前落地边界

V22 已实现任务定义、发布和学生本人查询。V23 在该基础上实现学生认领、情绪暂停/难题搁置、手动恢复、放弃转待优化、文字打卡、当前审核人待办与驳回、同来源候选审核人转交，以及授权管理角色设置免执行。V24 新增当前审核人通过打卡，并在同一事务内完成打卡通过、任务完成、累计与可用积分增加、任务奖励台账和审核通过事件。`LEARNING_TASK_MANAGEMENT` 关闭后，Web 与小程序入口隐藏、直达页面不请求任务数据，后端任务、学生执行、业务审核及班级关系接口同时拒绝。

任务定义状态仍为 `DRAFT`、`PUBLISHED`。学生实例已支持 `PENDING_CLAIM`、`IN_PROGRESS`、`PENDING_REVIEW`、`NEEDS_IMPROVEMENT`、`EXEMPT`、`COMPLETED`，暂停通过活动暂停记录派生为 `PAUSED`。V31 已支持 JPG/PNG 图片打卡；V32 已支持 23:59 转待优化、00:00 自动顺延及 Web 手动顺延；V33 已支持 Web 主家长按学生复制昨日家庭任务；V34 已支持系统预置常用模板和家长个人模板。音视频打卡、审核超时、自动转交、消息和统计仍属于后续功能点。

| 来源 | 创建角色 | 来源与目标约束 | 默认审核人 |
|---|---|---|---|
| 家庭 | 主家长 | 不指定来源组织；目标只能是当前家长活动主关系下的学生。 | 当前家长。 |
| 机构 | 机构管理员 | 来源组织须在当前数据范围；目标为来源组织子树内启用组织或活动学生。 | 当前机构管理员；可指定覆盖全部目标班级/学生的启用教师。 |
| 教师 | 教师 | 来源须为当前教师活动班级；目标为该班级或班内活动学生。 | 当前教师。 |

草稿字段为标题、难度、执行时长、计划日期、分类、标签、备注、审核人和原始目标。难度取 1 至 3，基础积分由服务端按难度乘以 10 生成，审核超时固定为 72 小时；分类与标签读取启用字典。任务一经发布即不可编辑，重复发布返回状态冲突。

#### V29 积分生命周期流程

1. `POINT_LIFECYCLE` 同时控制任务奖励衰减和沉睡扫描；关闭后新审核按基础积分全额发放，后台不创建提醒、不执行清零，历史台账仍可读取。
2. 任务审核通过时，服务端以任务标识、学生标识、来源类型、来源主体和任务计划日期查询未被纠错的历史任务奖励；复制出的新任务具有新任务标识，不继承原任务连续天数。
3. 服务端按自然日连续性计算连续天数，读取审核时点已生效的衰减规则，使用整数比例计算实发积分，并在同一事务内更新账户、任务状态、打卡状态、事件和积分台账。
4. 沉睡扫描按学生标识游标分页，综合任务有效操作、非休眠清零积分台账和用户主动复盘补录确定最后活跃时间；单个学生在独立事务内处理，失败不回滚其他学生。
5. 第 27 天提醒按学生和沉睡周期幂等创建。存在活动主家长时状态为 `PENDING`，无活动主家长时状态为 `NO_RECIPIENT`；V29 只形成待投递记录，不宣称微信、短信或站内消息已送达。
6. 第 30 天仅在可用积分大于 0 时原子清零，并追加 `DORMANCY_CLEAR` 台账；重复扫描不重复清零。清零后出现新的有效活动时开始新的沉睡周期。
7. Web 与 uni-app 积分明细展示连续天数、基础积分和衰减比例；19 位任务、规则和台账标识均按字符串传输。
8. V30 已提供每日固定任务配置、可选结束日和自动生成实例；V31 已提供文字、JPG/PNG 图片及图文混合打卡；V32 已提供顺延；V33 已提供 Web 主家长按学生复制昨日任务；V34 已提供 Web 家长任务模板。周规则、Cron、跳过节假日、音频和视频不属于当前已实现范围。

#### V30 每日固定任务流程

1. 家长、机构管理员或教师在自己可管理的任务草稿中启用每日固定任务，可不填结束日；结束日不得早于首个计划日，关闭固定任务时结束日必须为空。
2. 发布事务按当前有效目标生成首日学生实例；固定任务同时创建唯一 `ACTIVE` 计划，下一生成日为首日加一天。首日无有效学生时沿用发布规则拒绝发布。
3. 调度默认每日 00:05 按上海时区扫描到期计划，按计划雪花标识分页；每个计划在独立事务中锁行，防止同一计划并发推进。
4. 生成时重新展开当前有效学生目标，逐个计划日查询已存在学生实例，只插入缺失项；目标为空仍推进日期游标，避免计划永久堵塞。
5. 每个实例复用原任务标识、来源和审核人，计划日期为生成日，截止时间为当日 23:59:59；因此 V29 可按同任务相邻自然日计算连续完成。
6. 下一生成日超过可选结束日时计划转为 `COMPLETED`；无结束日时保持 `ACTIVE`。重复执行依靠计划锁、版本条件和任务/学生/计划日唯一约束保持幂等。
7. 管理人可主动停止 `ACTIVE` 计划；服务端复核功能开关、动态权限和家庭/组织/教师数据范围，记录停止人和时间，不删除已生成实例。
8. 当前仅支持 `DAILY`。周规则、Cron、节假日跳过和小程序周期管理仍未实现；顺延由 V32 实现，按学生复制昨日任务由 V33 实现。

#### V31 图片打卡流程

3. 学生可提交纯文字、纯图片或图文混合内容，但文字与图片不能同时为空。打卡请求只提交文字和文件标识，不提交存储路径。

#### V32 待优化与顺延流程

1. 每日 23:59:59 按上海时区扫描截止时间已到的进行中任务；有效暂停任务跳过，其余任务转为“待优化”并写系统事件，不扣分、不发积分。
2. 每日 00:00 扫描昨日待优化任务。未被手动顺延的实例自动迁移到当日，状态重置为待认领，并永久显示“隔夜迁移”。
3. 家长、创建教师或授权机构管理员可在 Web 查看数据范围内的待优化任务，选择未来 1 至 7 天手动顺延；学生端不提供顺延操作。
4. 顺延克隆原任务配置和标签，关闭克隆任务的周期配置，保留同一学生实例标识并追加不可变历史。积分、难度、来源和审核人不变。
5. 手动顺延标记阻止自动重复处理。自动顺延后学生尚未认领时允许手动改期；学生已经认领后禁止覆盖。
6. 原计划日统计移除已迁移实例，目标日纳入统计；已生成复盘快照不修改，事实变化后按既有规则追加版本。

#### V33 按学生复制昨日任务流程

1. 仅 Web 活动主家长可以选择本人主关系学生；服务端按上海时区计算昨日和今日，客户端不得提交源日期或目标日期。
2. 候选仅包含该家长创建、昨日计划日、家庭来源且已发布的学生任务，不限制昨日实例最终状态；顺延到今日的任务不再作为昨日候选。
3. 预览返回候选数量、今日同名标题和当日已有批次。存在同名时必须二次确认；确认后允许复制，同名不是唯一约束。
4. 每个学生每日最多创建一个复制批次。每个源任务形成一个独立条目并在 `REQUIRES_NEW` 事务中处理，单条失败不回滚其他成功项，可显式重试失败条目。
5. 新任务复制标题、难度、基础积分、时长、分类、备注、审核人、审核时限和标签；生成类型为 `COPIED`，记录来源任务，关闭周期属性，只创建当前学生目标和待认领实例。
6. 不复制原实例状态、暂停、打卡、审核、顺延、积分、附件和周期计划。复制任务使用新任务标识，因此不继承原任务连续完成天数。
7. 重复提交返回当日既有批次；若上次进程在批次创建后中断，只恢复 `PENDING` 条目，不重放成功或失败条目。失败条目只能通过单条重试接口再次处理。
8. 小程序不显示复杂批量复制入口；关闭 `LEARNING_TASK_MANAGEMENT` 或 `COPY_PREVIOUS_DAY_TASK` 后 Web 入口隐藏且后端同时拒绝。

#### V34 任务模板流程

1. 系统模板由 Flyway 预置并保持只读；个人模板只属于当前 Web 家长，不存在机构、教师或跨家长共享模板。
2. 模板仅保存模板名称、任务标题、难度、执行时长、分类、标签、备注和排序，不保存任务来源、组织、学生、计划日期、审核人、周期、状态或积分事实。
3. 家长可从模板库选用系统或本人个人模板，也可将当前任务编辑器中的可复用字段保存为个人模板；选用后仍须补齐日期和学生并走现有草稿创建、发布校验。
4. 个人模板最多 100 个；同一家长活动模板名称唯一。编辑、逻辑删除和全量排序均携带版本号，并发变化时要求刷新后重试。
5. 删除模板不影响已创建任务；逻辑删除后允许复用名称。分类和标签必须来自当前启用字典，基础积分继续由任务难度规则计算。
6. `LEARNING_TASK_MANAGEMENT` 或 `LEARNING_TASK_TEMPLATE` 任一关闭时入口隐藏且后端拒绝。小程序能力固定关闭，不包含模板管理代码。

## 11. V36 家长手机号认证详细流程

1. 入口先查询 `PARENT_PHONE_AUTH` 与当前协议版本；停用时隐藏验证码注册登录和家长小程序入口，后端同时拒绝相关接口。
2. 验证码按手机号、用途和客户端隔离，5 分钟到期并原子消费；新手机号在单事务创建 `FAMILY` 用户、`PARENT` 角色关系、家长档案、协议事实和设备会话。
3. 验证码首次注册必须接受当前协议；密码登录可建立受限会话，再按服务端状态先接受升级协议、完成四步引导，之后进入普通业务页面。
4. Web 提供验证码和密码两种模式；uni-app 提供家长、学生独立入口，家长会话与学生会话使用不同存储键、路由和退出逻辑。
5. 家长可在登录后设置密码，也可通过 `RESET_PASSWORD` 用途验证码重置；未知手机号、错误密码、停用账号或错误用户类型统一返回中性认证失败。
6. 服务端家长准入拦截器只约束存在 V36 家长认证档案的账号；历史家长账号保持原业务兼容。

## 12. V37 家长微信授权与绑定详细流程

1. 微信小程序读取公开家长认证上下文；仅当 `PARENT_PHONE_AUTH` 与 `PARENT_WECHAT_AUTH` 均启用时展示微信快捷登录，Web/H5 始终不展示。
2. 小程序调用 `uni.login` 取得一次性临时凭证，后端经登记为启用的微信出站接口服务调用 `code2session`；配置缺失、供应商错误、超时或响应缺少必要字段均失败关闭。
3. 已存在有效绑定时，后端校验家长账号启用且仍为家长角色，更新绑定最后登录时间并创建 `MINIAPP` 会话；停用账号不得登录。
4. 未绑定身份只返回 5 分钟有效、一次消费的不透明绑定票据，不创建用户、家长档案或设备会话，也不向客户端返回 `openid`、`unionid` 或 `session_key`。
5. 用户提交绑定票据、手机号、`WECHAT_BIND` 验证码、设备信息和当前协议确认；后端消费票据并复用 V36 手机号锁定注册、角色、档案和协议规则，在同一事务写入唯一绑定并创建会话。
6. 同一用户只能绑定一个小程序微信身份，同一 `app_id + open_id` 只能属于一个用户；冲突、票据过期、篡改或重放均拒绝，不自动覆盖或换绑。

## 13. V38 家长关系生命周期详细流程

1. 活动主家长选择自己的学生并提交目标手机号；服务端校验功能开关、RBAC、活动主关系、目标非本人、一个活动副家长上限及每位家长最多关联 10 名活动学生。
2. 服务端创建 5 分钟邀请并发送关系专用验证码；响应只返回邀请标识、脱敏手机号和到期时间。被邀请人可在未登录状态提交手机号、验证码、当前协议和设备信息接受或拒绝。
3. 接受副家长邀请时原子校验验证码、锁定邀请与学生关系、创建或复用启用家长账号、建立副关系、关闭邀请、写入不可变审计并签发独立家长会话；重复响应和并发竞争至多一条成功。
4. 主家长可解除副家长；副家长不能自行解绑。主家长自行解绑时，存在副家长则按绑定时间和关系标识顺序晋升，否则学生进入无主家长状态，历史数据不删除。
5. 监护权转移由原主家长发起，目标确认后目标成为主家长、原主降为副家长；该学生的家庭来源待审核任务在同一事务转交新主家长并记录固定原因“主家长关系变更”。
6. 副家长可读取学生档案、已分配任务、积分、奖励和复盘；任务创建/审核、积分纠错、奖励维护/审批、复盘补录、二维码签发和登录码重置仍只允许活动主家长。

## 14. V39 设备会话与账号安全详细流程

1. 任一合法登录统一创建 `auth_device_session`。创建前查询同一用户、同一客户端和同一设备标识的历史会话；首次出现时记录一条未读 `NEW_DEVICE_LOGIN/WARNING`，并发重复由唯一范围键收敛。
2. 设备列表只返回状态为活动且刷新凭证仍未过期的会话，标记当前认证会话，不返回原始设备标识、访问令牌、刷新令牌或摘要。
3. 用户可下线本人的其他设备；更新成功后记录 `DEVICE_REVOKED/INFO`。下线全部设备包含当前设备，成功后记录 `ALL_SESSIONS_REVOKED/INFO`。访问其他用户的会话统一按资源不存在处理。
4. 普通退出当前会话仅使当前令牌失效，不记录风险事件；账号停用触发的内部全量撤销也不伪装成用户主动操作。
5. 安全事件按发生时间倒序最多返回 50 条，支持仅未读、单条已读和全部已读；已读操作幂等且只能作用于当前用户事件。
6. 功能开关关闭时，设备列表、指定下线、全部下线和事件管理均由后端拒绝；登录安全事实继续记录，当前会话退出继续可用。

## 15. V40 机构管理员小程序认证详细流程

1. 小程序仅在公开能力 `organizationMiniappAuthEnabled` 为真时展示机构入口，机构会话和设备标识使用独立存储键。
2. 专用登录端点只接收账号、密码、设备标识和设备名称，服务端固定签发 `MINIAPP` 会话，不允许客户端选择终端类型。
3. 登录同时校验全局开关、启用用户、机构用户类型、启用 `ORG_ADMIN` 角色、至少一个直接管理的启用组织及密码；身份条件或凭据不满足统一返回认证失败。
4. 访问与刷新持续复核上述条件。功能关闭、用户停用、角色移除或停用、全部管理关系移除、全部管理组织停用后，旧机构小程序会话立即失效。
5. 工作台只展示当前账号和直接管理的启用组织摘要，支持进入账号安全和退出；不展示转班、任务、考勤、统计、定位或地图入口。
6. 动态权限拦截器同时匹配当前令牌客户端与权限目录客户端；机构小程序令牌不能调用仅标记为 `WEB` 的学生、组织或其他操作接口。
7. 未知账号与不满足机构身份条件的账号仍执行等价密码哈希校验。持续校验失败的撤销使用独立事务提交；审批关闭功能开关时批量撤销机构小程序活动会话，机构 Web 会话保持活动。

## 18. V43 家长账号最终注销流程

1. 条件调度按上海时区每 10 分钟读取有限数量的到期活动申请；功能开关停用时不读取、不终结账号。
2. 每个申请在独立事务中锁定申请和家长用户，再次校验状态、冷静期、下次执行时间、家长类型、`PARENT` 角色和活动学生关系。
3. 若活动关系在冷静期后恢复，则申请保持 `COOLING_OFF`，累计尝试次数、登记 `ACTIVE_RELATIONSHIP` 并延后一天，不强制解除关系。
4. 无活动关系时将用户名替换为 `cancelled_` 加内部用户标识，名称改为“已注销用户”，清空手机号和密码摘要，状态改为 `CANCELLED`；同时删除微信绑定并撤销全部活动会话。
5. 申请同步改为 `FINALIZED`、关闭活动范围键并记录终结时间。上述写入任一步失败时整项回滚，批处理中其他申请继续处理。
6. 已终结账号不能使用密码、手机号、微信、访问令牌或刷新令牌认证，也不能通过用户管理状态接口恢复；历史业务事实不删除。

## 19. V44 家长手机号人工核验换绑流程

1. 机构管理员在功能开关启用后查询本人直接管理组织子树内的活动学生及其活动主副家长，只返回脱敏旧手机号。
2. 管理员选择学生与家长，填写未占用且不同于旧号的新手机号；后端重新校验组织范围后发送 `MANUAL_MOBILE_RECOVERY_NEW` 专用验证码，公共家长验证码接口不能发送该用途。
3. 管理员填写验证码、1 至 200 字核验原因和固定确认语句“已完成线下身份核验”。提交时服务端锁定家长、学生和关系，复核家长角色、活动关系、组织范围、活动注销申请和新号码占用。
4. 验证码消费、手机号条件更新、默认手机号登录名同步、19 位雪花审计写入和全会话撤销在同一事务完成；任一步失败不保留部分换绑结果。
5. 审计只保存新旧手机号 HMAC 摘要，不保存手机号、验证码或证件资料；微信绑定、亲子关系和历史业务事实保持不变。
6. 功能默认停用；停用、越权、跨机构、学生已转出、关系已解除、账号停用、注销处理中或并发冲突均拒绝。独立家庭不属于本流程。

## 20. V45 学生账号注销流程

1. 机构管理员在 Web 或机构小程序读取注销候选。候选必须为启用学生及启用学生用户，具有学生角色，最新一条入学关系为停用，且当前不存在任何活动机构关系和活动家长关系。
2. 候选范围以操作人直接管理组织子树与最新停用入学组织求交集；从未关联机构的独立学生、较早历史机构和范围外机构均不可见。
3. 管理员选择学生，填写 1 至 200 字注销原因并精确输入“确认注销学生账号”，前端再显示不可恢复二次确认。
4. 服务端依次锁定学生、学生用户、活动机构关系和活动家长关系，重新计算最近停用入学组织范围，防止候选加载后的关系变化和并发越权。
5. 同一事务将学生姓名、用户显示名和登录名匿名化，状态置为 `CANCELLED`，清空用户手机号与密码摘要，删除 4 位登录码凭据，撤销活动二维码和全部设备会话，写入 19 位雪花主键审计。
6. 注销审计只保存稳定业务标识、操作组织、操作者、原因、客户端和时间，不保存原姓名、原账号、登录码、令牌或身份附件。任一步失败整笔回滚，重复注销按资源不可访问或冲突处理。

## V46 学生微信授权登录功能详细设计补充

学生微信认证由“临时凭证交换、学生口令预认证、主监护人短信验证、最终绑定、快捷登录、主监护人解绑”六个状态组成。临时微信身份只保存在 Redis 一次性票据中；登录码错误时保留微信票据并沿用图形验证码与锁定规则，学生身份校验成功后才消费身份票据。最终绑定前重新锁定并校验学生、学生用户、当前主监护关系和主监护人手机号，任一条件变化均阻止绑定。

解绑仅删除当前微信绑定，不删除学生数据、不修改登录码、不自动撤销已有设备会话；后续微信快捷登录必须重新完成双重绑定。

## V47 组织节点生命周期功能详细设计补充

### 低风险维护

1. 系统管理员读取组织树，节点返回自身状态 `status`、有效状态 `effectiveStatus` 和版本号 `versionNo`。
2. 编辑只允许修改组织名称和排序；提交原版本号，服务端按版本条件更新。版本已变化时返回冲突，前端重新加载后再提交。
3. 已停用节点可由系统管理员直接启用；父组织必须有效启用。启用后按父子关系重新计算整个子树的有效状态，并写入不可变审计。

### 高风险变更

1. 系统管理员选择 `DISABLE`、`MOVE` 或 `DELETE`，填写不超过 500 字的原因和当前版本；移动还必须选择有效启用且不在自身子树内的目标父节点。
2. 服务端保存组织编码、名称、原父节点和预期版本快照，创建并立即提交系统任务。系统管理员只能查看本人申请，系统审核员可查看全部待审核申请。
3. 系统审核员批准后，服务端锁定目标组织并再次核对版本。停用同步停用整个子树的有效状态；移动重建子树路径并重算有效状态；删除仅允许无下级节点且无业务引用的叶子节点。
4. 审核结论先提交，组织变更在独立事务执行。执行失败时任务保留已批准事实，变更状态记录为 `FAILED` 并保存受限长度的失败原因，不伪装为已生效。
5. 驳回不执行组织变更，任务状态为 `REJECTED`，同时写入驳回审计。成功执行后任务状态为 `EFFECTIVE`，变更状态为 `APPLIED`。

### 业务有效状态

组织管理员授权、学生创建和邀请、学生分班与机构关系变更、教师班级分配、机构/教师任务范围及机构安全操作均以有效状态为准；历史关系和历史业务查询不因上级停用而删除或篡改。

## V48 班级基础管理功能详细设计补充

### 班级维护

1. 机构管理员先读取授权范围内的有效学校和全部班级；停用班级保留在列表中，以便重新启用和查询历史关系。
2. 新增班级只提交学校、名称和排序。服务端校验学校有效状态、授权范围和同校名称唯一性，并以 `CLS_` 加 19 位雪花标识生成组织编码。
3. 编辑只允许修改名称和排序，必须提交当前版本号；所属学校、组织类型和编码不能通过班级接口变更。
4. 启用和停用均按版本条件更新。重新启用要求所属学校有效启用；重复提交和过期版本返回明确冲突。

### 停用联动

1. 停用班级时，在同一事务中锁定当前活动学生的机构/教师任务实例，将 `PENDING_CLAIM`、`IN_PROGRESS`、`PENDING_REVIEW`、`NEEDS_IMPROVEMENT` 更新为 `INVALIDATED`。
2. 每条失效任务追加 `CLASS_INVALIDATED` 事件，活动暂停以 `TERMINATED` 关闭；家庭任务、已完成、免执行和已失效任务不变。
3. 机构管理员直接停用和 V47 系统任务批准停用 `CLASS` 节点复用同一失效服务。重新启用班级只恢复组织有效状态，不恢复旧任务。
4. 创建、编辑、启用和停用写入组织不可变审计；功能停用或组织越权由后端最终拒绝。

## V49 权限授权边界功能详细设计补充

1. 系统管理员选择角色或用户后查询当前显式权限配置；列表只表示直接配置，不把继承结果重复保存为用户权限。
2. 保存角色权限时按权限标识幂等写入 `ALLOW` 或 `DENY`；保存用户补充允许时，用户必须至少具有一个启用角色。
3. 权限决策先校验用户、角色、权限和客户端状态，再执行“角色禁止或用户禁止优先、角色允许、用户补充允许”的顺序；没有任何允许来源时默认拒绝。
4. 用户补充允许只改变功能权限结果，不产生新的组织范围或数据范围；对象查询仍由后端数据范围组件裁剪。
5. 权限停用后禁止新增或改写配置，已停用权限不参与放行；系统管理员仍可撤销历史显式配置。权限变更审计留待独立专项实现。

## 通用组织数据范围查询功能详细设计补充

1. 服务端根据当前用户状态和活动角色解析范围，不接受客户端传入可访问组织集合。
2. `ALL` 返回全部组织；`REGION/SCHOOL/CLASS` 要求角色授权组织类型匹配并返回该组织子树；`CUSTOM` 使用角色配置根；`SELF` 只标记本人范围。
3. 非全部范围与用户组织关系取交集；存在组织管理员授权时再取一次交集。相交子树保留更窄根路径，重复或被上级覆盖的路径归并。
4. 单对象校验和组织列表查询使用同一不可变范围结果。组织停用状态由业务操作层另行校验，以便历史只读查询保留授权事实。

## V50 身份权限变更审计功能详细设计补充

1. 用户创建、状态变更、组织关联和角色授予，自定义角色与权限创建，角色或用户权限配置与撤销，角色自定义范围新增及组织管理员配置成功后追加审计。
2. 相同权限效果重复保存、重复撤销不存在关系和事务失败不产生审计；审计不记录姓名、手机号、密码或令牌。
3. Web 支持按事件、对象、操作者、目标和时间范围筛选，按发生时间与主键倒序分页；所有雪花标识按字符串返回。

## 统一访问边界验证功能补充

机构管理员只查询直接管理学校及其班级；另一地区、学校和班级不进入列表，直接新增或修改按不可访问处理。令牌签发后权限关系删除或角色停用，下一请求重新执行活动角色权限决策并拒绝旧能力。班级功能停用后业务接口拒绝，Web 与小程序公共能力均返回关闭。

## V51 数据字典功能详细设计补充

具备 `DICTIONARY_READ` 的 Web 用户进入数据字典页面后加载全部类型，并按排序号、名称和标识稳定排序；选择类型后加载其全部历史项。仅具备查询权限时隐藏新增和编辑入口，具备 `DICTIONARY_MANAGE` 后才显示维护操作。普通类型可新增和修改名称、排序、状态与默认项，编码创建后不可修改；同类型编码唯一且最多一个默认项。关键字典仍拒绝直接变更，后续必须通过系统任务审批执行。查询、维护和功能开关任一校验失败均不进入业务写事务。

## V52 缓存管理功能详细设计补充

具备 `CACHE_READ` 的 Web 用户可查询最近 200 条缓存操作，记录缓存域、操作类型、状态、影响说明、申请人、执行人、失败原因和时间。具备 `CACHE_MANAGE` 的角色可直接刷新或清除数据字典缓存；请求先写入 `PENDING` 台账，再执行处理器并更新为 `SUCCEEDED` 或 `FAILED`。全量清除与用户会话清除禁止直接执行，只允许活动系统管理员填写标题、影响说明并二次确认后创建和提交系统任务。

活动系统审核员且具备 `CACHE_REVIEW` 时可查询待审队列。批准顺序为锁定待执行操作、批准系统任务、执行处理器、记录结果；仅成功时把任务标记为 `EFFECTIVE`。驳回必须填写意见，系统任务与缓存台账分别进入 `REJECTED`，不记录执行人和执行时间。用户会话清除撤销 `auth_device_session` 中全部 `ACTIVE` 会话，包括审批人的当前会话；全量清除只遍历 Spring `CacheManager` 已注册缓存。功能开关关闭、权限不足、重复审核或非法域和操作组合均在执行前拒绝。

## V53 接口服务管理功能详细设计补充

具备 `INTERFACE_SERVICE_READ` 的 Web 用户可按服务名称、调用方、状态、用途和责任人查询接口服务，并查看最近变更和调用结果。活动系统管理员且具备 `INTERFACE_SERVICE_MANAGE` 时，可登记服务，或对已存在服务提交启用、停用和授权范围变更；登记字段包括服务名称、方向、用途、调用方、授权范围、责任人、任务标题和说明。授权范围为全局时不得填写范围值，区域、学校、机构或指定调用方时必须填写范围值。

提交动作只生成 `PENDING_REVIEW` 系统任务和变更快照，不提前改变服务。活动系统审核员且具备 `INTERFACE_SERVICE_REVIEW` 时可批准或驳回；批准后按快照原子执行登记、启停或授权变更，执行成功后任务进入 `EFFECTIVE`，驳回只记录意见并保持原服务不变。重复审核、状态不匹配、功能停用、权限不足和固定角色不符均在变更前拒绝。调用台账只保存服务、调用方、成功或失败、受限异常摘要、追踪标识和时间，不保存请求响应正文、凭据或位置。

## V54 附件统一管理功能详细设计补充

具备 `ATTACHMENT_RULE_READ` 的 Web 用户可按规则名称、模块、分类和状态查询最多 200 条规则；具备 `ATTACHMENT_RULE_MANAGE` 时可新增、编辑、启用和停用。模块编码与文件分类创建后不可修改，名称、扩展名、单文件上限、单批数量和预览配置可编辑；保存和启停均携带当前版本号，版本不一致时拒绝覆盖。重复提交当前启停状态返回现状，不重复增加版本。

具备 `ATTACHMENT_FILE_LEDGER_READ` 时可按文件名称、模块、分类、状态、上传人和创建时间查询安全文件台账，并查看活动与已解除的业务关系历史。页面不返回存储键、实际路径或摘要原文，只返回是否已记录摘要。附件总开关关闭后，上传、元数据、预览、下载和删除接口均拒绝，父业务附件集合返回空列表；学习任务文字详情和文字打卡不因附件停用而失败。下载复用预览的对象权限和内容读取逻辑，只将内容处置改为附件下载。

## V55 导入导出模板管理功能详细设计补充

具备 `IMPORT_EXPORT_TEMPLATE_READ` 的 Web 用户可按模板名称、类型、适用模块和状态查询最多 200 条模板，并读取三个启用字典选项。具备 `IMPORT_EXPORT_TEMPLATE_MANAGE` 时可上传一个文件创建新版本、启用、停用或设为默认；模板名称和版本去除首尾空格，类型、模块和状态必须来自启用字典，同模块、同类型、同版本不得重复。创建流程依次完成权限与字典校验、版本预检、统一附件保存、模板写入、`TEMPLATE_FILE/SYSTEM_CONFIGURATION` 关系写入和可选默认切换，失败时数据库回滚并补偿物理内容。

启停和设默认必须携带当前 `versionNo`，过期版本返回冲突并刷新台账；重复提交当前启停状态返回现状。默认模板必须处于启用状态，同模块同类型只允许一个默认项，停用默认模板时同时取消默认。已停用模板仍可在有读取权限时受控下载。模板管理和附件服务任一开关关闭后，入口、直达路由及后端接口均不可用。字段映射、文件内容校验、导入结果与错误文件、异步导出、脱敏审批和执行记录不属于本闭环。

## V56 通用导入校验作业功能详细设计补充

导入模板创建时必须至少配置一个有序字段；字段编码、表头和顺序在模板内唯一，支持文本、整数、小数、日期、日期时间和布尔类型。文本可配置最大长度，字段可配置必填或启用字典类型。停用且未被作业引用的导入模板允许携带 `versionNo` 整体替换字段；启用模板和已被作业引用的模板只读，导出模板不得配置字段。

具备 `IMPORT_JOB_CREATE` 的 Web 用户选择启用导入模板、可选授权组织和单个 `.xlsx` 文件创建校验作业。系统在同一流程固化模板版本、名称、有序字段和启用字典项编码快照，并通过统一附件建立源文件关系。调度器使用 `QUEUED + versionNo` 条件领取，分批校验表头、必填、长度、类型和字典值；空白行忽略，公式不执行。全有效进入 `VALIDATED`，存在表头或行错误进入 `VALIDATION_FAILED`，内部异常进入 `SYSTEM_FAILED`。错误文件只包含行号、列名、字段编码、错误编码和中文说明，不包含原始单元格值。

具备 `IMPORT_JOB_READ` 的用户只可查询本人且仍处于当前组织范围内的作业；无组织作业只对创建人和系统管理员可见。权限撤回、显式禁止、组织范围变化或账号停用立即生效。校验作业不调用业务写入端口，不能把 `VALIDATED` 解释为学生或其他业务数据已导入。

## V57 通用异步导出作业功能详细设计补充

导出创建先校验 Web 客户端、`DATA_EXPORT`、模板管理和附件服务三个功能开关，再按数据集校验动态权限。积分台账要求 `EXPORT_JOB_CREATE`、必选当前用户可访问的学生，可按开始时间和结束时间筛选；权限变更审计要求系统管理员身份和 `EXPORT_SENSITIVE_SUBMIT`，可按时间和事件类型筛选。列集合必须来自服务端数据集白名单，模板必须为 `REPORT/EXPORT` 下启用的默认模板。系统在创建时固化模板、筛选、列、对象范围上界和脱敏策略快照，并只保存请求来源的 HMAC 摘要。

普通积分导出直接进入 `QUEUED`。敏感权限审计先创建并提交 `DATA_EXPORT` 系统任务，导出作业进入 `PENDING_REVIEW`；系统审核员只能查询等待审核的系统管理员申请，批准后作业进入 `QUEUED`，驳回后进入 `REJECTED`。调度器用状态和版本条件领取为 `EXPORTING`，再次校验开关、账号、角色、权限、对象范围和模板有效性，再按创建时的数据上界游标分批读取并写入 XLSX。成功保存统一附件和业务关系后进入 `SUCCEEDED`；敏感系统任务此时才标记生效。执行或附件确认失败进入 `FAILED`，临时文件和未完成物理内容必须补偿清理。

状态只允许 `PENDING_REVIEW`、`QUEUED`、`EXPORTING`、`SUCCEEDED`、`FAILED`、`REJECTED` 的受控迁移，事件表追加请求、送审、批准、驳回、领取、成功和失败记录。本人台账可按数据集和状态分页；详情返回安全快照摘要与事件，只有成功作业且当前权限和对象范围仍有效时允许下载。积分台账对学生姓名、来源机构和审核人姓名执行姓氏级脱敏；权限审计对操作人及用户类目标名称脱敏，不导出内部变更快照、IP、存储键或永久地址。

## V58 机构学员批量导入功能详细设计补充

机构管理员只能选择本人、当前授权学校、状态为 `VALIDATED` 且模板模块为 `STUDENT` 的校验作业，每个校验作业只允许创建一个业务执行。可选班级必须是同校启用班级；不选班级时仅创建学员及学校关系。执行采用排队、条件领取和逐行新事务，单行失败不回滚其他行；失败行可单独重试，每行总尝试次数最多三次。执行状态为排队中、执行中、全部成功、部分成功或失败，逐行结果只返回源行号、状态、学生账号和固定失败摘要，不返回姓名和登录码。

每行开户成功后，登录码仅以 AES-256-GCM 行级密文短期存在；终态生成 XLSX 后，文件再次整体加密并交由统一附件保存，同时清除行级密文。凭证仅创建该执行的机构管理员可下载一次，有效期 24 小时，消费或过期后删除物理密文。凭证尚可下载时不得重试失败行，避免覆盖未交付结果。

## V59 教师管理功能详细设计补充

### 教师创建与目录

1. 机构管理员进入教师管理后，服务端按当前组织根路径在 SQL 分页前裁剪教师目录，可按账号或姓名、学校、班级和状态组合筛选，单页最多 100 条。
2. 新增教师必须选择授权范围内的有效学校，提交全局唯一账号、姓名、可选手机号和符合现有密码策略的初始密码；教师固定创建为机构用户并授予全局教师角色。
3. 初始班级可为空。选择班级时操作者还必须具备班级分配权限，且全部班级必须启用并属于所选学校；用户、学校关系、角色、密码和班级关系在同一事务中提交，任一步失败整体回滚。
4. 账号和学校创建后不可通过 V59 修改。详情与目录只返回脱敏手机号、活动班级和必要状态，不返回密码、摘要或会话信息。

### 资料、状态、密码和班级关系

1. 姓名和手机号可独立修改；手机号留空表示保持不变，只有显式清空标记才删除现有手机号，清空与新号码不得同时提交。
2. 启用、停用和锁定按目标教师及组织范围校验；停用或锁定后撤销全部活动会话。教师存在待审核任务时拒绝停用、锁定或解绑相关班级。
3. 密码重置复用统一密码策略和 BCrypt 摘要，成功后撤销该教师全部活动会话，并追加不含密码内容的 IAM 审计。
4. 班级绑定与解绑同时要求教师管理和班级管理开关。重复绑定保持幂等且不重复记日志；真实绑定与解绑分别追加不可变变更日志，范围外对象统一按不存在处理。

### Web 批量与小程序单项

Web 批量请求最多包含 100 个不重复教师标识。批量权限只代表使用批量编排能力，状态操作还要求状态基础权限，班级操作还要求班级分配权限；每位教师使用独立新事务，返回稳定成功状态或中性失败码，一个失败不回滚其他成功项。uni-app 不提供批量选择、批量接口调用或教师导入，只复用查询、新增、资料、状态、密码和单项班级关系接口。

## V60 机构与教师任务功能详细设计补充

### 登录与工作台

1. 启用的机构用户具备机构管理员角色且管理有效组织，或具备教师角色且至少关联一个有效班级时，可以建立小程序会话；会话后续请求继续实时校验账号、角色和组织关系。
2. 教师工作台只返回本人账号安全信息、实时小程序权限和有效班级摘要，不接受前端传入教师或班级身份。失去最后一个有效班级后，后续会话请求失败关闭。

### 任务操作与进度

1. 机构管理员在授权组织范围内创建机构任务，教师在本人有效班级范围内创建教师任务；草稿可编辑，发布后不可改写。小程序只支持单项草稿保存与下发，不提供批量下发。
2. 教师任务默认由创建教师审核。机构任务按任务配置确定审核人；已发布机构任务对承担目标学生班级的教师可见，但不复制任务或任务实例。
3. 进度接口只接受任务标识和分页参数。机构管理员查看授权组织任务全部学生，教师仅查看本人有效班级学生；家庭任务和范围外任务统一不可访问。学生账号只返回脱敏值。
4. 有审核权限的机构管理员或教师可查看本人待办，审核通过后按既有规则发放积分，驳回必须填写中性意见。

### 审核自动转交

停用或锁定教师、解除教师班级关系时，系统先锁定该教师相关待审核实例并逐项选择接替人。同班启用教师优先，授权机构管理员兜底；每次转交同步更新当前审核人、版本号、转交历史和任务事件。任一实例无接替人或并发状态变化时，教师状态或班级关系变更整体回滚。

## V61 学生异常报备功能详细设计

### 教师提交

1. 教师进入异常报备页时，后端重新校验功能开关、活动账号、教师角色、读取权限和当前有效班级，只返回本人班级选项。
2. 教师选择班级后，学生选项只包含该班当前有效学生，账号按前两位和后两位脱敏；前端提交班级、学生、异常类型、客观事实描述和 8 至 64 位幂等键。
3. 后端在写入前再次验证教师、班级和学生三方活动关系。相同教师和幂等键对应完全相同请求时返回原记录，对应不同请求时拒绝复用。
4. 创建事务同时写入待处理主记录、`SUBMIT` 动作和面向班级所属组织范围的 `PENDING` 本地消息事件；任一步失败整体回滚。

### 查询与处理

1. 教师台账仅展示本人提交且仍在本人有效班级范围内的记录；机构管理员台账按实时组织根路径裁剪，可按班级、学生、异常类型和状态分页筛选。
2. 详情查询沿用同一对象范围，返回主记录和按时间排列的动作历史，不返回家庭私有字段、完整学生账号、内部范围路径或消息载荷。
3. 机构管理员填写处理说明并携带当前版本号。后端确认记录仍为待处理且班级仍在组织范围内，以状态和版本条件更新为已处理，再追加 `HANDLE` 动作及面向原报备教师的 `PENDING` 本地消息事件。
4. 已处理记录再次处理、旧版本并发处理和范围外记录均失败；系统不提供编辑、撤回、删除、重新打开和批量处理接口。

### 功能停用

`STUDENT_EXCEPTION_REPORT` 停用后，Web 和小程序入口、菜单与命令隐藏，直达页重启到首页；后端所有查询和写接口独立拒绝。历史事实与待分发本地事件保留，不因开关停用删除。
