**版本**：V1.0（V34 本地验收快照）

**核对日期**：2026-08-08

**状态**：已核对，非完整项目验收结论

**核对依据**：[设计追溯](00-设计文档体系与需求追溯-V1.0.md)、[完整开发实施计划](../superpowers/plans/2026-08-08-lingdong-learning-master-development.md)、`server/`、`web/`、`miniapp/` 实际代码及 Flyway `V1` 至 `V34`

## 1. 核对结论

当前实现已形成组织与 RBAC、系统任务审核、功能开关、通用配置核心、平台账号 Web 会话、学生关系、8 位学生账号加 4 位登录码，以及学习任务发布、执行、业务审核、任务奖励积分原子入账、安全查询、主家长纠错和家庭奖励兑换。Web 与 uni-app 是两个独立前端工程；V28 新增成长复盘，V29 新增连续完成衰减和沉睡生命周期，V30 新增每日固定任务，V31 新增 JPG/PNG 图片打卡与统一附件认证访问，V32 新增任务待优化与手动/自动顺延，V33 新增 Web 主家长按学生复制昨日家庭任务，V34 新增系统预置常用模板与 Web 家长个人模板。

当前仍不是完整可上线的灵动学习系统。V34 已完成任务图片打卡、待优化与顺延、Web 主家长按学生复制昨日任务、系统/家长个人任务模板、小程序端侧隔离和本地回归，可标记为 **V1-V34 本地代码与构建验收通过**。复杂周期、提醒实际投递、短信与微信登录、二维码登录、副家长和关系变更、复盘 PDF/订阅/排行、导入导出执行、对象存储及真实第三方适配仍未完成，因此不能标记为 BRD 全功能验收或上线准备完成。

## 4. V21-V34 关键边界

1. 学生账号按当前年份后两位加 6 位序号生成，每年从 `000001` 递增到 `999999`；数据库行锁、期望值更新和唯一约束共同控制并发，账号不循环复用。
2. 创建学生、创建学生用户、授予 `STUDENT` 角色、写入凭证和建立家长或机构关系处于同一事务，任一步失败均不留下半成品身份。
3. 历史学生初始化和重置同时要求 RBAC 权限与对象范围。无关家长和跨机构管理员统一得到 404，避免泄露学生是否存在；重复初始化和非法状态返回 409。
4. 登录码使用测试与生产分离的版本化密钥。生产配置只保留环境变量占位，启动时要求当前版本 Base64 密钥解码后不少于 32 字节；代码、迁移和前端产物不保存真实密钥。
5. 未知账号、账号类型错误、账号或学生停用、凭证缺失和登录码错误统一返回 `STUDENT_AUTH_FAILED`，并执行等价摘要比较；错误响应不区分账号是否存在。
6. 登录按账号设备和来源地址限流，验证码按来源限流。生产使用 Redis 原子脚本，测试使用独立内存实现；Redis 异常返回 `AUTH_PROTECTION_UNAVAILABLE`，不降级绕过安全控制。
7. 登录码重置覆盖摘要和随机盐，并在同一事务中撤销该学生全部活动会话；客户端退出即使服务端请求失败也会清除本地会话。
8. 小程序 H5 仅用于独立调试与兼容构建，开发代理指向本地 `127.0.0.1:8080`；微信小程序产物仍由 `build:mp-weixin` 独立生成，Web 端状态和路由不与小程序复用。
9. 微信、数据库和 Redis 的真实连接参数不进入本次测试。当前测试只使用本地 H2、测试专用密钥、测试验证码和内存保护存储。
10. 家庭任务只能面向当前家长活动主关系学生；机构任务只能使用机构管理员授权组织子树；教师任务只能使用教师本人活动班级及其学生。跨范围任务统一按不存在处理，避免对象枚举。
11. 任务创建、编辑和发布均由后端重新计算来源、目标、审核人与基础积分，不信任前端提交的权限范围或派生值；只有 `DRAFT` 可编辑和发布。
12. 发布事务先锁定草稿，再重新校验范围、展开并去重学生、批量写入实例，最后更新任务状态；没有有效学生时整单拒绝。批量发布通过独立 Bean 的 `REQUIRES_NEW` 逐项隔离，单项失败不回滚其他成功项。
13. 学生任务查询从当前 `MINIAPP` 会话解析学生身份，不接受请求方指定学生标识；Web 管理端与小程序端不复用路由或会话类型。
14. 暂停不改变任务基础状态；存在未关闭且未到期暂停时，响应有效状态为 `PAUSED`。打卡每次生成独立提交序号，驳回后再次提交不覆盖旧记录。
15. 审核待办只按当前审核人读取。转交候选必须来自服务端家庭主关系、活动班级或机构范围查询，转交同时更新快照、写历史和事件。
16. V24 审核通过端点不接受客户端积分、学生、来源或余额；服务端锁定任务实例、最新打卡和积分账户，在同一事务内写入 `APPROVED`、`COMPLETED`、双余额、唯一任务奖励台账和 `REVIEW_APPROVED` 事件。
17. 未纠错任务由任务状态、最新打卡状态、事务行锁和账户版本共同防止重复发奖；重复审核、并发旧请求、账户版本冲突或任一步写入失败均不得产生部分入账。
18. V25 学生积分端点从 `MINIAPP` 会话反查本人，不接受学生标识；家长端点只允许 `WEB` 会话和活动主关系学生，无关系学生按 404 处理。
19. 统一账户包含家庭、机构和教师来源，V25 不向教师、机构管理员、系统管理员或系统审核员开放；后续统计必须按来源和组织范围隔离。
20. `GROWTH_POINT_QUERY` 停用后 Web/小程序入口及直达页不可用，后端授权请求返回 `FEATURE_DISABLED`；前端隐藏不能替代后端开关、RBAC 和对象范围校验。
21. V26 只允许当前活动主家长纠正本人审核的家庭任务奖励，且任务必须仍为完成、当前审核责任未变、最新打卡仍为该家长通过；教师、机构角色、学生和其他家长不能发起。
22. 纠错时限从原奖励发生时间计算 72 小时；原因去空白后必须为 1 至 500 字。累计积分整笔扣除原奖励，可用积分最多扣至 0，不产生负余额。
23. 纠错不修改原台账，新增唯一关联原奖励的 `CORRECTION` 台账；账户、反向台账、任务回退、完成时间清空、打卡回退和 `POINT_CORRECTED` 事件处于同一事务。纠错后重新审核可产生新奖励。
24. V27 奖励直接归属一个学生；创建家长只保留审计意义，当前活动主家长可维护和处理该学生既有奖励，无关家长按 404 处理。
