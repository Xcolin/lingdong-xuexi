## 1. 测试目标与范围

1. 验证六类角色、RBAC、组织树、用户权限、数据范围、家庭/机构隔离和功能开关按设计联动。
2. 验证账号、学生、任务、积分、奖励、复盘、机构、考勤、消息、导出和系统配置的主流程、状态流转、异常与历史态。
3. 验证 Web 与小程序独立构建而业务结果一致；复杂统计/配置只在 Web 完整提供，高频操作按设计在两端可用。
4. 验证 Flyway 从空库和升级库均可执行，且不通过手工改库、修改历史迁移脚本完成发布。
5. 验证未成年人数据、位置控制、脱敏、附件、接口、日志、导出和第三方回调不会产生越权或泄露。
