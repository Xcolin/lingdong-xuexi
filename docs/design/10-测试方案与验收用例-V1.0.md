# 灵动学习测试方案与验收用例

**版本**：V1.0（设计基线草案）  
**状态**：待评审  
**依据**：[BRD](../../灵动学习-业务需求说明书-V1.0.md)、[FSD](01-功能详细设计-FSD-V1.0.md)、[API](06-API接口设计-V1.0.md)、[安全设计](07-权限与安全设计-V1.0.md)

## 1. 测试目标与范围

1. 验证六类角色、RBAC、组织树、用户权限、数据范围、家庭/机构隔离和功能开关按设计联动。
2. 验证账号、学生、任务、积分、奖励、复盘、机构、考勤、消息、导出和系统配置的主流程、状态流转、异常与历史态。
3. 验证 Web 与小程序独立构建而业务结果一致；复杂统计/配置只在 Web 完整提供，高频操作按设计在两端可用。
4. 验证 Flyway 从空库和升级库均可执行，且不通过手工改库、修改历史迁移脚本完成发布。
5. 验证未成年人数据、位置控制、脱敏、附件、接口、日志、导出和第三方回调不会产生越权或泄露。

## 2. 测试层级

| 层级 | 覆盖目标 | 证据 |
|---|---|---|
| 单元测试 | 状态机、权限判定、数据范围、字段校验、计算规则 | JUnit 测试和覆盖的关键规则。 |
| 持久化/迁移集成测试 | MyBatis XML、约束、Flyway 顺序、升级兼容性 | 空库/升级库迁移结果和查询验证。 |
| API 集成测试 | 认证、授权、幂等、错误码、事务、审计、脱敏 | API 请求/响应断言与审计记录。 |
| Web E2E | 路由、菜单/按钮隐藏、表单、列表、导出、复杂统计 | 自动化浏览器测试及截图。 |
| 小程序 E2E | 登录、任务执行、审核、摘要、功能关闭和构建包能力 | 自动化/真机验证记录。 |
| 安全测试 | 越权、跨家庭/跨组织、会话、文件、导出、密钥泄露 | 安全测试报告和修复验证。 |
| 第三方集成测试 | 微信、短信、文件、地图、回调、通知失败重试 | 沙箱/测试环境记录。 |
| 性能与稳定性测试 | 列表、统计、导出、消息、定时任务、迁移 | 使用经确认的并发、数据量和 SLA 目标。 |
| UAT | 业务方按角色验收流程和报表 | 签署的用例结果与遗留清单。 |

性能容量、并发量、响应时间和可用性目标尚未由业务方给出，不能以临时数字替代验收基线；在发布评审前必须补充。

## 3. 标准测试数据

| 数据组 | 内容 | 用途 |
|---|---|---|
| 组织树 | 至少两个区域、每区多个学校、学校下年级/班级，含启用与停用节点 | 验证树、同级唯一、组织范围和跨区隔离。 |
| 角色用户 | 系统管理员、系统审核员、机构管理员、教师、主家长、副家长、学生及自定义角色 | 验证内置/自定义角色、允许/禁止和会话。 |
| 家校关系 | 仅家庭学生、仅机构学生、已绑定主副家长学生、已解绑学生 | 验证双主体与数据隔离。 |
| 任务 | 家庭、机构、教师来源；待认领、进行中、暂停、待审核、已完成、待优化、免执行 | 验证状态机、审核、转交和统计。 |
| 积分与奖励 | 正向发放、兑换待审批、驳回、待核销、已核销、纠错、休眠清零 | 验证账户、台账和只奖不罚。 |
| 配置 | 启停字典、模板、附件规则、接口服务、功能开关 | 验证配置生效、历史展示、缓存刷新和审核。 |
| 位置 | 地理考勤、轨迹均关闭；模拟授权、撤销、过期和审批通过但构建未包含能力 | 验证默认拒绝与隐私边界。 |

测试数据必须使用虚拟账号和脱敏样本；不得使用真实未成年人、真实家长或真实生产凭证。

## 4. 核心验收用例

### 4.1 组织、角色与数据范围

| 用例编号 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|
| UAT-IAM-001 | 系统管理员已登录 | 新增自定义运维角色并授予限定权限 | 创建成功；无法授予超过管理员可授权边界的权限。 |
| UAT-IAM-002 | 两个区域、多个学校存在 | 为机构管理员配置一个学校范围 | 只能查询、编辑授权学校及子树数据；跨校请求被后端拒绝。 |
| UAT-IAM-003 | 用户有角色允许和用户明确禁止同一操作 | 请求该操作 | 明确禁止优先，菜单/按钮隐藏且接口返回拒绝。 |
| UAT-IAM-004 | 用户有用户补充允许权限但无组织范围 | 请求其他学校数据 | 不扩大组织/数据范围，接口拒绝。 |
| UAT-IAM-005 | 组织管理员绑定一个组织 | 访问该组织子树和同级组织 | 子树内按授权可用，同级/上级无权。 |
| UAT-IAM-006 | 角色、用户或组织已停用 | 使用已登录会话访问受控接口 | 下一次访问按最新状态失效，不继续执行。 |

### 4.2 系统任务、配置与功能开关

| 用例编号 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|
| UAT-SYS-001 | 系统管理员已登录 | 创建并提交全局功能开关调整 | 任务进入待审核，开关不提前变化。 |
| UAT-SYS-002 | 待审核任务由管理员 A 提交 | 审核员审批通过 | 记录审批信息，配置执行成功后任务才为已生效。 |
| UAT-SYS-003 | 审核员是任务提交人 | 审批本人任务 | 被拒绝，不能自审。 |
| UAT-SYS-004 | 家庭任务待审核/积分兑换待审批存在 | 系统审核员尝试处理 | 不存在入口，接口拒绝；普通业务审核人保持不变。 |
| UAT-SYS-005 | 某功能关闭 | 用菜单、消息、收藏直链和 API 访问 | 所有入口隐藏或拒绝；不产生新数据、待办、通知。 |
| UAT-SYS-006 | 字典项被停用 | 新建表单与历史详情分别查看 | 新建不可选该项；历史仍显示原值。 |
| UAT-SYS-007 | 全量缓存或会话缓存清除请求 | 发起操作 | 展示影响与二次确认，进入系统审核；失败有记录。 |

### 4.3 账号、学生与家校关系

| 用例编号 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|
| UAT-AUTH-001 | 已登录家长或直接机构管理员 | 创建学生 | 同事务建立学生档案、独立 `STUDENT` 用户、角色、8 位账号和 4 位登录码；明文登录码只在创建响应出现一次。 |
| UAT-AUTH-002 | 机构学生待绑定，家长已持有既有 `PARENT` 账号 | 在 7 天内使用机构线下受控转交的一次性令牌确认或拒绝邀请；或在过期后由机构重新签发 | 确认后原子建立唯一主家长关系；拒绝/过期不建立关系，机构可重新发送；原始令牌不落库、不写日志且只在创建响应可见一次。 |
| UAT-AUTH-003 | 学生存在 | 连续输错登录码 5 次与 10 次 | 第 5 次后要求图形验证码；第 10 次锁定 15 分钟。 |
| UAT-AUTH-004 | 主副家长均绑定 | 主家长解绑 | 最早副家长升级为主家长；待审核家庭任务转交。 |
| UAT-AUTH-005 | 家长与机构通过学生关联 | 机构管理员查询家庭任务/奖励 | 不返回家庭私有数据。 |
| UAT-AUTH-006 | 用户有多个设备会话 | 一键下线 | 所有旧设备会话失效，当前操作记录日志。 |
| UAT-AUTH-007 | V19/V20 历史学生未关联学生用户 | 主家长、直接机构管理员和无关家长分别初始化 | 前两者各自在对象范围内成功且只返回一次登录码；无关家长得到 404；重复初始化得到 409。 |
| UAT-AUTH-008 | 学生已建立活动小程序会话 | 主家长或直接机构管理员重置登录码 | 登录码摘要和随机盐发生变化，所有旧活动会话撤销，旧登录码不可再登录。 |
| UAT-AUTH-009 | `STUDENT_CODE_LOGIN` 已关闭 | 从首页、登录页直达、验证码和登录接口访问 | 首页隐藏入口、直达页不可操作，后端返回 `FEATURE_DISABLED` 且不创建会话。 |
| UAT-AUTH-010 | 已存在学生账号 | 分别从 Web 密码端点和小程序登录码端点登录 | Web 密码端点拒绝学生账号；正确登录码仅创建 `MINIAPP` 会话，19 位会话标识以字符串返回。 |

### 4.4 学习任务、积分与成长复盘

| 用例编号 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|
| UAT-TASK-001 | 家长/机构/教师具有相应范围 | 分别创建并下发任务 | 任务来源正确、目标范围合法，学生统一列表可按来源筛选。 |
| UAT-TASK-002 | 学生拥有待认领任务 | 认领、暂停/搁置、恢复、打卡 | 状态按 FSD 流转；暂停记录类型且不改变基础任务状态。 |
| UAT-TASK-003 | 打卡任务无有效审核人 | 提交打卡 | 被拦截，提示先配置或转交审核责任。 |
| UAT-TASK-004 | 教师审核人失效 | 等待审核的教师任务处理 | 转交同班授权教师；无同班教师时按规则转机构/组织管理员，并留痕。 |
| UAT-TASK-005 | 进行中任务 | 学生放弃或授权角色设置免执行 | 放弃进入待优化且无扣分；免执行终止且不发积分。 |
| UAT-POINT-001 | 任务打卡待审核 | 审核通过 | 任务完成，累计与可用积分正确增加，生成可追溯台账。 |
| UAT-POINT-002 | 可用积分充足 | 学生申请兑换，主家长同意、核销 | 先待审批，批准后扣可用积分并待核销，核销后不可重复。 |
| UAT-POINT-003 | 兑换 72 小时未审批 | 定时处理 | 自动驳回，积分不变。 |
| UAT-POINT-004 | 主家长本人误审家庭任务且原奖励未超过 72 小时 | 填写原因并发起积分纠错 | 整笔扣除累计积分，可用积分最低扣到 0；原奖励保留并新增唯一反向台账，任务与最新已通过打卡回退待审核，重复/越权/过期请求被拒绝。 |
| UAT-POINT-005 | 学生提交兑换后奖励被编辑、下架或删除 | 查询历史并由主家长处理 | 历史名称、所需积分和描述保持申请快照；下架、过期或删除后的待审批请求被拒绝且不扣分。 |
| UAT-POINT-006 | 同一待审批兑换有两个并发同意请求 | 同时提交审批 | 仅一个请求成功并生成一笔兑换台账；另一个返回状态冲突，累计积分不变，可用积分只扣一次。 |
| UAT-POINT-007 | 奖励兑换开关停用或请求方跨家庭/跨学生 | 通过菜单、直达页和接口访问 | 两端入口与页面不可用；后端停用返回功能关闭，越权对象按不存在处理，不泄露数据且不产生兑换或积分变化。 |
| UAT-POINT-008 | 同一任务标识连续安排并完成 16 个自然日 | 逐日审核通过 | 第 1 至 7 天全额、第 8 至 15 天衰减 20%、第 16 天起衰减 40%；每笔台账固化基础积分、实发积分、连续天数和规则。 |
| UAT-POINT-009 | 连续任务中断一天，或复制为新任务标识 | 再次完成并审核 | 连续天数从 1 重新计算；不得按标题、分类或复制来源继承原任务连续天数。 |
| UAT-POINT-010 | 学生连续 27 天无有效活动且有活动主家长 | 执行沉睡扫描两次 | 只生成一条 `PENDING` 提醒待投递记录，不重复创建；不宣称已实际发送。 |
| UAT-POINT-011 | 学生连续 30 天无有效活动且可用积分大于 0 | 执行沉睡扫描两次 | 第一次将可用积分清零并生成唯一 `DORMANCY_CLEAR` 台账，累计总积分不变；第二次不重复清零。 |
| UAT-POINT-012 | `POINT_LIFECYCLE` 关闭，或学生发生任务操作/积分变动/主动补录 | 审核任务并执行沉睡扫描 | 关闭时任务全额发放且不提醒、不清零；出现有效活动时沉睡周期重置。登录、查看和自动复盘不重置。 |
| UAT-GROW-001 | 当日有各状态任务 | 21:00 生成日复盘 | 生成完成率、积分、暂停、待优化数据；进行中不计完成率分母。 |
| UAT-GROW-002 | 复盘功能关闭 | 到达生成时间或调用导出 | 不生成新复盘、不显示新导出；历史按权限可读。 |
| UAT-GROW-003 | 学生存在日、周、月历史复盘 | 学生从小程序、主家长从 Web 查询 | 学生只见本人日复盘摘要；主家长只见活动主关系孩子并可筛选日/周/月；所有 19 位标识按字符串返回。 |
| UAT-GROW-004 | 同一周期事实未变化 | 重复执行生成和前一日回补 | 不新增快照版本；迟到任务、积分或暂停事实出现后新增下一版本，旧版本内容不变。 |
| UAT-GROW-005 | 当日或次日的日复盘 | 学生/主家长连续追加三类补录 | 每条独立留痕且不修改快照；非日复盘、超过次日、空白或超过 1000 字正文被拒绝。 |
| UAT-GROW-006 | 一个学生复盘生成异常 | 执行批量生成 | 失败学生记录摘要日志，其余学生继续生成，批次游标不会停滞。 |
| UAT-GROW-007 | 教师、机构管理员、无关家长或客户端类型不符 | 访问复盘列表、详情或补录接口 | 返回 403 或对象隐藏 404，不泄露学生、复盘或家庭补录内容。 |

## 6. 缺陷分级与准出

| 级别 | 定义 | 准出要求 |
|---|---|---|
| P0 | 数据泄露、未成年人位置误采集、越权、损坏账务/任务状态、无法登录、迁移破坏数据 | 必须关闭并回归。 |
| P1 | 主流程阻断、审核错误、积分错误、功能开关失效、导出越权 | 必须关闭并回归。 |
| P2 | 非主流程错误、有替代路径但影响体验/统计正确性 | 发布前评审并有明确处理结论。 |
| P3 | 文案、布局、低风险体验问题 | 记录并纳入后续排期。 |
