# 菜单与按钮管理能力增量规格

## Purpose

让菜单管理成为 Web 端权限目录的唯一维护入口：菜单与权限按钮的编码即权限编码，由系统自动同步至权限数据，授权时勾选菜单树即可；同时提供拖拽排序/层级调整与按钮批量维护能力。

## ADDED Requirements

### Requirement: 菜单与按钮字段维护
菜单管理 SHALL 维护菜单与按钮的类别（目录/页面/按钮）、名称、编码、路由（页面必填）、图标、顺序、状态；页面类型 MUST 提供路由，目录与按钮类型不提供路由。菜单管理 SHALL NOT 再提供"绑定已有路由/动作选项"与权限绑定入口。

#### Scenario: 新增页面菜单
- **WHEN** 管理员新增一个页面类型菜单并填写路由
- **THEN** 菜单保存成功并可配置名称、编码、图标、顺序、状态

#### Scenario: 页面类型缺路由被拒绝
- **WHEN** 管理员新增页面类型菜单但未填写路由
- **THEN** 系统拒绝保存并提示路由必填

### Requirement: 菜单编码即权限编码自动同步
页面菜单与其下权限按钮的编码 SHALL 即权限编码；当管理员创建或修改页面/权限按钮时，系统 MUST 按编码自动创建或更新对应的权限记录，管理员 MUST NOT 再单独新增权限。后端运行时权限判定行为 MUST 保持不变。

#### Scenario: 创建权限按钮自动生成权限
- **WHEN** 管理员在某页面下创建编码为某权限码的权限按钮
- **THEN** 系统自动存在对应权限记录，编码一致，无需手工新增

#### Scenario: 修改编码联动更新权限
- **WHEN** 管理员修改某权限按钮的编码
- **THEN** 对应权限记录的编码同步更新，既有授权关系保持关联

### Requirement: 权限按钮与纯 UI 按钮分类
按钮 SHALL 分为权限按钮与纯 UI 按钮两类：权限按钮编码对齐权限码、参与授权勾选与权限同步；纯 UI 按钮（查询、重置等纯前端交互）仅用于显示控制，MUST NOT 参与授权勾选，也 MUST NOT 产生权限同步。

#### Scenario: 纯 UI 按钮不出现在授权视图
- **WHEN** 管理员打开角色的菜单树授权视图
- **THEN** 树中仅出现页面与权限按钮，纯 UI 按钮不可见、不可勾选

### Requirement: 菜单下按钮批量添加与修改
系统 SHALL 支持在某个菜单下批量添加多个按钮（一次提交多条编码/名称/类别信息），并支持对其下既有按钮批量修改（名称、编码、类别、顺序、状态等字段）；批量提交 MUST 保证编码唯一性校验，冲突时明确报告冲突条目。

#### Scenario: 批量添加按钮
- **WHEN** 管理员在某页面下一次提交 5 个新按钮
- **THEN** 5 个按钮全部创建成功并出现在该页面下

#### Scenario: 批量提交编码冲突
- **WHEN** 批量提交中存在与既有节点重复的编码
- **THEN** 系统报告冲突的条目，冲突条目不写入，其余合法条目按事务边界处理

### Requirement: 菜单拖拽排序与层级调整
系统 SHALL 支持对菜单与按钮进行拖拽调整同级顺序与层级挂载，保存后立即生效；系统 MUST 阻止将节点移动到自身或其子孙节点之下，并记录审计信息。

#### Scenario: 拖拽移动菜单层级
- **WHEN** 管理员将某页面菜单拖拽到另一个目录之下
- **THEN** 层级立即变更，树形导航按新结构展示，并产生审计记录

#### Scenario: 拖入自身子孙被拒绝
- **WHEN** 管理员将某菜单拖拽到其自身子孙节点之下
- **THEN** 系统拒绝该操作，菜单树保持不变

### Requirement: 存量按钮目录重编码迁移
存量迁移 SHALL 将既有按钮目录中具有权限语义的按钮重编码为对应权限编码，纯 UI 按钮编码保持不变；重编码 MUST 保证前端按钮显示控制按新编码正常工作，既有角色授权关系 MUST 保持有效。

#### Scenario: 重编码后授权关系保持
- **WHEN** 权限型按钮重编码迁移执行完成
- **THEN** 原有已授予该按钮对应权限的角色仍保持该权限

#### Scenario: 重编码后前端按钮控制正常
- **WHEN** 使用者打开启用重编码按钮的页面
- **THEN** 按钮的显示、名称、顺序控制行为与迁移前一致

### Requirement: 小程序权限不受影响
小程序端权限 MUST 维持既有目录与授予方式，不纳入菜单树授权，其数据与行为 MUST NOT 因本能力变更而改变。

#### Scenario: 小程序权限照常授予
- **WHEN** 管理员按既有方式为角色授予小程序端权限
- **THEN** 授予行为与生效结果与升级前一致
